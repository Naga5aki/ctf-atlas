## 范围与完成条件

用户指定四个入口，随后要求 Forensics-Wiki 与 DigiForensics 各知识页；DigiForensics 登录限制出现后，用户选择先完成公开可读内容。57 个 Wiki 正文节点、58 个 Digi 知识目录页及两个独立入口共 117 条记录均有处理说明。Wiki 的另一节点是 X-Ways 分类目录，不是正文页。目录外的题库、赛事题目、检材、WP、网盘、公众号和外部教程不自动扩大为新采集范围。

内容按事实、证据位置、命令、条件、判断和限制重新编排；保留已有正文，并沿用五类题型与通用方法。网页读取、命令文档核对和合成数据验证不是对题目检材的独立复跑。

## 勘误与版本条件

- 内存采集与分析分开；物理内存、进程 memdump、PE 导出和 LSASS minidump 不混用。Vol2 Profile ZIP 与 Vol3 ISF 不互换。
- Vol3 dumpfiles 的 virtaddr / physaddr 指 FILE_OBJECT 所在地址层，输出可能缺页；GUI 字节视图、截图、扫描命中不直接当作完整文件或恶意证据。
- Linux Profile 指定目标 KVER；不按分析机 uname-r 制作。RAID 不用 create 重建原盘，Btrfs 等挂载记录只读与日志重放条件。
- MySQL 应为 .ibd，必须核对版本、DDL、表空间及加密条件；XtraBackup 解包/解压后还需 prepare 和实际数据库验证。
- SAM 常见 NT hash 不是普通 MD5；EFS、DPAPI、BitLocker、TrueCrypt/VeraCrypt 条件分别记录。VeraCrypt 1.26 不再提供旧 TrueCrypt 模式。
- Chromium 时间纪元、Firefox 微秒、iOS Manifest 路径哈希分别校验；无痕模式不保证所有可关联材料均不存在。Chrome AppBound、Firefox 144 的 NSS 条件不套用旧解密教程。
- Recall 数据有当前保护条件，WSA 是历史组件；旧 iPhone DFU 操作不推广到所有机型。Android 外部存储不必然是物理 SD 卡。
- adduser 不普遍等同 useradd；ctime 不是创建时间；chattr 的历史属性不保证支持安全擦除或恢复。
- 本机 Volatility 目录只确认有 Vol2 及其独立程序，删除了不存在的 Vol3 本地路径声称。其他已登记本机目录只读核对，未运行取证工具。
