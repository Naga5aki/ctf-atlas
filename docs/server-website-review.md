## 技术校正

- SSH 连通按网络、监听/实际 unit/socket、策略与认证逐层核对；不能把现代 OpenSSH 默认视为受 TCP wrappers 控制，也不以关闭全机防火墙代替排查。
- 宝塔菜单编号按构建核对；`default.db` 解析 schema、WAL 与一致快照；绑定字段和操作候选不直接等同实际操作者或成功动作。
- 两份 Linux 根树不是站库分离的充分证据；核对 UUID/fstab、主机身份、服务、连接目标、实例与时间。
- 三要素具体化为 Web/运行时、数据库/数据、代码/配置三条匹配链。代理方向、FPM socket、Host/SNI、活动 profile、外部配置和容器网络命名空间逐项对应。
- MySQL/MariaDB 账户恢复、认证插件、逻辑/物理恢复按版本处理；不通用套用 `PASSWORD()`、旧 GRANT、`mysql.user` 改列、`root@%` 或 Docker 初始化环境变量。
- 32 位十六进制不能单独判 MD5；盐、参数、pepper 和验证流程一起判断。不上传摘要到公共查询站点。仿真认证与外部验证码采用专用身份、受控测试接口和正反例，记录改动、差异和回滚。
- 业务查询保留基表主键基线，检查字典和关联重复、孤立记录、NULL、软删除、租户/角色、状态枚举、时区、单位与币种。不能让 INNER JOIN、NOT IN/NULL 或重复连接悄悄改变统计范围。
