## 4. 结构和技术判读修正

- 将“找配置/找名单/找口令”升级为实际配置、账户来源、认证、传输、业务结果和时间覆盖的逐层证据链。
- 校正 Apache 配置根与网站根、Tomcat redirectPort、IIS W3C 时间、FTP chroot 名单的语义。
- 区分 PHP 表单字段、User-Agent、文件写入和邮件调用；命令优先显示定位对象，不在普通输出复制硬编码秘密。
- 区分 Docker 镜像与容器、初始化环境与当前数据库、声明端口与发布端口、宿主回环与分析机回环。
- SQL 保留全部模糊候选、实际 schema、排序规则及原值；自然人身份不由昵称、姓名片段或单个账户直接确定。
- 跨设备案例使用独立构造标识与模拟时间、请求、业务行，配有缺附件、缺认证映射、失败业务及冲突的反例。相同字节内容和时间接近不足以证明同一人完成全部操作。
