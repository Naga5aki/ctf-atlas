# 服务器取证模块原位实战化核查计划

## 范围与保全
- 范围取自当前服务器取证分类：21 篇维护稿及对应生成页，533 个真实章节；代码内 8 行 SQL 注释不计章节。
- 先冻结原文件、SHA-256、目录清单及基线检查；上一级原始资料只读。
- 不新增文章、不改标题/层级/分类，不删代码、表格、技术参数或复用示例。

## 实施顺序
1. 按章节逐项阅读，记录适用场景、操作、判读、风险与交叉引用是否完整。
2. 分别核对本地原始资料、来源缓存和当前官方文档；将全文已读、缓存已读、公开预览、访问受限分开记录。
3. 在原段落补足命令输出含义和下一步，拆解长句；有效内容原样保留。来源不确定处保留并列待确认，不删除。
4. 校验每条替换仅命中一次；先修改工作副本，再同步维护稿和生成正文，保留元数据。
5. 校验 533 个标题、全部代码块、全部表格和原技术 token；逐条复核变更及来源依据。
6. 运行回归、构建、链接审计及两轮隔离导入；回滚在另一份副本测试，当前知识库保留改进后状态。

## 验收与停止条件
- 每篇均有章节检查记录及实际变更清单，无跨模块变更、无新增重复流程。
- 不确定应否保留的内容先保留并询问；不执行原始检材程序或连接原服务器。
- 已存在的外部工具目录缺失单独报告，不用造目录消除基线失败。
- 浏览器既有访问决定保持有效；静态构建与页面文件检查不冒充浏览器验收。
- 交付逐文件变更清单、机器核查记录、改后模块副本、差异、验证及可执行回滚。
