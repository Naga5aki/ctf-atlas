## 范围与维护文件

- 网站架构、中间件、访问日志、连接配置、PHP 行为与副本重构：`src/content-curation/fic-case-04.md`；面板页仅补跳转。

## 约束

保留原有详细正文；不新增题型、冗余标签或重复文章。K8s 仍只有服务器集群下的一篇完整知识点。网站不出现题号、人名、比赛、固定答案、出处或真实凭据。命令默认 Kali/Linux，IIS 所需 Windows 例外明确标注。不得运行未知检材、原网站 PHP 或连接真实数据库/邮件服务。
