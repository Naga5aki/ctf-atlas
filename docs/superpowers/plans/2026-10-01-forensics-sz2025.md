# Forensics 文档知识整合 Implementation Plan

> **For agentic workers:** 按已授权的独立实战规范分组编辑，主任务统一导入、复核与验收。

**Goal:** 完整提取指定手册中的可复用取证知识与考点，合并重叠内容，形成独立、详细、可操作的知识内容。

**Architecture:** 完整正文维护于 `src/content-curation`，既有条目补充对应技术主题；无线握手形成一个独立网络条目。内部覆盖清单记录手册章节与网站知识点的对应关系，网站不展示文档或具体题目。生成器保留内部关联并支持重复导入。

**Tech Stack:** Markdown、Python、Astro、Pagefind。

**Spec:** 用户指定的 `取证/2025数证杯初赛-取证知识点-模块化复习手册.md` 与已确认的 Forensics 独立实战格式。

## Global Constraints

- 指定手册只读；新增知识以手册实际出现的主题为范围。
- 网站不提文档、比赛、题名、题号、固定答案；案例使用说明清楚的演示数据。
- 原有正文保留并细化；沿用五类题型和通用方法，Docker 仍在唯一专题下。
- 每个实战写场景、材料、证据路径、命令、输出判读、交叉验证和限制。
- 默认 Kali/Linux 命令；离线、现场和隔离仿真明确区分。
- 不声称已执行未知附件。工具文档经 Context7 或官方资料校正。

## Review Focus

- 概括式错误：握手必须连续四包、硬删只能靠 binlog、容器重启必然换 ID。
- 字节/扇区/簇与相对/绝对地址混淆；PNG CRC 和 ZIP 标志修复破坏有效数据。
- 调试和仿真改变证据；配置或字符串被当作历史运行证明。
- 派生参数、盐、认证标签、钱包网络/路径不完整造成错误恢复。
- 导入丢失改写、分类重复、文案泄露或搜索索引未更新。
