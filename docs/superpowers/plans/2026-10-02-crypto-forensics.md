1. 读取指定知乎公开正文；并行核对链官方、钱包官方、国内取证实例及国外研究。协议事实优先按官方规范校正；研究结论保留适用范围。
2. 在现有题型目录中增加虚拟币取证，提供基础与证据、钱包与控制权、链上交易、资金追踪与实战四组，共六篇新正文。内部登记阅读日期和技术修正，网页正文独立实用。
3. 添加可下载的离线合成账本与整数统计脚本，验证跨网络资产隔离、重复冲突、失败和自转排除、时间边界及零选中输出。练习使用合成标识，不代表真实链查询。
4. 同步搜索筛选和维护约定，按规范导入生成正文；核对原有正文与页面数量。
5. 完成单元测试、界面测试、类型检查、构建、审计，以及浏览器目录、正文、下载、搜索与筛选检查；保留截图和验证记录。当前工程无 Git 仓库，不创建提交。
