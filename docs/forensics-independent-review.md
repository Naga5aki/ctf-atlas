# Forensics 独立实战内容复核

正文在 `src/content-curation/<页面ID>.md` 维护，导入在 Docker 与通用方法归并后应用。页面 ID、分类、标签、内部关联字段均已逐篇核对；101 篇其他模块知识点与本轮基线逐字节一致。

计数采用统一换行、去除 frontmatter 并去掉正文首尾空白后的字符数。长度只作缩减预警，主题保留另由各组复核记录确认。命令与示例不是实际附件复跑证明。

## 技术复核

- 偏移、分区与数据库：分清字节/扇区、Btrfs/ext 结构位置、SQLCipher 盐与参数、整数编码及 WAL 提交/残留。
- 身份与历史：区分配置、安装、运行和业务成功；PE/PDB 时间、包时间、文件时间与日志不可相互代替。
- 网络与容器：代理/中继节点不能推定操作者位置；重启隧道不能恢复历史公网地址；环境、卷、日志与编排配置按实际对象核对。
- 恢复与解密：每层输入输出可对应，修复字段具有范围与方向验证；可打印文本或预览正常不足以证明完整正确。
- 全部原有任务索引保留为 52 个独立分析任务，关联流程与平台路径单独可查。

SQLite 的只读、备份、恢复边界核对了 [官方 CLI](https://www.sqlite.org/cli.html)、[WAL](https://www.sqlite.org/wal.html)和[恢复说明](https://www.sqlite.org/recovery.html)。其他具体工具的文档入口随专题保留，内部复核不进入网站展示。
