# U盘取证构造练习

sample.mft 是45个1024字节槽位的 FILE 记录流；sample.usn 是3条USN V2记录。它们用于练习解析、驻留导出、两个名字与ADS、头部/工具键的序列表现及日志关联。

这些文件不是完整NTFS卷或实际U盘镜像；非驻留数据簇为虚构，不能恢复真实内容。XFW/WinHex应按普通文件查看原始记录，而不是按整盘加载。工具参数与实战步骤见知识库的“U盘取证”页面。

有效记录槽为0、5、24、42、43、44；Docs为24-1，42-2有两个名字和ADS，43头部序列为3且已空闲。日期与名称是构造材料。具体长度、SHA-256及验证版本在manifest.json中。

MFTECmd 2026.5.0 已对该记录流验证常规CSV、JSON、bodyfile、单记录查看、驻留字节、USN路径与输出核对。其他版本应先保存帮助和版本，再对照原始结构，不仅比较行数。
