逻辑漏洞没有统一的特殊字符。它是业务流程允许了不该成功的状态。判断方法是把正常请求和“少掉一步、改掉一个数字”的请求比在一起。对象归属问题见 [越权](/knowledge/web-request-auth/)，这里看金额、顺序、次数与状态。

> 只在本地题目或授权环境里改自己的订单/验证码；响应中的验证码与口令不写入笔记。

## 00 30 秒速查

| 我要… | 先改… | 看什么 |
|---|---|---|
| 价格篡改 | 请求里的单价/总价 | 服务端是否重算 |
| 数量为负 | `qty=-1`/超大数 | 总额/库存变化 |
| 优惠券 | 叠加/换订单/重复用 | 是否绑定 |
| 跳过步骤 | 直接最后一步 | 是否要前序状态 |
| 验证码复用 | 同一码用两次 | 是否一次性 |
| 账号绑定 | 验证 A，重置 B | 主体是否绑定 |
| 并发 | 同时发两次 | 库存/余额只减一次？ |
| 频控 | 换 IP/换会话 | 计数在哪层 |
| 登录 | 枚举/空验证码/锁定 | 分支差异 |

## 01 原理与成立条件

```text
用户请求 → 服务端读参数 → 查业务状态 → 写结果
              ├─ 信任客户端金额/数量
              ├─ 不检查前序步骤
              ├─ 不绑定验证对象
              └─ 检查与写入非原子
```

| 条件 | 含义 | 不满足时 |
|---|---|---|
| 参数可改 | 金额/数量/状态 | 找其他字段 |
| 服务端复用客户端值 | 不重算 | 找二次写入 |
| 流程有状态 | 多步/审批 | 跳步 |
| 有并发窗口 | 读后写 | 竞争 |

## 02 判断与分型

```text
请求里有金额/数量吗？
 ├─ 有 → 改一个数字看订单
 └─ 无 → 看流程
      ├─ 多步 → 跳步/重放
      ├─ 验证码 → 复用/换账号
      ├─ 库存/余额 → 并发
      └─ 登录 → 枚举/频控/锁定
```

| 信号 | 含义 | 下一步 |
|---|---|---|
| 改单价成交价变 | 信任客户端 | 记录字段 |
| 负数使总额变负 | 未校验范围 | 试退款/增加 |
| 跳过验证仍改口令 | 状态未绑定 | 记录步骤 |
| 同码两次成功 | 非一次性 | 试跨账号 |
| 并发两单都成功 | 无锁 | 记差额 |
| 换 IP 后次数重置 | 计数按头 | 找真实 IP |
| 存在/不存在账号提示不同 | 枚举 | 记录差异 |

| 假阳性 | 原因 | 处理 |
|---|---|---|
| 页面显示改价 | 只前端 | 看订单/支付 |
| 200 但未写库 | 校验失败 | 查订单状态 |
| 并发一次成功 | 锁生效 | 提并发/换接口 |
| 提示统一 | 可能仍可枚举 | 比时间/长度 |

## 03 利用阶梯

### L0 画流程与字段

**前提**：有下单/支付/找回/登录流程。

**步骤**：
1. 正常走一遍，保存每步请求与状态。
2. 标出金额、数量、状态、账号、验证码字段。
3. 找服务端可能重算的位置（商品 ID/订单号）。
4. 记录哪些字段只在前端。

**成功标志**：流程与可控字段清单。

**失败分支**：接口不明→抓包；无状态→换业务。

### L1 金额与数量

**前提**：请求携带价格/数量/折扣。

**步骤**：
1. 改单价/总价，商品 ID 不变。
2. 试负数、零、小数、超大数。
3. 优惠券叠加/交换订单/重复使用。
4. 看订单最终金额与库存。

**成功标志**：成交价/库存与预期不符。

**失败分支**：服务端重算→找数量/优惠券；类型转换→试字符串。

### L2 步骤与验证码

**前提**：多步流程/验证码。

**步骤**：
1. 直接重放最后一步，不带前序验证。
2. 同码用两次；验证 A 账号后重置 B。
3. 改响应里的账号/令牌/步骤标记。
4. 看口令/订单是否真的变化。

**成功标志**：跳过验证仍完成操作。

**失败分支**：状态绑定→找令牌复用；验证码一次性→换通道。

### L3 并发与频控

**前提**：库存/余额/抽奖/登录失败计数。

**步骤**：
1. 同时发两个相同请求，记录时间与订单号。
2. 看库存/余额只减一次还是两次。
3. 换 IP/会话/设备看频控是否重置。
4. 试条件竞争：先校验后使用（优惠券/兑换码）。

**成功标志**：超扣/多次领取/绕过次数限制。

**失败分支**：有锁→提高并发/换接口；计数服务端→换账号。

### L4 登录与状态机

**前提**：登录/注册/找回有分支。

**步骤**：
1. 枚举用户名：状态码/文案/长度/时间。
2. 空验证码/缺字段/数组传参。
3. 锁定绕过：换客户端/改来源头/等窗口。
4. 会话固定/不旋转；默认口令。
5. 记录每一步的服务端分支。

**成功标志**：登录绕过/账号接管/枚举。

**失败分支**：统一错误→看时间；锁定严格→换账号/换入口。

## 04 绕过与边界

| 限制 | 替代 | 示例 |
|---|---|---|
| 前端校验 | 直接改包 | 单价/数量 |
| 金额重算 | 改数量/优惠券 | 负数/叠加 |
| 步骤校验 | 跳步/重放 | 最后一步 |
| 验证码绑定 | 换账号/复用 | 同码两次 |
| 频控按 IP | 换头/换出口 | `X-Forwarded-For` |
| 锁 | 提高并发/换接口 | 条件竞争 |
| 状态标志 | 改参数/方法 | `paid=1` |

边界：并发结果受事务/隔离级别影响；一次成功不等于没有竞争窗口；错误提示统一仍可能通过时间枚举；`Host` 头影响重置链接时看反代配置。

## 05 非典型入口

| 位置 | 示例 | 注意 |
|---|---|---|
| 退款 | 负数/超额 | 金额 |
| 积分/签到 | 重复领取 | 并发 |
| 邀请 | 自己邀请自己 | 绑定 |
| 试用/订阅 | 改到期时间 | 状态 |
| 导出 | 次数/范围 | 频控 |
| 审批 | 跳过审批 | 状态机 |
| 兑换码 | 多用/枚举 | 一次性 |

## 06 差异速查

| 场景 | 服务端应做 | 缺陷 |
|---|---|---|
| 价格 | 按商品 ID 查 | 信任请求单价 |
| 数量 | 范围/类型 | 负数/溢出 |
| 金额 | 十进制/舍入 | 浮点误差 |
| 状态 | 只由回调写 | 请求自带 `paid` |
| 库存 | 事务+条件更新 | 读后写 |
| 验证码 | 一次性+绑定 | 复用/换账号 |

| 阶段 | 动作 | 产出 |

| 1 流程 | 正常走一遍 | 步骤/字段 |

## 09 失败分支

| 现象 | 优先怀疑 | 处理 |
|---|---|---|
| 改价无效 | 服务端重算 | 改数量/券 |
| 200 未写库 | 校验失败 | 看状态 |
| 跳步失败 | 状态绑定 | 找令牌复用 |
| 并发只成功一次 | 锁 | 提并发/换接口 |
| 频控不重置 | 服务端计数 | 换账号 |
| 枚举无差异 | 统一提示 | 比时间/长度 |
| 验证码收不到 | 环境 | 看日志/测试通道 |
