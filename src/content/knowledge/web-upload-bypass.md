上传题的校验通常不止一层：前端 JS、后端扩展名、`Content-Type`、文件内容、保存路径、执行权限。绕过的前提是**知道哪一层在拦**，而不是把 `phtml`、`%00`、图片马全部试一遍。

> 只对本地题目或授权环境上传文件；不要上传到真实业务，测试后按题目方式清理。

## 00 30 秒速查

| 现象 | 先判断 | 下一步 |
|---|---|---|
| 选文件即弹窗 | 前端 JS | 禁 JS/直接 POST |
| “类型不允许” | 扩展名/MIME | 看提示对应项 |
| “不是图片” | 文件头/二次渲染 | 图片马 |
| 上传成功访问 403 | 目录不可执行 | 包含/换目录 |
| 文件名被改 | 重命名 | 找返回路径/包含 |
| 找不到文件 | 随机名/路径 | 返回包/列表/扫描 |
| 白名单只允许 jpg | 解析链 | `.htaccess`/`.user.ini` |
| Windows 目标 | 尾随点/ADS | `.php.`/`::$DATA` |
| 先存后删 | 竞争 | 上传+并发访问 |

## 01 原理与成立条件

```text
字节 → 前端校验 → 后端扩展名/MIME/内容 → 保存路径 → Web 解析
                                                        ├─ 可执行 → getshell
                                                        └─ 不可执行 → 包含/下载/反序列化
```

| 条件 | 含义 | 不满足时 |
|---|---|---|
| 能上传字节 | 有上传点/写文件 | 找其他写入口 |
| 校验可绕 | 某层只看声明/开头 | 换层/换解析 |
| 落点可访问 | Web 根/可包含 | 找包含/路径 |
| 解析器执行 | 扩展名映射 | 换后缀/配置 |

## 02 判断与分型

```text
上传一个 .jpg 和一个 .php，对比返回：
 ├─ 都被拒 → 前端/统一拦截
 ├─ jpg 成功、php 被拒 → 扩展名/MIME
 ├─ 都成功但 php 不执行 → 解析/目录权限
 └─ 都成功且 php 执行 → 直接 getshell
再看提示：
 ├─ “类型” → MIME/扩展名
 ├─ “内容/图片” → 文件头/二次渲染
 └─ “大小/路径” → 其他限制
```

| 信号 | 含义 | 下一步 |
|---|---|---|
| 返回包有路径 | 可定位文件 | 访问验证 |
| 文件名变 UUID | 重命名 | 包含/找映射 |
| 图片被重编码 | 二次渲染 | 找不变区域 |
| 上传目录可列 | 目录遍历 | 找已传文件 |
| `.htaccess` 可传 | Apache 配置 | 改解析 |
| `.user.ini` 可传 | PHP 配置 | `auto_prepend_file` |

| 假阳性 | 原因 | 处理 |
|---|---|---|
| 上传 200 | 只表示写入 | 访问/包含验证 |
| 后缀是 `.jpg` | 可能按内容解析 | 看服务器配置 |
| 文件头是图片 | 后面可附加 | 看解析器 |
| 目录 403 | 可能仍可包含 | 试 LFI |

## 03 利用阶梯

### L0 定位校验层

**前提**：有上传点。

**步骤**：
1. 传正常 `.jpg` 与 `.php`，对比返回码/文件名/路径。
2. 禁 JS 或直接 `curl -F` 重放。
3. 改 `Content-Type` 再试。
4. 看提示语对应哪层校验。

**成功标志**：知道哪层拦截、文件落在哪。

**失败分支**：统一拦截→换上传点；无回显→看返回包/日志。

### L1 扩展名与 MIME

**前提**：后端按后缀/声明类型拦截。

**步骤**：
1. 大小写：`.PhP`、`.PHTML`。
2. 多后缀：`shell.php.jpg`、`shell.jpg.php`。
3. 双写：`.pphphp`（只替换一次 `php`）。
4. 尾随点/空格：`.php.`、`.php `（Windows）。
5. MIME：`Content-Type: image/jpeg`。
6. 其他后缀：`php3/php4/php5/phtml/pht/phar/inc`。

**成功标志**：文件落盘且扩展名被解析。

**失败分支**：白名单→L3；重命名→L2/包含。

### L2 内容检测与图片马

**前提**：后端读文件头或二次渲染。

**步骤**：
1. 加魔数：`GIF89a` + 代码；JPEG `FF D8 FF`；PNG 完整签名。
2. EXIF 注释写入 payload。
3. 二次渲染：先上传图片，下载渲染后的版本，找不变区域（IDAT 后/注释块）再插入。
4. 短标签/拆分关键字绕过内容正则。

**成功标志**：通过内容检测，且解析时执行。

**失败分支**：重编码彻底→换格式/换解析链；内容杀毒→混淆/分段。

### L3 解析链与目录配置

**前提**：白名单严格，无法直接传脚本后缀。

**步骤**：
1. Apache：传 `.htaccess`，`AddType application/x-httpd-php .jpg`。
2. PHP-FPM/CGI：传 `.user.ini`，`auto_prepend_file=shell.jpg`。
3. Nginx `CVE-2013-4547`：`shell.jpg%20.php`（老版本）。
4. IIS：`shell.asp;.jpg`、`shell.asp/`、`shell.php.`。
5. 上传+包含/phar/日志。

**成功标志**：图片后缀被当脚本执行/被包含执行。

**失败分支**：`AllowOverride None`→换 `.user.ini`；配置已修→换组合链。

### L4 路径、竞争与权限

**前提**：文件能写入，但名字/位置/时机受限。

**步骤**：
1. 文件名穿越：`filename="../../shell.php"`。
2. 绝对路径：`filename="/var/www/html/shell.php"`。
3. 竞争：先落盘后校验/删除，上传与访问并发跑。
4. 找可写且可访问目录：`/uploads/`、`/static/`、`/tmp`（通常不可访问）。

**成功标志**：文件落到可执行目录/窗口内执行。

**失败分支**：名字被清洗→竞争/包含；目录不可写→换点。

## 04 绕过与边界

| 限制 | 替代 | 示例 |
|---|---|---|
| 前端后缀 | 改包 | `curl -F` |
| 黑名单 | 其他后缀/大小写/双写 | `phtml`、`.Php` |
| 白名单 | `.htaccess`/`.user.ini` | 改解析 |
| 文件头 | 魔数/图片马 | `GIF89a` |
| 二次渲染 | 不变区域 | IDAT/注释 |
| 重命名 | 包含/竞争 | 随机名也可包含 |
| 目录不执行 | 包含/下载 | LFI |
| Windows | 尾随点/ADS/分号 | `.php.`、`::$DATA` |

边界：`getimagesize` 只看开头；`.user.ini` 只对 CGI/FastCGI 且目录有 PHP 入口；`%00` 截断仅 PHP <5.3.4；`CVE-2013-4547` 仅老 Nginx。

## 05 非典型入口

| 位置 | 示例 | 注意 |
|---|---|---|
| 头像/附件 | 图片马 | 二次渲染 |
| 导入功能 | CSV/XML | 公式/XXE |
| 压缩包 | zip 内路径 | 解压穿越 |
| 对象存储 | 键名/公开读 | 云场景 |
| 日志 | 文件名写码 | 包含日志 |
| 临时文件 | 上传后删除 | 竞争 |
| 编辑器 | 富文本/文件管理 | 直传 |

## 06 差异速查

| 环境 | 规则 | 影响 |
|---|---|---|
| Apache | 多段扩展名/`AddHandler` | `php.jpg` 可能执行 |
| Nginx+PHP-FPM | `cgi.fix_pathinfo` | 路径回找 |
| IIS 6 | 分号/`.asp` 目录 | 截断 |
| IIS 7+ | 处理程序映射 | 看配置 |
| Windows | 尾随点/空格/ADS | 名字归一化 |
| PHP | `%00` 截断 | <5.3.4 |

## 07 工具与验证

| 目标 | 工具/命令 |
|---|---|
| 改包 | Burp Repeater |
| 上传 | `curl -F "file=@x;type=image/jpeg"` |
| 文件头 | `xxd`/十六进制编辑 |
| 图片马 | `exiftool`/`printf` 拼接 |

## 09 失败分支

| 现象 | 优先怀疑 | 处理 |
|---|---|---|
| 上传即失败 | 前端/统一拦截 | 改包/换点 |
| 后缀被改 | 重命名 | 包含/竞争 |
| 内容被拒 | 文件头/重编码 | 图片马/换格式 |
| 访问 403 | 目录不执行 | 包含/换目录 |
| 找不到文件 | 随机名 | 返回包/列表 |
| `.htaccess` 无效 | AllowOverride | `.user.ini` |
| 竞争不中 | 窗口/并发 | 提高并发/换点 |
| 执行无输出 | 命令权限 | 见 RCE 页 |
