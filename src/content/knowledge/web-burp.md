Burp 放在浏览器和本地题目之间，让你看见浏览器没显示的头和正文，并把同一次请求反复发出去。先把代理和证书接对，再谈改包。

> 只把代理指向自己的题目或明确授权的目标；陌生环境的根证书不要导入信任库。

## 00 30 秒速查

| 我要… | 先做… | 备注 |
|---|---|---|
| 接上代理 | 浏览器→`127.0.0.1:8080` | Burp 监听同端口 |
| 看 HTTPS | 导入 Burp CA 到信任库 | Firefox 用自己证书库 |
| 固定基线 | History 找一条正常请求 | 记方法/URL/头/体 |
| 一次改一处 | Repeater | 其余字节不动 |
| 看差异 | Comparer（Words/Bytes） | 剔掉动态字段 |
| 批量取值 | Intruder + 载荷 | 先清空位置 |
| 动态令牌 | Grep Extract/Recursive grep | 或宏 |
| 抓不到 | 代理/证书/锁定 | 见 09 |

## 01 原理与成立条件

```text
浏览器 → Burp 代理 → 目标
            ├─ TLS 终止（Burp CA）
            ├─ 明文历史
            └─ Repeater/Intruder 重发
HTTPS = HTTP + TLS；Burp 对浏览器出示自己的证书
```

| 条件 | 含义 | 不满足时 |
|---|---|---|
| 浏览器走代理 | 系统/插件/Firefox | 历史为空 |
| 信任 Burp CA | 根证书在用的库 | 只见 CONNECT |
| 应用不锁定 | 不校验固定指纹 | 握手失败 |
| 原始字节可改 | Raw/Hex | 长度/空行被改 |

| 检查 | 正确表现 | 错误表现 |
|---|---|---|
| 代理 | History 有请求 | 一直转圈 |
| 证书 | 有请求行/Cookie | 只有 CONNECT |
| 监听 | 端口一致 | 连接拒绝 |
| 字符集 | 按响应 `charset` | 中文乱码 |

## 02 判断与分型

```text
History 为空？
 ├─ 浏览器没走代理 → 检查系统/插件
 ├─ Burp 没监听 → 看 Proxy 监听表
 └─ 端口不对 → 改一致
只有 CONNECT？
 ├─ CA 没装进这只浏览器 → 导入根证书
 ├─ 装错存储 → 移到受信任根
 └─ App 锁定 → 换浏览器/放弃
有明文但响应异常？
 ├─ 跟随重定向 → 先看不跟随
 ├─ 字符集 → 按 charset 看
 └─ 长度被改 → 用 Raw 核对
```

| 现象 | 含义 | 下一步 |
|---|---|---|
| History 有请求 | 代理通 | 找基线 |
| 只有 CONNECT | TLS 未解密 | 装 CA |
| 证书警告 | 根不在信任库 | 导入 |
| 中文乱码 | 显示字符集 | 改显示 |
| 响应 302 | 跳转 | 读 `Location` |
| 请求体被改 | Pretty 模式 | 切 Raw |

| 假阳性 | 原因 | 处理 |
|---|---|---|
| 自带浏览器能看 | 它自动信任 CA | 系统浏览器另装 |
| 一次响应不同 | 会话过期 | 重登 |
| 长度变化 | 动态页面 | 看正文 |

## 03 利用阶梯

### L0 代理与证书

**前提**：本地浏览器/题目。

**步骤**：
1. Burp 监听 `127.0.0.1:8080`，浏览器代理指向同端口。
2. 访问 `http://burp` 下载 CA，或 Proxy 设置导出 DER。
3. 导入“受信任的根证书颁发机构”；Firefox 单独导入。
4. 完全退出浏览器再打开，访问 HTTPS 题目看明文。

**成功标志**：History 出现请求行、Host、Cookie、响应体。

**失败分支**：只有 CONNECT→证书；连接拒绝→端口/监听地址。

### L1 固定基线

**前提**：History 有流量。

**步骤**：
1. 挑一条正常请求，记方法、完整 URL、关键头、正文、状态码、长度。
2. 匿名/普通/管理员各留一条，分标签。
3. 原样送 Repeater 发一次，确认与历史一致。
4. 不一致先查会话/题目重启。

**成功标志**：可重复的基线响应。

**失败分支**：会话过期→重登；动态页面→找稳定字段。

### L2 Repeater 一次改一处

**前提**：有基线。

**步骤**：
1. 只改一个参数/头/字段。
2. `Raw` 核对空行/换行/长度；`Hex` 看不可见字节。
3. 响应与基线放 Comparer（Words/Bytes）。
4. 重定向先不跟随，记 `Location`。

**成功标志**：差异只来自改动的那一处。

**失败分支**：长度错→改 `Content-Length`；编码错→Decoder 确认。

### L3 Intruder / Comparer / Grep

**前提**：已知取值范围或需要提取令牌。

**步骤**：
1. Clear 位置再 Add，别把版本/长度标进去。
2. 选模式：Sniper（单点）、Battering Ram（同值）、Pitchfork（配对）、Cluster Bomb（笛卡尔积）。
3. 结果按状态/长度分组，再抽一条回 Repeater 看正文。
4. 动态令牌：Grep Extract 取标记间文本；载荷用 Recursive grep 回填。
5. 需要先 GET 表单再用宏。

**成功标志**：批量结果可解释，令牌能续上。

**失败分支**：令牌空→标记错；请求数不对→模式/基线；被限速→降速。

### L4 宏 / 会话 / 导出

**前提**：多步流程/一次性令牌/需要留证。

**步骤**：
1. Session handling rule 建宏：GET 表单→提取→POST 前替换。
2. 宏里用相同起止标记，先在 Repeater 手工框选。
3. 导出 History/请求，令牌与口令打码。
4. 记录基线、改动、状态、长度、正文差异。

**成功标志**：多步流程可重复，证据完整。

**失败分支**：宏顺序错→看日志；令牌对不上→重选框选。

## 04 绕过与边界

| 场景 | 边界 | 处理 |
|---|---|---|
| HTTPS | 需信任 CA | 导入根存储 |
| App 锁定 | 内置指纹 | 换浏览器/放弃 |
| 重定向 | 默认不跟随 | 先看 `Location` |
| Pretty | 可能改空格 | 用 Raw 发 |
| 社区版 Intruder | 限速 | 不看时间差 |
| `Content-Length` | 改正文要同步 | 自动/手工 |
| 动态令牌 | 旧值失效 | Grep/宏 |

## 05 非典型入口

| 位置 | 示例 | 注意 |
|---|---|---|
| WebSocket | 升级后的帧 | 另开工具 |
| HTTP/2 | 伪头 | 看支持 |
| 手机 App | 代理/证书 | 用户 CA 限制 |
| 非浏览器 | `curl` | 手动代理 |
| 内部请求 | 服务端发出 | 看日志 |

## 06 差异速查

| 浏览器 | 信任库 | 备注 |
|---|---|---|
| Chrome/Edge | Windows 当前用户根 | `certmgr.msc` |
| Firefox | 自己的库 | 或企业策略 |
| Burp 内置 | 自动信任 | 仅它自己 |
| Android 7+ | 用户 CA 受限 | 目标 SDK |

| Intruder 模式 | 请求数 | 用途 |
|---|---|---|
| Sniper | 位置×值 | 单点 |
| Battering Ram | 值数 | 同值 |
| Pitchfork | 最短列 | 配对 |
| Cluster Bomb | 笛卡尔积 | 组合 |

## 07 工具与验证

| 目标 | 操作 |
|---|---|
| 看明文 | Proxy → HTTP history |
| 重放 | 右键 → Send to Repeater |
| 对比 | Comparer |
| 批量 | Intruder |
| 提取 | Grep Extract / Recursive grep |
| 编码 | Decoder |
| 记录 | 导出 + 打码 |

验证顺序：代理 → 证书 → 基线 → 单点 → 批量 → 记录。

| 1 代理 | 浏览器/Burp | History |

## 09 失败分支

| 现象 | 优先怀疑 | 处理 |
|---|---|---|
| 一直转圈 | 代理/端口 | 查监听 |
| 只有 CONNECT | CA | 导入根 |
| 证书无效 | 装错存储 | 移根存储 |
| 中文乱码 | 显示字符集 | 改 UTF-8/按 charset |
| 手机连不上 | 绑定回环 | 监听 `0.0.0.0` |
| App 握手失败 | 锁定 | 换浏览器 |
| 历史空 | 直连 | 关系统代理/插件 |
