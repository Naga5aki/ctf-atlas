页面与接口表现不同，或题目包含登录、Cookie/JWT、角色与管理接口时，先把问题拆成三层：**请求是否到达**、**身份是否被识别**、**操作是否获得授权**。HTTP 200 只说明返回成功，不等于数据已按预期变化。

> 只对本地题目或明确授权的环境做对照；令牌只留短指纹。

## 00 30 秒速查

| 我要… | 先做… | 备注 |
|---|---|---|
| 建基线 | 匿名/同级/高权各一份请求 | 方法、路径、体、头 |
| 判断未授权 | 去掉 Cookie/Authorization 重放 | 仍返回业务数据 |
| 水平越权 | 保持 A 会话，换 B 的对象号 | 看是否读到/改到 |
| 垂直越权 | 高权请求换低权会话 | 看操作是否成功 |
| 找对象号 | 数字/ UUID/文件名 | 不可猜≠有校验 |
| 多步绕过 | 去掉前几步，直接最后一步 | 状态是否绑定 |
| CORS | 看 `Allow-Origin` 是否反射 | 带凭证更严重 |
| JSONP | `callback` 是否可控 | 读跨域数据 |
| 记录 | 三组响应并排 | 只改一个变量 |

## 01 原理与成立条件

```text
请求 → 认证（你是谁） → 授权（你能做什么） → 业务
          ├─ 无认证 → 未授权访问
          ├─ 有认证无所有权检查 → 水平越权
          └─ 有认证无角色检查 → 垂直越权
```

| 条件 | 含义 | 不满足时 |
|---|---|---|
| 请求可达接口 | 路由存在 | 找隐藏接口 |
| 身份可识别 | Cookie/JWT/头 | 换会话 |
| 授权缺失 | 路由/业务层不查 | 找其他对象/方法 |
| 结果可观察 | 数据/状态变化 | 用差异/副作用 |

| 类型 | 身份 | 多了什么 | 证实方式 |
|---|---|---|---|
| 未授权 | 匿名 | 受保护路径仍返回数据 | 与登录响应内容一致 |
| 水平 | 同级 | 他人对象编号 | 读到/改到他人数据 |
| 垂直 | 低权 | 高权功能 | 低权完成高权操作 |

## 02 判断与分型

```text
去掉身份还能用吗？
 ├─ 能 → 未授权访问
 └─ 不能 → 换对象编号
      ├─ 读到他人数据 → 水平越权
      └─ 不能 → 换高权功能
           ├─ 低权成功 → 垂直越权
           └─ 拒绝 → 看多步/方法/参数
```

| 信号 | 含义 | 下一步 |
|---|---|---|
| 匿名 200 + 业务数据 | 无认证 | 记录路由 |
| A 会话读到 B 数据 | 无所有权检查 | 换 ID 批量验证 |
| 低权调用管理接口成功 | 无角色检查 | 找更多功能 |
| 前端隐藏按钮 | 只说明入口限制 | 直接调接口 |
| 改方法/参数后成功 | 授权在错误层 | 记录绕过 |
| 最后一步单独成功 | 状态未绑定 | 多步绕过 |

| 假阳性 | 原因 | 处理 |
|---|---|---|
| 200 但空数据 | 只返回模板 | 看正文/状态 |
| 读到自己的数据 | 服务端按会话取 | 换对象号 |
| 前端 403 | 只前端拦 | 直接请求 |
| 改 ID 返回登录页 | 会话失效 | 重新登录 |

## 03 利用阶梯

### L0 三组基线

**前提**：有登录/角色/对象接口。

**步骤**：
1. 准备匿名、同级 A/B、高权 C。
2. 各保存方法、路径、查询、体、Cookie/Authorization、响应。
3. 先原样重放，确认稳定。
4. 每次只改一个变量。

**成功标志**：三组响应可并排比较。

**失败分支**：会话不稳→先修登录；接口不明→抓前端请求。

### L1 未授权访问

**前提**：有受保护路由/接口。

**步骤**：
1. 去掉 Cookie/Authorization 重放。
2. 试直接访问管理页面/API。
3. 看静态资源/备份/调试接口。
4. 对比匿名与登录响应正文。

**成功标志**：匿名拿到业务数据/执行操作。

**失败分支**：返回登录→认证存在；再查授权。

### L2 水平越权（IDOR）

**前提**：请求里有对象编号/文件名/租户 ID。

**步骤**：
1. 用 A 会话请求自己的对象，记录 ID。
2. 换成 B 的 ID，其余不动。
3. 看响应是否 B 的数据/是否改到 B。
4. 试不可猜 ID 的来源：列表、邮件、导出、前端。

**成功标志**：A 会话读到/改到 B 的对象。

**失败分支**：服务端按会话取→换参数；ID 不可猜→找泄露。

### L3 垂直越权

**前提**：存在高权功能/接口。

**步骤**：
1. 用高权 C 触发功能，保存请求。
2. 换成低权 A 的会话，其他不变。
3. 看是否成功、数据是否变化。
4. 试方法覆盖/参数隐藏/角色字段。

**成功标志**：低权完成高权操作。

**失败分支**：路由拦→换接口/方法；业务拦→找参数绕过。

### L4 多步与跨域边界

**前提**：多步流程，或需要判断浏览器能否读响应。

**步骤**：
1. 去掉前几步，直接重放最后一步。
2. 改步骤顺序/重复提交/跳过验证。
3. CORS：看 `Allow-Origin` 是否反射 `Origin`，是否带 `Allow-Credentials: true`。
4. JSONP：`callback` 是否可控、是否返回敏感数据。
5. 记录“能发请求”和“能读响应”的区别。

**成功标志**：绕过流程/跨域读到数据。

**失败分支**：状态绑定→找令牌复用；CORS 严格→转 CSRF/XS-Leaks。

## 04 绕过与边界

| 限制 | 替代 | 示例 |
|---|---|---|
| 前端隐藏 | 直接调接口 | 抓包重放 |
| 路由拦截 | 换方法/路径大小写 | `POST`/`PUT` |
| 只查 URL | 参数/体里加角色 | `role=admin` |
| 只查 GET | 换 POST/JSON | 内容类型 |
| 对象 ID 校验 | 换租户/父对象 | `tenant`/`org` |
| 多步校验 | 跳步/重放 | 最后一步 |
| CORS 白名单 | 子域/`null` | 看反射 |

边界：同源策略拦的是**读响应**，不是发请求；`curl`/服务端没有同源限制；CORS 预检不是授权；JWT 可解码不等于可验签。

## 05 非典型入口

| 位置 | 示例 | 注意 |
|---|---|---|
| GraphQL | 直接查他人节点 | 看 resolver |
| 导出/报表 | 对象 ID | 批量越权 |
| 文件下载 | 文件名/路径 | 水平越权 |
| 邀请/分享 | 链接令牌 | 权限提升 |
| 租户头 | `X-Tenant-ID` | 多租户 |
| 移动 API | 旧版本接口 | 鉴权缺失 |
| WebSocket | 订阅他人频道 | 授权 |

## 06 差异速查

| 机制 | 作用 | 缺口 |
|---|---|---|
| Session Cookie | 服务端认身份 | 固定/可预测 |
| JWT | 声明身份 | 未验签/弱密钥 |
| `SameSite` | 跨站带 Cookie | 未写按 Lax |
| CORS | 浏览器读响应 | 反射 Origin+凭证 |
| JSONP | script 跨域 | callback 可控 |
| `X-Frame-Options` | 禁止嵌入 | 缺失可点击劫持 |

## 09 失败分支

| 现象 | 优先怀疑 | 处理 |
|---|---|---|
| 匿名返回登录 | 认证存在 | 查授权 |
| 换 ID 返回自己数据 | 按会话取 | 换参数 |
| 低权被拒 | 路由/业务拦 | 换方法/参数 |
| 前端 403 | 只前端 | 直接请求 |
| 多步跳不过 | 状态绑定 | 找令牌复用 |
| CORS 不反射 | 白名单 | 子域/null |
| 200 无数据 | 模板/空 | 看正文 |
