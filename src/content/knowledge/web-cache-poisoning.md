缓存题先分清两个方向：**缓存投毒**是把恶意内容写进共享缓存，让下一个用户中招；**缓存欺骗**是让缓存把用户的私有页面当成公共资源存下来，攻击者再读。判断顺序：缓存层 → 缓存键 → 未键控输入 → 响应差异。

> 只对本地题目或授权目标测试；投毒可能影响其他用户，先在隔离环境验证，不要在共享 CDN 上做破坏性测试。

## 00 30 秒速查

| 我要… | 先试… | 备注 |
|---|---|---|
| 判断有无缓存 | 两次请求看 `Age`/`X-Cache` | 带随机 `?cb=` 强制回源 |
| 找缓存键 | 改路径/查询/Host/Cookie 看命中 | `Vary` 说明参与键 |
| 找未键控头 | `X-Forwarded-Host`、`X-Original-URL` | 一次带毒、一次不带 |
| 确认投毒 | 带恶意头请求 → 不带该头再请求 | 响应保留 = 成功 |
| 投 XSS | `X-Forwarded-Host: evil.com` | 看绝对 URL/脚本地址 |
| 投重定向 | `X-Forwarded-Proto: http` | 看 `Location` |
| 投 DoS | 超长头/错误页 | 缓存错误响应 |
| 缓存欺骗 | `/account/profile.css` 变体 | 私有页被当静态资源 |
| 键注入 | `?cb=1&utm_source=...` | 键归一化、后端仍读 |
| 走私组合 | CL/TE 探测 | 见请求走私页 |

## 01 原理与成立条件

```text
请求 → CDN/反代查缓存键
          ├─ 命中 → 直接返回已存响应
          └─ 未命中 → 回源 → 按规则存响应
未进入键、但影响响应的输入 = 投毒面
```

| 条件 | 含义 | 不满足时 |
|---|---|---|
| 有共享缓存 | CDN/反代/框架缓存 | 只看浏览器缓存/无缓存 |
| 输入未进键 | 头/参数/路径变体不影响键 | 找键归一化差异 |
| 响应会反射/使用该输入 | 链接、脚本、重定向、错误页 | 换头/换页面 |
| 缓存可存储 | `Cache-Control` 允许、无 `Vary` 阻断 | 找静态后缀/欺骗 |

| 概念 | 写入 | 读取者 |
|---|---|---|
| 缓存投毒 | 攻击者写恶意响应 | 下一个访问者 |
| 缓存欺骗 | 受害者私有响应被缓存 | 攻击者 |

## 02 判断与分型

```text
响应有 Age/X-Cache 吗？
 ├─ 否 → 可能无共享缓存/只浏览器缓存
 └─ 是
    改查询/路径/头，缓存键怎么变？
    ├─ 头未进键 → 看响应是否反射该头
    │    ├─ 反射 → 投毒（XSS/重定向/DoS）
    │    └─ 不反射 → 换头/换页
    └─ 路径后缀影响缓存 → 缓存欺骗
         └─ 私有页 + 静态后缀 → 读他人数据
```

| 信号 | 含义 | 下一步 |
|---|---|---|
| `Age` 递增 | 命中共享缓存 | 继续 |
| `X-Cache: HIT` | CDN 标记 | 看键 |
| `Vary: User-Agent` | UA 参与键 | 换未键控头 |
| 带毒头后不带仍生效 | 已写入缓存 | 记录 |
| 私有页有 `public` | 可被共享缓存 | 试欺骗 |
| 路径后缀被忽略 | 路由/缓存解析不一致 | 试变体 |

| 假阳性 | 原因 | 处理 |
|---|---|---|
| 看到 `Age` 就认为可投毒 | 键包含该头 | 换头 |
| 带毒响应变了 | 只影响本次请求 | 不带该头复测 |
| 缓存命中但内容旧 | 正常过期 | 清缓存/换 URL |
| 私有页返回登录页 | 会话失效 | 重新登录 |

## 03 利用阶梯

### L0 确认缓存层与键

**前提**：目标前面有 CDN/反代/框架缓存。

**步骤**：
1. 连续两次请求同一 URL，看 `Age`/`X-Cache`/`CF-Cache-Status`。
2. 带随机 `?cb=123` 强制回源，确认可区分 HIT/MISS。
3. 分别改路径、查询、Host、Cookie，看哪些影响命中。
4. 看 `Vary`/`Cache-Control`。

**成功标志**：能稳定判断 HIT/MISS，并知道哪些输入进键。

**失败分支**：无共享缓存→转浏览器缓存/无缓存；全 MISS→缓存规则不缓存该页。

### L1 未键控头反射

**前提**：某个头未进键，但会影响响应。

**步骤**：
1. 试 `X-Forwarded-Host`、`X-Forwarded-Proto`、`X-Host`、`X-Original-URL`、`X-Rewrite-URL`。
2. 一次带恶意值，一次不带，比较响应体/头。
3. 看页面里的绝对 URL、`<script src>`、`Location`、错误信息。

**成功标志**：不带恶意头时响应仍保留恶意内容（已缓存）。

**失败分支**：头被剥离→换头；响应不反射→换页面/换输入。

### L2 投毒到 XSS / 重定向 / DoS

**前提**：未键控头能影响响应，且缓存会存储。

**步骤**：
1. XSS：`X-Forwarded-Host: evil.com`，看是否生成 `http://evil.com/app.js`。
2. 重定向：`X-Forwarded-Proto: http` + `Host`，看 `Location`。
3. DoS：超长头/触发 500，缓存错误页。
4. 用无头请求/换浏览器验证其他用户拿到毒化响应。

**成功标志**：下一个无恶意头的请求拿到攻击者内容/错误页。

**失败分支**：缓存不存该响应→找静态后缀/降低 `Cache-Control` 限制；头被规范化→换头。

### L3 缓存欺骗

**前提**：私有页可被缓存，CDN 与后端对路径后缀解析不一致。

**步骤**：
1. 登录访问 `/account/profile`，确认私有数据。
2. 试 `/account/profile.css`、`;.css`、`%2f.css`、`/.css`、`%00.css`、`?x=.css`。
3. 看响应是否仍是私有数据，且 `Cache-Control: public`/`Age` 增加。
4. 退出/换浏览器请求同一变体，看能否读到上一个人的数据。

**成功标志**：未登录请求变体拿到他人私有数据。

**失败分支**：CDN 按完整路径缓存→换后缀；后端 404→换分隔符/编码。

### L4 键注入与走私组合

**前提**：缓存键归一化与后端解析不一致，或前端会复用连接。

**步骤**：
1. 试 `?cb=1&utm_source=<payload>`，看缓存键是否去掉 `utm_*` 而后端仍读。
2. 试参数顺序/大小写/重复参数，看是否命中同一键。
3. 用 CL/TE 走私把第二个请求投进缓存（见请求走私页）。
4. 验证下一个用户收到毒化响应。

**成功标志**：键相同、响应不同，且可稳定复现。

**失败分支**：键严格→回到 L1；走私被阻断→单请求投毒。

## 04 绕过与边界

| 限制 | 替代 | 示例 |
|---|---|---|
| 头被剥离 | 换未键控头 | `X-Host`/`X-Forwarded-*` |
| `Vary` 覆盖 | 找未列出的头 | UA/Referer |
| 动态页不缓存 | 静态后缀欺骗 | `.css`/`.js`/`.jpg` |
| 路径归一化 | 分隔符/编码 | `;`/`%2f`/`%00` |
| 缓存键含查询 | 键注入 | `utm_*`/重复参数 |
| 缓存不存错误 | 找可缓存状态码 | 301/404 |
| CDN 清缓存 | 换 URL/参数 | 新键 |

边界：投毒影响共享缓存，可能波及真实用户；只在授权环境验证，验证后清理缓存。

## 05 非典型入口

| 位置 | 示例 | 注意 |
|---|---|---|
| `X-Forwarded-Host` | 绝对 URL/脚本 | 最常见 |
| `X-Original-URL` | 路由覆盖 | 前端/后端不一致 |
| `User-Agent`/`Referer` | 回显页 | 存储型 |
| Cookie 未键控 | 私有内容 | 缓存给他人 |
| 路径后缀 | `.css`/`.js` | 缓存欺骗 |
| 查询归一化 | `utm_*`/顺序 | 键注入 |
| 错误页 | 500/404 | DoS/信息泄露 |
| 重定向 | `Location` | 开放重定向 |

## 06 差异速查

| 层 | 标记/行为 | 影响 |
|---|---|---|
| Cloudflare | `CF-Cache-Status` | HIT/MISS/DYNAMIC |
| Fastly | `X-Cache`/`X-Cache-Hits` | 命中次数 |
| Akamai | `X-Cache`/`True-Client-IP` | 边缘/回源 |
| Varnish | `Age`/`X-Cache` | 默认键含 Host |
| Nginx | `X-Cache-Status` | 需配置 |
| 浏览器 | `Cache-Control`/`ETag` | 只影响本地 |

## 09 失败分支

| 现象 | 优先怀疑 | 处理 |
|---|---|---|
| 两次都 MISS | 不缓存/规则 | 换静态资源/后缀 |
| `Age` 不增 | 没命中 | 换 URL/清缓存 |
| 带毒头无效 | 头被剥离/进键 | 换头/看 Vary |
| 响应变了但不持久 | 只影响本次 | 不带头复测 |
| 缓存欺骗 404 | 路径不被接受 | 换分隔符/编码 |
| 私有页不缓存 | `private/no-store` | 找静态后缀/其他页 |
| 投毒影响自己 | 缓存共享 | 换隔离环境 |
| 清不掉缓存 | CDN 规则 | 换键/等过期 |
