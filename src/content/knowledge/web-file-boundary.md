文件类题看起来都是“路径不对”或“类型不对”，实际要分开四件事：客户端申报的类型、服务端保存的名字、进程真正打开的路径、解析器是否再取别的资源。

> 只在本地题目或授权环境对照；用普通图片或题目给定样本确认保存路径，不要把可执行内容放进样本。

## 00 30 秒速查

| 我要… | 先看… | 备注 |
|---|---|---|
| 上传落到哪 | 上传后访问 URL | 确认目录/文件名 |
| 校验在哪层 | 前端/后缀/MIME/文件头 | 逐层记录 |
| 后缀绕过 | 大小写/多后缀/点空格 | 看服务器映射 |
| 文件头 | JPEG `FF D8 FF`、PNG `89 50 4E 47` | 只证明开头 |
| 目录配置 | `.htaccess`/`.user.ini` | 看 AllowOverride |
| 读文件 | 下载/导出/预览参数 | 拼接后路径 |
| 包含 | `include` + 包装器 | 看 `allow_url_include` |
| 无直接入口 | session/日志/phar | 包含触发 |
| 解析差异 | IIS/Apache/Nginx | 看 `Server` |

## 01 原理与成立条件

```text
上传：字节 → 校验层 → 保存路径 → Web 访问/解析
包含：参数 → include/require → 本地文件/包装器/远程
读取：参数 → fopen/file_get_contents → 拼接路径
```

| 条件 | 含义 | 不满足时 |
|---|---|---|
| 输入进入路径/包含 | 参数可控 | 找下载/预览 |
| 校验可绕过 | 后缀/MIME/文件头 | 换层/换入口 |
| 落盘目录可访问 | Web 根/可执行 | 找包含/其他目录 |
| 解析器会执行 | 扩展名映射 | 换后缀/换服务器 |

| 名字 | 谁提供 | 用途 |
|---|---|---|
| 原始文件名 | 浏览器/多部分正文 | 显示或拼路径 |
| `Content-Type` | 客户端头 | 只是声明 |
| 保存路径 | 服务端代码 | 决定落点/执行 |

## 02 判断与分型

```text
有上传点吗？
 ├─ 有 → 逐层看校验（前端/后缀/MIME/文件头/重命名）
 │    └─ 落盘后可访问？→ 直接执行/包含
 └─ 无 → 找读取/包含/下载
      ├─ 参数拼路径 → 路径穿越/任意读
      ├─ include → 包装器/远程/session/日志
      └─ 文件函数 + phar → 反序列化
```

| 信号 | 含义 | 下一步 |
|---|---|---|
| 上传 200 但访问 404 | 路径/权限 | 找真实保存名 |
| 返回文件名随机 | 服务端重命名 | 看扩展名是否保留 |
| 只拦前端 | 直接改包可绕 | 重放 |
| `getimagesize` 通过 | 文件头对 | 图片马/二次渲染 |
| 包含报路径 | 警告泄露路径 | 记基础目录 |
| `allow_url_include` 报错 | 配置关闭 | 用 `php://filter` |
| session 文件可包含 | 进度写入 | 伪造键值 |

| 假阳性 | 原因 | 处理 |
|---|---|---|
| 上传成功就认为能执行 | 目录不解析 | 看服务器配置 |
| 文件头对就认为纯图片 | 后面可附加 | 看解析器 |
| 读到报错路径 | 只是信息泄露 | 看正文文件内容 |
| 包含无输出 | 脚本只赋值 | 用 `phpinfo`/编码读源码 |

## 03 利用阶梯

### L0 画清校验与落点

**前提**：有上传/下载/包含入口。

**步骤**：
1. 上传普通图片，确认访问 URL 与保存名。
2. 按代码顺序列校验层：前端、后缀、MIME、文件头、重命名、目录权限。
3. 下载/预览接口记录基础目录与参数拼接。
4. 包含接口确认是白名单键还是原样路径。

**成功标志**：知道文件落在哪、哪层校验真正生效。

**失败分支**：无上传→转读取/包含；全层严格→找配置/二次渲染。

### L1 上传绕过

**前提**：上传点存在，但后缀/MIME 受限。

**步骤**：
1. 前端校验：直接改包/禁用 JS。
2. 后缀：大小写 `.Php`、多后缀 `a.php.jpg`、末尾点/空格（Windows）。
3. MIME：改 `Content-Type: image/jpeg`。
4. 文件头：加 `GIF89a`/JPEG/PNG 魔数。
5. 目录配置：`.htaccess`（Apache）或 `.user.ini`（PHP）。

**成功标志**：文件落盘且能被解析/包含。

**失败分支**：服务端重命名为随机名→找包含/竞争；目录不解析→换目录/配置。

### L2 文件包含

**前提**：`include`/`require` 参数可控。

**步骤**：
1. 试本地路径与 `../`。
2. `php://filter/convert.base64-encode/resource=index.php` 读源码。
3. 远程包含需 `allow_url_include=On`，试 `data://`/`http://`。
4. `phar://` 触发反序列化；`zip://` 读包内文件。
5. 包含日志/session 时先确认路径。

**成功标志**：读到源码/执行代码/触发反序列化。

**失败分支**：协议被禁→本地文件/日志；路径拼接→截断/编码。

### L3 session / 日志 / 竞争

**前提**：不能直接上传可执行文件，但能写内容到可包含文件。

**步骤**：
1. session：`PHP_SESSION_UPLOAD_PROGRESS` 写入文件名，包含 `sess_<id>`。
2. 日志：UA/Referer 写 PHP 代码，包含 access.log。
3. 竞争：上传后删除前访问，或先写临时目录再移动。
4. 二次渲染：图片库重编码，找保留附加数据的位置。

**成功标志**：包含后执行/读到数据。

**失败分支**：session 路径不可知→读配置/报错；日志格式转义→换字段。

### L4 服务器解析与组合

**前提**：文件已上传，但扩展名/路径不被执行。

**步骤**：
1. 看 `Server` 确认 IIS/Apache/Nginx。
2. IIS 6：`.asp` 目录/分号截断；IIS 7+/Nginx：`cgi.fix_pathinfo`。
3. Apache：多段扩展名与 `AddHandler`/`FilesMatch`。
4. 组合：上传+包含、phar+文件函数、SSRF+FastCGI。

**成功标志**：在解析差异下执行/读取。

**失败分支**：配置已修→换目录/换协议；无解析→转反序列化/SSRF。

## 04 绕过与边界

| 限制 | 替代 | 示例 |
|---|---|---|
| 前端后缀 | 改包 | 直接 POST |
| 后缀黑名单 | 大小写/多后缀/点空格 | `.Php`、`a.php.jpg` |
| MIME | 改 `Content-Type` | `image/jpeg` |
| 文件头 | 加魔数 | `GIF89a` + 代码 |
| 重命名 | 包含/竞争 | 随机名也可包含 |
| 目录不解析 | `.htaccess`/`.user.ini` | 看 AllowOverride |
| `allow_url_include=Off` | `php://filter` | 读源码 |
| `phar://` 被拦 | 大小写/编码 | `PHAR://` |

边界：`getimagesize` 只看开头；`.user.ini` 不把 `.jpg` 变 PHP；空字节截断仅 PHP <5.3.4；二次渲染会丢附加数据。

## 05 非典型入口

| 位置 | 示例 | 注意 |
|---|---|---|
| 下载接口 | `file=../../etc/passwd` | 路径穿越 |
| 导出/报表 | 模板路径 | 包含 |
| 头像/附件 | 上传后包含 | 组合 |
| 日志 | UA 写码 | 包含日志 |
| session | upload_progress | 包含 session |
| phar | 图片马 metadata | 文件函数 |
| 压缩包 | `zip://` | 包内路径 |
| 对象存储 | 键名/公开读 | 云场景 |

## 06 差异速查

| 环境 | 规则 | 边界 |
|---|---|---|
| IIS 6 | `.asp` 目录/分号截断 | 仅这一代 |
| IIS 7+/Nginx | `cgi.fix_pathinfo` | PHP CGI 配置 |
| Apache | 多段扩展名/`AddHandler` | 看 `FilesMatch` |
| PHP `allow_url_fopen` | 默认开 | `fopen` 类 |
| PHP `allow_url_include` | 默认关 | `include` 远程 |
| `phar.readonly` | 默认开 | 只阻止创建 |

## 09 失败分支

| 现象 | 优先怀疑 | 处理 |
|---|---|---|
| 上传 404 | 路径/权限 | 找真实名 |
| 后缀被改 | 服务端重命名 | 包含/竞争 |
| 文件头被拒 | 魔数不对 | 换图片/加头 |
| 包含无输出 | 脚本无回显 | `php://filter` |
| 远程包含失败 | 配置关闭 | 本地文件 |
| `.htaccess` 无效 | `AllowOverride None` | 换 `.user.ini` |
| 解析不执行 | 目录/映射 | 看服务器配置 |
| 读不到文件 | 基础目录 | 报错/编码 |
