WAF 绕过不是“背 payload”，而是**判断拦截发生在哪一层**：浏览器到 CDN、CDN 到源站、源站到应用代码，每层的规则与解析都不同。先定位，再变形。

> 只对本地题目或授权环境测试；高频变异会被封 IP，控制速率并记录基线。

## 00 30 秒速查

| 我要… | 先看… | 备注 |
|---|---|---|
| 有没有 WAF | `Server`/拦截页/403 突变 | 先指纹 |
| 哪段被拦 | 逐段拆分 | 最小触发片段 |
| SQL 空格 | `/**/`/`%09`/`%0a` | 看 DBMS |
| SQL 关键字 | 注释/大小写/等价函数 | 方言不同 |
| XSS 标签 | 换标签/事件/编码 | 看上下文 |
| RCE 空格 | `${IFS}`/Tab/重定向 | 看 shell |
| 协议层 | `X-Forwarded-*`/`X-Original-URL` | 前后端差异 |
| 分块 | `Transfer-Encoding: chunked` | 打乱关键字 |
| 代码级 | `str_replace` 只替换一次 | 双写/递归 |

## 01 原理与成立条件

```text
客户端 → CDN/WAF → 反代 → 应用代码
           ├─ 正则/规则匹配
           ├─ 协议规范化
           └─ 自写过滤
绕过 = 让 WAF 看到的 与 后端执行的 不一致
```

| 条件 | 含义 | 不满足时 |
|---|---|---|
| 有拦截 | 403/406/挑战页 | 无 WAF |
| 规则可探 | 最小片段 | 盲变异 |
| 解析差异 | 编码/协议/方言 | 语法绕过 |
| 后端可执行 | 变形后仍有效 | 换等价语法 |

## 02 判断与分型

```text
正常请求 200，攻击请求 403？
 ├─ 是 → WAF/代码过滤
 └─ 否 → 可能没拦/换 payload
逐段拆：
 ├─ 关键字触发 → 语法变形
 ├─ 符号触发 → 编码/等价
 ├─ 长度触发 → 分块/分段
 └─ 头触发 → 协议绕过
看响应：
 ├─ WAF 页 → 网络层
 ├─ 应用报错 → 代码层
 └─ 连接重置 → 设备
```

| 信号 | 含义 | 下一步 |
|---|---|---|
| 403 固定页 | 网络 WAF | 找规则 |
| 200 但参数被删 | 代码过滤 | 双写/编码 |
| 只拦关键字 | 正则 | 注释/等价 |
| 只拦长度 | 限制 | 分块/分段 |
| 换头就过 | 协议层 | 记录头 |
| 换 IP 就过 | IP 黑名单 | 看 XFF |
| 分块后过 | 设备不重组 | chunked |

| 假阳性 | 原因 | 处理 |
|---|---|---|
| 403 是应用权限 | 非 WAF | 看登录 |
| 200 但无效果 | 后端未执行 | 验证语义 |
| 一次通过 | 规则未覆盖 | 重复确认 |
| 被封 IP | 高频 | 降速/换出口 |

## 03 利用阶梯

### L0 基线与定位

**前提**：有正常请求与一个明显攻击 payload。

**步骤**：
1. 记录正常请求的状态码/长度/头。
2. 发攻击 payload，记录拦截页/状态。
3. 逐段拆分：关键字、符号、长度、位置。
4. 找触发规则的最小片段。

**成功标志**：知道哪一层、哪一段被拦。

**失败分支**：全放行→无 WAF；全 403→换出口/看权限。

### L1 SQL/XSS 语法变形

**前提**：网络/代码层按关键字拦。

**步骤**：
1. SQL 空格：`/**/`、`%09`、`%0a`、`()`。
2. 关键字：大小写、`/*!50000union*/`、`un/**/ion`。
3. 等号/逗号：`like`/`between`/`substr from`。
4. XSS：换标签（`svg`/`img`）、事件、无引号、HTML 实体。
5. 按上下文选，不混用。

**成功标志**：变形后语义等价且通过。

**失败分支**：仍拦→L2 协议层；语义变→换等价语法。

### L2 协议头与分块

**前提**：WAF 只看 URL/部分头，或前后端路由不一致。

**步骤**：
1. `X-Forwarded-For`/`X-Real-IP` 绕 IP 黑名单。
2. `X-Original-URL`/`X-Rewrite-URL` 让前端按 `/` 放行。
3. `X-Forwarded-Host` 影响白名单/生成 URL。
4. `Transfer-Encoding: chunked` 分块拆关键字。
5. HTTP/2 伪头/重复 `content-length`；走私见专页。

**成功标志**：换头/分块后到达后端。

**失败分支**：头被覆盖→换头；分块被重组→H2/走私。

### L3 代码级过滤

**前提**：应用自己写过滤（非网络设备）。

**步骤**：
1. `str_replace('select','')`：双写 `selselectect`。
2. `preg_match` 无 `s`：换行拆关键字。
3. `strip_tags`：事件属性/`<img>`。
4. `addslashes`：宽字节/二次注入。
5. `in_array` 松散：`0`/`true`。

**成功标志**：过滤后仍执行。

**失败分支**：递归/白名单→换入口；统一字符集→换编码。

### L4 上传/长度/速率

**前提**：WAF 拦上传内容/长 payload/高频。

**步骤**：
1. 文件名：大小写/双写/尾随点/`::$DATA`。
2. MIME：`image/png`/multipart 边界。
3. 内容：图片马/EXIF/二次渲染不变区。
4. 分块上传/分段写入。
5. 降速/换出口/换会话，避免封禁。

**成功标志**：文件落盘/内容通过。

**失败分支**：内容杀毒→换格式；封 IP→停手记录。

## 04 绕过与边界

| 层 | 限制 | 绕过 |
|---|---|---|
| SQL | 空格/关键字 | 注释/等价/编码 |
| XSS | 标签/事件 | 换标签/上下文 |
| RCE | 空格/斜杠 | IFS/通配/变量 |
| 上传 | 后缀/MIME/内容 | 双写/图片马 |
| 协议 | 路径/头 | `X-Original-URL` |
| 传输 | 关键字 | chunked/H2 |
| 代码 | 单次替换 | 双写/递归 |

边界：WAF 可能只记录不拦（观察模式）；分块需后端支持；H2 伪头依实现；高频测试会封 IP；代码过滤的绕过要以源码为准。

## 05 非典型入口

| 位置 | 示例 | 注意 |
|---|---|---|
| Header | UA/Referer/XFF | 规则覆盖少 |
| Cookie | 序列化/Base64 | 解码后 |
| 文件名 | 上传 | 后缀 |
| JSON | 嵌套/Unicode | 解析器 |
| 路径 | 编码/分号 | 规范化 |
| 分块 | 正文 | 设备重组 |

## 06 差异速查

| DBMS | 注释/拼接 | 注意 |
|---|---|---|
| MySQL | `/*! */`、`concat` | `div` |
| PostgreSQL | `::`、`$$` | 大小写 |
| SQL Server | `;`、`waitfor` | 堆叠 |
| Oracle | `||`、`dual` | 方言 |

| 设备 | 特征 | 绕过 |
|---|---|---|
| 云 WAF | 挑战 Cookie | 协议/编码 |
| 反代 | `X-Original-URL` | 路由差 |
| 代码 | 报错/截断 | 双写 |

## 09 失败分支

| 现象 | 优先怀疑 | 处理 |
|---|---|---|
| 全 403 | IP/权限 | 换出口/登录 |
| 变形仍拦 | 规则更强 | 协议层 |
| 通过但无效 | 后端未执行 | 验证语义 |
| 被封 | 高频 | 降速/停 |
| 分块失败 | 后端重组 | H2/走私 |
| 上传被拒 | 内容检测 | 图片马 |
