## 01 先确认是不是同一组参数

收集 `n`、`e`、`c`，写清进制、位长、字节序和是否来自同一次运行。先检查 `0 ≤ c < n`、`1 < e < n`，再看是否有多个模数或多份密文。若题目给出了 `p`、`q`，要先证实 `p*q=n` 且两者为素数，再按题目采用的密钥定义计算私钥指数；不能把任意两个因子直接塞进 `φ(n)=(p-1)(q-1)`。

## 02 按前提选择路线

| 线索 | 必须先验证的条件 | 下一步 |
|---|---|---|
| 一因子很小或两因子相近 | 分解结果相乘等于 `n`，因子确为素数 | 求私钥并代回密文 |
| 多个公钥共享 `n` | 确认密文来自**相同明文与填充方式**，检查指数互素 | 才考虑共模关系 |
| `e` 较小 | 明文幂是否没有跨过模数，是否存在填充 | 不满足条件不能直接开整数根 |
| 私钥指数或因子部分泄露 | 泄露的是高位/低位、位数与边界是否可靠 | 再评估对应数学方法 |
| 结构化素数或连续素数 | 生成关系是否真实约束 `p,q` | 用关系缩小候选并验证 |

`e=3`、`p` 很接近 `q` 等都只是筛选线索，不是攻击成功证明。若题目把 RSA 与 AES、异或或编码串联，解出 RSA 层后还要继续按实际字节链处理。

## 03 用可复核等式验证

已知正确素因子时，可用下面的**小数值演示**检查代码流程。正式题目要换成自己的参数，并保留原始密文与输出长度。

```python
from math import gcd

p, q, e, m = 61, 53, 17, 65
n = p * q
phi = (p - 1) * (q - 1)
assert gcd(e, phi) == 1
d = pow(e, -1, phi)
c = pow(m, e, n)
assert pow(c, d, n) == m
print(n, c, d)
```

最后还需确认候选明文与题目加密流程匹配：重新加密应得到同一 `c`；转字节时明确模数长度，避免丢失前导零；再核对填充、编码或校验值。取证题若已有私钥文件、内存残留或密钥派生记录，应优先从证据还原密钥用途，而不是无条件尝试分解。
