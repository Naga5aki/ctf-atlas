Web 里的密码学题通常不是“破解算法”，而是**误用模式**：ECB 暴露结构、CBC 可翻转、MAC 与密文拼接、随机数可预测。先判断模式，再套对应的攻击。

> 只对本地题目或授权环境测试；Padding Oracle 会产生大量请求，注意速率。

## 00 30 秒速查

| 线索 | 判断 | 攻击 |
|---|---|---|
| 密文长 16 的倍数 | AES/DES 分组 | 看模式 |
| 相同明文块→相同密文块 | ECB | 重排/逐字节 |
| 每块不同、首块随 IV 变 | CBC | 比特翻转 |
| 有 `iv` 参数 | CBC/CTR | 改 IV |
| 填充错误可区分 | Padding Oracle | 逐字节解密 |
| 签名=`hash(secret||msg)` | 长度扩展 | hashpump |
| `mt_rand`/时间戳 | 随机数 | 预测 |
| `e=3`/小 `n` | RSA 弱用法 | 开方/分解 |

## 01 原理与成立条件

```text
明文 → 分组密码（ECB/CBC/CTR） → 密文
          ├─ ECB：块独立
          ├─ CBC：C_i = E(P_i XOR C_{i-1})
          └─ MAC：hash(secret||msg)
随机数 → seed → 输出 → 预测
RSA → n/e/d → 弱参数
```

| 条件 | 含义 | 不满足时 |
|---|---|---|
| 能看到密文 | 响应/Cookie | 找泄露 |
| 能控制明文 | 拼接/前缀 | 逐字节/翻转 |
| 错误可区分 | 填充/长度/状态 | 盲打 |
| 参数弱 | 小 n/小 e/时间种子 | 换攻击 |

## 02 判断与分型

```text
密文像分组密码吗？
 ├─ 16 倍数 → 对比两块明文
 │    ├─ 相同块相同 → ECB
 │    └─ 不同 → CBC/CTR
 ├─ 有 iv → CBC
 └─ 流式 → CTR/异或
有签名吗？
 ├─ hash(secret||msg) → 长度扩展
 ├─ 密文+MAC → 看拼接
 └─ 随机 token → 预测
```

| 信号 | 含义 | 下一步 |
|---|---|---|
| 相同块重复 | ECB | 重排 |
| 首块随 IV 变 | CBC | 翻转 |
| 填充错误 500 | Oracle | 逐字节 |
| 改密文后 MAC 仍过 | 拼接/扩展 | 长度扩展 |
| token 随秒变 | 时间种子 | 预测 |
| `n` 很小 | RSA | 分解 |

| 假阳性 | 原因 | 处理 |
|---|---|---|
| 块重复 | 明文本身重复 | 控制输入 |
| 填充错误 | 其他校验 | 看响应差异 |
| 随机 token | 强随机 | 换入口 |
| 签名过 | 未校验 | 换字段 |

## 03 利用阶梯

### L0 识别算法与模式

**前提**：有密文/签名/随机 token。

**步骤**：
1. 解码 Base64/Hex，看长度。
2. 构造两条只差一字节的明文，对比密文块。
3. 看是否有 `iv`/`key`/`nonce`。
4. 看签名与密文的拼接方式。

**成功标志**：确定 ECB/CBC/CTR/哈希/RSA。

**失败分支**：看不到密文→找接口；算法不明→长度/块对比。

### L1 ECB 重排与逐字节

**前提**：ECB，且明文含可控/敏感块。

**步骤**：
1. 块重排：把 `admin` 块移到 `role=` 后。
2. 逐字节：构造 `A*15+guess` 对齐块边界。
3. 与已知前缀的密文块比较，匹配即猜中。
4. 逐块推进，恢复 secret。

**成功标志**：权限字段改变/恢复明文。

**失败分支**：有随机前缀→先对齐；非 ECB→L2。

### L2 CBC 比特翻转

**前提**：CBC，能改密文/IV，明文可预测。

**步骤**：
1. 目标块 `P_i`，改前一块 `C_{i-1}` 对应字节。
2. 差值 = 原字节 XOR 目标字节。
3. 第一块改 IV。
4. 接受前一块变乱码，只要目标字段生效。

**成功标志**：明文目标字段改变且服务端接受。

**失败分支**：有 MAC→先过 MAC；乱码影响解析→换块/换位置。

### L3 Padding Oracle

**前提**：解密后“填充错误”与其他错误可区分。

**步骤**：
1. 取 `C_{n-1}`/`C_n`，遍历 `C_{n-1}` 末字节。
2. 找到合法填充（`0x01`）的响应。
3. 反推 `P_n` 末字节，再构造 `0x02 0x02`。
4. 逐字节解完整块，再向前一块推进。
5. 过滤 `0x02 0x02` 等误报。

**成功标志**：逐字节恢复明文。

**失败分支**：响应不可区分→换 oracle（长度/时间）；限流→降速。

### L4 长度扩展 / 随机数 / RSA

**前提**：MAC 拼接、弱随机或 RSA 弱参数。

**步骤**：
1. 长度扩展：`hashpump -s <hash> -d <data> -a <append> -k <len>`。
2. `mt_rand`：收集输出，`php_mt_seed` 反推种子。
3. Python `random`：624 个 32 位输出克隆状态。
4. RSA：小 `n` 分解；`e=3` 开方；共模/小 `d`。
5. 只验证到读文件/管理员。

**成功标志**：伪造签名/预测 token/解出明文。

**失败分支**：SHA-3/BLAKE2→换攻击；随机强→换入口；RSA 参数强→找泄露。

## 04 绕过与边界

| 限制 | 替代 | 示例 |
|---|---|---|
| 有 MAC | 长度扩展/先过 MAC | `hash(secret||msg)` |
| 随机前缀 | 块对齐 | 先填满 |
| 填充 Oracle 限流 | 降速/换 oracle | 长度/时间 |
| Base64 | 解码改字节再编码 | 注意 `=` |
| 强随机 | 找种子泄露 | 时间/进程 |
| RSA 大 n | 共模/小指数 | 看参数 |

边界：ECB 逐字节需要可控前缀；CBC 翻转会破坏前一块；Padding Oracle 依赖错误区分；长度扩展只对 Merkle–Damgård；SHA-3/BLAKE2 不受影响。

## 05 非典型入口

| 位置 | 示例 | 注意 |
|---|---|---|
| Cookie | 加密会话 | 翻转/重放 |
| 参数 | `data=`/`token=` | 解码 |
| 文件名 | 加密路径 | 块对齐 |
| 前端 | 硬编码 key/iv | 逆向 |
| 验证码 | `mt_rand` | 预测 |
| 邀请码 | 时间种子 | 枚举 |
| 下载 | 加密文件 | 已知明文 |

## 06 差异速查

| 模式 | 特征 | 攻击 |
|---|---|---|
| ECB | 块重复 | 重排/逐字节 |
| CBC | 链式、IV | 翻转/Oracle |
| CTR | 流式、nonce | 重用/异或 |
| GCM | 认证 | nonce 重用 |
| MD5/SHA1 | 长度扩展 | hashpump |
| SHA-3 | 海绵 | 不适用 |

## 09 失败分支

| 现象 | 优先怀疑 | 处理 |
|---|---|---|
| 块不重复 | 非 ECB | 换 CBC |
| 翻转后解析失败 | 前块乱码 | 换位置 |
| Oracle 无差异 | 错误统一 | 换通道 |
| 长度扩展失败 | 算法/长度 | 换 hash |
| 预测不中 | 种子/截断 | 多组输出 |
| RSA 解不出 | 参数 | 换攻击 |
