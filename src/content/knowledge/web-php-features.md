PHP 题“代码很简单但就是过不去”，多数不是思路问题，而是没把**比较规则、类型转换、正则边界**当回事。这一页按“看到什么代码 → 试什么”组织。

> 只对本地题目或授权环境测试；伪协议与变量覆盖可能读到敏感文件，注意范围。

## 00 30 秒速查

| 看到… | 先试… | 备注 |
|---|---|---|
| `==` 比较 | `0e` 哈希/数组 | 看两边类型 |
| `md5($x)==md5($y)` | `a[]=1&b[]=2` | 数组返回 null |
| `strcmp`/`in_array` | 数组/松散比较 | 第三参数是否 true |
| `switch` | `1abc`/`0e` | 松散匹配 |
| `intval`/`is_numeric` | 进制/溢出/空格 | 版本差异 |
| `extract`/`$$` | 覆盖同名变量 | 看键名 |
| `include` | `php://filter` | 先读源码 |
| `preg_match` | 换行/数组/回溯 | 返回值 0/1/false |
| 字母数字过滤 | 自增/取反 | 看版本 |

## 01 原理与成立条件

```text
用户输入 → PHP 表达式/函数
             ├─ 松散比较 → 类型转换
             ├─ 数组参数 → 函数返回 null/false
             ├─ 变量名可控 → 覆盖
             └─ 文件函数 → 伪协议
```

| 条件 | 含义 | 不满足时 |
|---|---|---|
| 输入进入比较/函数 | 参数可控 | 找其他入口 |
| 类型可操纵 | 数组/字符串/数字 | 换绕过 |
| 版本有差异 | PHP 5/7/8 | 先确认版本 |
| 配置允许 | `allow_url_include` 等 | 换协议/换路径 |

## 02 判断与分型

```text
代码在比较什么？
 ├─ 哈希/字符串 → 0e/数组/真实碰撞
 ├─ 数字 → 进制/溢出/精度
 ├─ 变量名 → 变量覆盖
 ├─ 文件路径 → 伪协议/截断
 └─ 正则 → 换行/数组/回溯
函数返回什么？
 ├─ null/false → 用数组触发
 └─ 0/1 → 注意 == false 与 ! 的差异
```

| 信号 | 含义 | 下一步 |
|---|---|---|
| `==` 且两边可控 | 松散比较 | 0e/数组 |
| `===` | 严格 | 真实碰撞/类型相同 |
| `md5(array)` 警告 | 返回 null | 双数组 |
| `strcmp` 返回 null | 数组绕过 | `a[]=1` |
| `in_array` 无第三参 | 松散 | `0`/`true` |
| `extract($_GET)` | 变量覆盖 | 同名参数 |
| 文件函数报协议错 | 伪协议可用 | `php://filter` |
| 正则 `$` 匹配换行 | `%0a` | 末尾换行 |

| 假阳性 | 原因 | 处理 |
|---|---|---|
| 0e 不生效 | 用了 `===` | 换碰撞/数组 |
| 数组绕过失败 | 函数不返回 null | 换函数 |
| `intval` 结果不符 | 版本/进制 | 本机验证 |
| 伪协议被禁 | `allow_url_include=Off` | 用 `php://filter` |
| 正则绕过无效 | 用了 `D` 修饰符 | 换思路 |

## 03 利用阶梯

### L0 确认比较与类型

**前提**：有输入进入 `if`/函数参数。

**步骤**：
1. 读代码确认 `==`/`===`、函数、版本。
2. 输入不同类型：字符串、数字、数组、`null`。
3. 看报错/分支变化。

**成功标志**：知道哪条分支由类型控制。

**失败分支**：全严格→找碰撞/其他入口；无回显→盲测。

### L1 哈希与数组绕过

**前提**：`md5`/`sha1`/`strcmp` 等结果进入松散比较。

**步骤**：
1. `0e` 哈希：`a=240610708&b=QNKCDZO`。
2. 数组：`a[]=1&b[]=2`，让两边都返回 `null`。
3. `strcmp`：`a[]=1`。
4. `in_array`：试 `0`、`true`、`"1"`。

**成功标志**：无需真实原像即通过比较。

**失败分支**：`===`→真实碰撞/数组不适用；函数报错→换参数。

### L2 数字、变量覆盖与函数边界

**前提**：代码用 `intval`/`is_numeric`/`extract`/`$$`。

**步骤**：
1. `intval`：试 `0x1A`、`1e3`、空格、超长数字。
2. `is_numeric`：试 `"1 "`、`"1e3"`、`"0x1A"`。
3. `extract($_GET)`：提交同名变量覆盖。
4. `parse_str` 无第二参数：污染当前作用域。

**成功标志**：绕过数值校验/覆盖关键变量。

**失败分支**：`EXTR_SKIP`→换键名；严格类型→换入口。

### L3 伪协议与文件

**前提**：`include`/`file_get_contents` 等接受用户路径。

**步骤**：
1. `php://filter/convert.base64-encode/resource=index.php` 读源码。
2. `php://input`/`data://` 需 `allow_url_include=On`。
3. `phar://` 触发反序列化（见反序列化页）。
4. `zip://`/`phar://` 读压缩包内文件。

**成功标志**：读到源码/执行代码/触发反序列化。

**失败分支**：协议被禁→`file://`/相对路径；路径拼接→截断/编码。

### L4 正则与历史特性

**前提**：过滤用 `preg_match` 或老版本函数。

**步骤**：
1. `$` 末尾换行：`flag%0a`。
2. 数组让 `preg_match` 返回 false，`!preg_match` 为真。
3. 超长字符串触发回溯限制（`pcre.backtrack_limit`）。
4. 老版本：`preg_replace /e`、`assert(string)`、`create_function`。
5. 字母数字过滤：自增 `'a'++`、取反构造。

**成功标志**：过滤条件下仍通过/执行。

**失败分支**：`D` 修饰符/严格类型→换入口；版本已修→换特性。

## 04 绕过与边界

| 限制 | 替代 | 示例 |
|---|---|---|
| `===` | 真实碰撞/同类型 | 数组不适用 |
| 0e 被禁 | 数组/null | `a[]=1` |
| `extract` 安全 | `$$`/`parse_str` | 看作用域 |
| `allow_url_include=Off` | `php://filter` | 读源码 |
| 关键字过滤 | 编码/拼接/自增 | `'a'++` |
| 正则 `$` | 末尾换行 | `%0a` |
| 长度限制 | 分步/短变量 | 见 RCE 页 |

边界：PHP 8 收紧了字符串与数字比较；`assert` 不再执行字符串；自增行为有弃用提示。版本不同先本机验证。

## 06 差异速查

| 表达式/函数 | PHP 7 | PHP 8 |
|---|---|---|
| `"abc" == 0` | true | false |
| `"" == 0` | true | false |
| `assert(string)` | 执行 | 不执行 |
| `preg_replace /e` | 已移除 | 已移除 |
| `create_function` | 可用（<7.2） | 移除 |
| 自增非数字串 | 可用 | 可用但弃用提示 |
