像素点合成属于非图片格式的像素数据还原类题型，核心特征是题目不直接给出完整图片，而是将像素信息以文本、数值、坐标、索引等离散形式存储，需要解题者将一维/离散数据映射到二维平面，还原出完整图像。

## 一、四大核心题型详解

### 1.RGB像素流题型

数据特征

**核心格式：** 连续的0~255范围数值，每3个值对应一个像素的R、G、B通道

**存储形式：** 逐行三元组分隔、单行连续空格分隔、十六进制字符串、单整数压缩RGB等多种变种

**典型标识：** 数值全部落在0-255区间，总数为3的整数倍

核心考点

**宽高因数分解：** 总像素数=数值总数÷3，需枚举总像素数的所有因数组合，找到正确的宽高配比

**通道顺序辨析：** 默认RGB顺序，变种包括BGR、RGBA、ARGB等

**编码格式识别：** 十进制、十六进制、24位单整数压缩RGB需先做格式转换

还原方法

**PPM纯文本拼接：** 构造P3格式头+RGB数据，直接生成图片

Python Pillow：putdata()批量写入像素，灵活度最高

典型坑点

宽度错误会导致逐行像素偏移，呈现斜纹、错位的图像，此时优先调整宽高，而非旋转图片。

### 2.纯坐标点题型

数据特征

**核心格式：** 每行两列数值，对应二维平面的x、y坐标

**内容特点：** 仅记录有效像素点的位置，无颜色信息，其余位置为背景色

**细分两类：**

**散点型：** 离散像素点，如二维码、文字、图形轮廓

**轨迹型：** 按时间/顺序排列的连续路径，如鼠标轨迹、绘图仪路径、GPS轨迹

核心考点

**坐标方向判断：** 数学坐标系（Y轴向上）与图像坐标系（Y轴向下）的差异，常出现上下颠倒

**等比例控制：** X/Y轴比例不一致会导致图形拉伸变形，二维码、圆形等特征无法识别

**XY轴交换：** 横纵轴错位，需测试转置效果

**连线判断：** 轨迹题需按顺序连线，散点题仅打点即可，二者不可混淆

还原方法

**GNUPlot：** 首选工具，快速出图，支持一键调整方向、比例、点样式、连线模式

Python Pillow：逐点putpixel()绘制，适合自定义逻辑

典型坑点

轨迹题随意排序去重，破坏路径顺序，导致连线完全错乱

未设置等比例，导致圆形变椭圆、二维码变形无法扫描

### 3.坐标+RGB题型

数据特征

**核心格式：** 每行5列数值，结构为X Y R G B，同时携带位置与颜色信息

**特点：** 像素位置明确，无需通过顺序推断位置，但需自行确定画布边界

核心考点

**画布尺寸计算：** 通过坐标最大值、最小值计算宽高，公式：宽=max_x-min_x+1、高=max_y-min_y+1

**坐标归一化：** 坐标不从0起始时，需减去最小坐标值做偏移，避免大片空白

**像素覆盖规则：** 同一坐标出现多次时，后出现的数据覆盖前者，需严格按文件顺序处理

还原方法

Python Pillow逐点写入像素，是该题型的最优方案。

典型坑点

未做坐标偏移，导致图像缩在角落、大部分区域空白

背景色选错，导致有效像素与背景融为一体，无法识别

### 4.像素索引题型

数据特征

**核心格式：** 单列整数，代表像素在二维图像中的一维线性编号；部分题目附带灰度、颜色值作为第二列

**本质：** 将二维像素按固定顺序展开为一维序列，仅记录有效点的索引位置

核心考点

**宽度爆破：** 最核心难点。未知图片宽度时，枚举常见尺寸（64、100、128、200、256、512等），逐一还原验证

**排列顺序：** 默认行优先（逐行排列），变种为列优先（逐列排列），公式不同

**行优先：** x=index%width，y=index//width

**列优先：** x=index//height，y=index%height

**索引基值：** 0基（编程通用）与1基（Excel、Matlab、人为编号）的偏移差异

还原方法

Python遍历索引，转换为坐标后逐点绘制。

典型坑点

行列优先搞反，导致图像转置、内容错乱

1基索引未做减1偏移，导致整体错一位

宽度判断错误，图像完全无法识别

## 二、通用图像修正排查清单

初步生成图像异常时，按优先级依次排查：

**尺寸类：** 宽高配比是否正确、比例是否失调

**方向类：** Y轴反转、XY轴交换、矩阵转置、旋转90°/180°/270°、水平/垂直翻转

**颜色类：** RGB/BGR通道颠倒、黑白反色、通道缺失

**偏移类：** 坐标偏移、索引基值错误、起始位置错位

常用ImageMagick修正命令

| 命令参数 | 效果 |
| --- | --- |
| -flip | 上下翻转 |
| -flop | 左右镜像 |
| -rotate 90 | 顺时针旋转90度 |
| -negate | 颜色反色 |

## 三、核心工具与适用场景

| 工具 | 最优适配题型 | 核心优势 |
| --- | --- | --- |
| GNUPlot | 纯坐标点题型 | 快速出图、调参便捷、比例控制精准 |
| Python Pillow | RGB像素流、坐标+RGB、像素索引 | 灵活度高，支持自定义逻辑与复杂处理 |
| ImageMagick | 图像后期修正 | 格式转换、批量变换高效便捷 |
| PPM格式 | RGB像素流 | 无需第三方库，纯文本即可快速生成图片 |

## 四、高频易错点与避坑指南

**斜图误判：** 图像出现规律性倾斜错位，第一反应是检查宽高是否正确，而非旋转；宽度错误会导致逐行偏移的斜纹。

**顺序破坏：** 轨迹类坐标题、索引题禁止随意排序去重，会破坏原始传输顺序，导致内容完全错乱。

**基值固化：** 索引题不要默认0基，需同时测试0基与1基，1基数据不偏移会导致整体错一位。

**排列顺序：** 索引题默认行优先，图形异常时必须测试列优先模式。

**通道思维定式：** 不要默认三通道就是RGB，BGR、ARGB都是高频变种，出现偏色时优先调换通道顺序。

**背景单一思维：** 默认白底黑点不对时，立即尝试黑底白点，尤其是二维码、条形码场景。

**格式误判：** 看到两列数字不要直接转ASCII，优先当坐标绘图验证；看到三列数据不要默认都是RGB，也可能是坐标+灰度、坐标+状态等格式。
