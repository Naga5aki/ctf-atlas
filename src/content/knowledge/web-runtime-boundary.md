能在响应里看到计算结果，和能让服务器启动任意进程，不是同一层证据。先找解释器，再看用户控制的是数据、命令名，还是两者都有。

> 只在本地题目或授权环境验证；用只读命令与固定回显确认通道，不提交下载器、反弹连接或写文件命令。

## 00 30 秒速查

| 我要… | 先看… | 备注 |
|---|---|---|
| 命令注入 | 参数是否拼进 shell 字符串 | 数组传参通常不经 shell |
| 代码执行 | `eval`/`assert`/表达式求值 | 与系统命令分开 |
| 反序列化 | `unserialize`/`pickle`/`readObject` | 输入字节从哪来 |
| 输出通道 | stdout/stderr/文件/延时/回连 | 无回显先找通道 |
| 自动调用 | `__wakeup`/`__destruct`/`__reduce__` | 构造不一定执行 |
| 沙箱 | 还能到达哪些对象 | 先列对象图 |
| 版本 | PHP/Java/库版本 | 决定边界 |
| 记录 | 参数→函数→资源 | 一句话结论 |

## 01 原理与成立条件

```text
用户输入 → 函数入口
             ├─ 拼进 shell 字符串 → 外壳再解析
             ├─ 作为数组参数 → 程序自己解释
             ├─ 当成代码字符串 → 语言解释器执行
             └─ 当成序列化字节 → 还原对象并触发钩子
```

| 条件 | 含义 | 不满足时 |
|---|---|---|
| 输入可达危险函数 | 参数进入 sink | 找二次使用/其他路由 |
| 未做类型/字符限制 | 元字符或对象可达 | 换编码/换入口 |
| 解释器会执行 | shell/语言/反序列化 | 只是数据 |
| 有可观察通道 | 回显/文件/延时/日志 | 建通道再验证 |

| 种类 | 例子 | 结果 |
|---|---|---|
| 代码执行 | PHP `eval`/`assert`；Python `eval`/`exec`；Node `Function` | 语言值/对象 |
| 系统命令 | `system`/`exec`/`shell_exec`；`Runtime.exec`；`subprocess` | 进程输出/退出码 |
| 反序列化 | `unserialize`/`pickle.loads`/`readObject` | 自动调用钩子 |

## 02 判断与分型

```text
参数进入哪个函数？
 ├─ shell 字符串 → 命令注入
 ├─ 数组参数 → 通常不是命令注入
 ├─ eval/表达式 → 代码执行
 ├─ 反序列化 → 看类与钩子
 └─ 模板/沙箱 → 看对象图
有回显吗？
 ├─ 有 → 直接验证
 └─ 无 → 文件/延时/日志/回连
```

| 信号 | 含义 | 下一步 |
|---|---|---|
| 元字符改变输出 | 进入 shell | 试分隔符/替换 |
| 数组传参无效 | 不经 shell | 换函数/换入口 |
| `eval` 报语法错 | 字符串进解释器 | 构造合法表达式 |
| Base64/二进制令牌 | 可能序列化 | 查是否 `unserialize` |
| 页面出现新文件 | 写文件通道 | 只读打开 |
| 固定延时 | 时间通道 | 多次测量 |
| 钩子里有文件/命令 | 反序列化可利用 | 找链 |

| 假阳性 | 原因 | 处理 |
|---|---|---|
| 页面显示命令文本 | 只是回显 | 看执行结果 |
| 单组分隔符无效 | 被过滤/在参数里 | 换分隔符/确认 shell |
| Base64 就是 JSON | 不是序列化 | 解码确认 |
| 序列化字符串但不进函数 | 只是数据 | 找调用点 |
| 延时一次 | 网络抖动 | 多次取中位数 |

## 03 利用阶梯

### L0 定位 sink 与通道

**前提**：有源码或可观测的输入点。

**步骤**：
1. 搜危险函数：`system`/`exec`/`eval`/`unserialize`/`pickle`/`readObject`。
2. 确认参数来源：请求、Cookie、缓存、文件。
3. 确认输出通道：响应、文件、延时、日志。
4. 记录“参数 P → 函数 F → 资源 R”。

**成功标志**：能指出用户输入进入哪个 sink，且有一次可观察结果。

**失败分支**：无源码→黑盒试探；无回显→L2 建通道。

### L1 命令注入

**前提**：参数被拼进 shell 字符串（`shell=True`/`system`/反引号）。

**步骤**：
1. 用只读命令确认执行：`id`/`whoami`（按题目允许）。
2. 试分隔符：`;`、`&&`、`||`、`|`、换行。
3. 空格被过滤时试 `$IFS`、Tab、`${IFS}`。
4. 参数以数组传递时，确认是否真的经过 shell。

**成功标志**：命令输出/延时/文件变化可复现。

**失败分支**：数组传参→不是命令注入；过滤严格→编码/换分隔符/换参数。

### L2 代码执行

**前提**：输入进入 `eval`/`assert`/表达式求值/动态函数。

**步骤**：
1. 先发语法错误，确认字符串被当代码解析。
2. 用最小表达式验证：算术/字符串拼接。
3. 找可用的内建函数与对象（读文件/列目录）。
4. 区分代码执行与系统命令，不要混用证据。

**成功标志**：表达式结果/报错位置随输入变化。

**失败分支**：被当普通字符串→找二次解码；沙箱→L4。

### L3 反序列化副作用

**前提**：输入字节进入 `unserialize`/`pickle.loads`/`readObject`。

**步骤**：
1. 确认格式：PHP `O:`、Python pickle、Java `AC ED`、JSON `@type`。
2. 找自动调用钩子：`__wakeup`/`__destruct`/`__toString`/`__reduce__`/`readObject`。
3. 看钩子里是否碰文件、命令、网络。
4. 有类白名单/签名时，先确认密钥与名单。

**成功标志**：还原时产生可观察副作用（文件/请求/延时）。

**失败分支**：无可用类→找链/找 phar；签名校验→找密钥泄露。

### L4 沙箱与组合

**前提**：已有代码执行/反序列化，但被沙箱或禁用函数限制。

**步骤**：
1. 列出沙箱允许的对象/函数。
2. 找原型链、`constructor`、导入链、反射。
3. 反序列化链结合文件上传/phar/模板。
4. 只验证到可读文件/固定回显，不扩大破坏。

**成功标志**：在限制下仍能执行/读文件。

**失败分支**：对象图封闭→换入口；链断→回到 L0 找其他 sink。

## 04 绕过与边界

| 限制 | 替代 | 示例 |
|---|---|---|
| 空格过滤 | `$IFS`/Tab/`${IFS}` | `cat$IFS/etc/passwd` |
| 分隔符过滤 | 换行/`%0a` | 按 shell 支持 |
| 关键字过滤 | 拼接/变量/通配 | `c'a't`、`/bin/c?t` |
| `disable_functions` | 找未禁用函数/扩展 | 先列 `phpinfo` |
| 数组传参 | 换字符串入口 | 找另一处拼接 |
| 类白名单 | phar/框架链 | 见 PHP 反序列化页 |
| 签名校验 | 密钥泄露/长度伪造 | 先找配置 |

边界：反序列化可能触发写文件/网络请求；验证用只读资源，避免影响共享环境。

## 05 非典型入口

| 位置 | 示例 | 注意 |
|---|---|---|
| 文件名 | 图片处理/压缩命令 | 命令拼接 |
| 邮件/导出 | 调用外部程序 | 参数注入 |
| 模板 | 表达式/沙箱 | 见模板页 |
| Cookie | 序列化会话 | 签名/密钥 |
| 缓存 | 反序列化缓存值 | 写入点 |
| phar:// | 文件函数触发元数据 | 不需显式 unserialize |
| 日志/配置 | 包含即执行 | 文件包含 |
| 第三方库 | 版本漏洞 | 核对入口 |

## 06 差异速查

| 语言 | 命令 | 代码 | 反序列化 |
|---|---|---|---|
| PHP | `system`/`exec`/反引号 | `eval`/`assert` | `unserialize`/phar |
| Python | `os.system`/`subprocess(shell=True)` | `eval`/`exec` | `pickle`/`yaml.load` |
| Java | `Runtime.exec`/`ProcessBuilder` | 表达式/脚本引擎 | `readObject`/Fastjson |
| Node | `child_process` 字符串 | `eval`/`Function` | 原型链/库 |

| 项 | 行为 | 影响 |
|---|---|---|
| `subprocess` 列表 | 不经 shell | 元字符是普通字符 |
| `shell=True` | 经 shell | 分隔符生效 |
| `ProcessBuilder` 列表 | 不经 shell | 除非首项是 `sh`/`cmd` |
| PHP `unserialize` | 不调用 `__construct` | 看 `__wakeup`/`__destruct` |
| Python `pickle` | 调 `__reduce__` | 可调用对象 |
| Java `readObject` | 类自己的方法 | 类路径决定 |

## 07 工具与验证

| 目标 | 工具/命令 |
|---|---|
| 命令确认 | 只读命令 + 固定回显 |
| 无回显 | 写文件后只读、延时、日志 |
| 反序列化 | 手工构造/框架链工具 |
| PHP | `php -r` 本地生成序列化 |
| Java | ysoserial（授权环境） |
| Python | pickle 本地构造 |
| 审计 | `grep -rn` 危险函数 |
| 记录 | 参数、函数、版本、通道 |

验证顺序：sink → 通道 → 最小执行 → 版本边界 → 记录。

## 09 失败分支

| 现象 | 优先怀疑 | 处理 |
|---|---|---|
| 元字符无效 | 数组传参/过滤 | 确认 shell/换分隔符 |
| `eval` 无反应 | 不是代码上下文 | 找二次解码 |
| 反序列化无副作用 | 无钩子/类未加载 | 找链/phar |
| 签名失败 | 密钥/长度 | 找配置/重签 |
| 无回显 | 通道未建 | 文件/延时/日志 |
| 被禁用函数 | `disable_functions` | 列函数/换扩展 |
| 沙箱拦截 | 对象图受限 | 找原型/反射 |
