应用把昵称、页面片段或配置值交给模板引擎时，重点看用户输入是作为**数据**传入，还是被拼进**模板文本**后重新编译。引擎名称只是线索；必须找到调用点和实际到达路径。

> 只在本地题目或授权环境对照；用普通文本和无副作用表达式确认，不执行破坏性操作。

## 00 30 秒速查

| 我要… | 先看… | 备注 |
|---|---|---|
| 是否有注入 | 输入是否拼进模板源码 | 数据绑定不算 |
| 认引擎 | 依赖文件/调用函数 | 别只看括号 |
| 最小验证 | `{{7*7}}`/`${7*7}` | 按引擎语法 |
| Python 链 | `__class__`/`__mro__`/`__globals__` | 看沙箱 |
| Flask 全局 | `config`/`request`/`url_for`/`lipsum` | 直接可读 |
| Java 引擎 | FreeMarker/Velocity/Thymeleaf | 看数据模型 |
| PHP 引擎 | Twig/Smarty | 看版本/配置 |
| 沙箱 | 拦截了哪些属性 | 版本决定 |
| 到 RCE | `os`/`popen`/`exec` | 见 RCE 页 |

## 01 原理与成立条件

```text
用户输入 → 模板调用
             ├─ render(固定模板, 数据) → 安全（默认）
             └─ render(前缀 + 用户输入) → 模板源码可控
                          ↓
                    引擎解析表达式 → 属性/方法/模块
```

| 条件 | 含义 | 不满足时 |
|---|---|---|
| 输入进入模板源码 | 拼接/`render_template_string` | 只是数据绑定 |
| 引擎会求值 | 表达式/标签 | 只显示文本 |
| 对象可达 | 配置/函数/类 | 换链 |
| 能到 sink | 文件/命令/网络 | 只算表达式 |

| 层 | 例子 | 风险 |
|---|---|---|
| 数据绑定 | `render("tpl", name=user)` | 通常安全 |
| 模板源码 | `render_template_string(f"...{user}")` | 可注入 |
| 视图名 | 控制器返回用户输入 | Thymeleaf 等可解析 |
| 二次渲染 | 存库后再次编译 | 存储型 |

## 02 判断与分型

```text
用户输入进模板了吗？
 ├─ 否 → 只是数据/前端
 └─ 是
    看依赖/调用：
    ├─ Jinja2 → {{ }} / {% %}
    ├─ Twig → {{ }} / {% %}
    ├─ Smarty → {$var}
    ├─ FreeMarker → ${} / <#>
    ├─ Velocity → $var / #if
    └─ Thymeleaf → th:* / ${}
最小验证：
 ├─ 计算结果 → 表达式执行
 ├─ 原样输出 → 只当文本
 └─ 报错 → 看语法/沙箱
```

| 信号 | 含义 | 下一步 |
|---|---|---|
| `{{7*7}}` 变 49 | Jinja2/Twig | 查依赖区分 |
| `${7*7}` 变 49 | FreeMarker/Velocity | 看 `<#`/`#` |
| `{$x}` 被解析 | Smarty | 看 PHP 配置 |
| `th:text` 生效 | Thymeleaf | 看视图名/模型 |
| 表达式原样输出 | 只当文本 | 找二次渲染 |
| 报沙箱错误 | 受限环境 | 列允许对象 |

| 假阳性 | 原因 | 处理 |
|---|---|---|
| 前端也算出 49 | JS 计算 | 看服务端响应 |
| 括号相似 | 引擎未定 | 查依赖 |
| 报错但无执行 | 语法错误 | 修表达式 |
| 数据绑定 | 不是模板源码 | 换入口 |

## 03 利用阶梯

### L0 确认数据流与引擎

**前提**：有模板渲染点。

**步骤**：
1. 搜 `render`/`compile`/`template`/`render_template_string`。
2. 区分固定模板与拼接源码。
3. 看依赖：`jinja2`、`twig/twig`、`freemarker`、`thymeleaf`。
4. 用普通文本确认回显位置。

**成功标志**：能指出“用户输入 → 模板源码”的调用点与引擎。

**失败分支**：只是数据绑定→换入口；引擎未定→查 `composer.json`/`pom.xml`/`package.json`。

### L1 最小表达式验证

**前提**：输入进入模板源码。

**步骤**：
1. Jinja2/Twig：`{{7*7}}`。
2. FreeMarker：`${7*7}`；Velocity：`#set($x=7*7)$x`。
3. Smarty：`{7*7}` 或 `{$x}`。
4. 看响应是否为 49，排除前端计算。

**成功标志**：服务端渲染结果随表达式变化。

**失败分支**：原样输出→找二次渲染；报错→看语法/沙箱。

### L2 读配置与对象

**前提**：表达式可执行。

**步骤**：
1. Jinja2：`{{config}}` 看 `SECRET_KEY`/数据库。
2. Flask 全局：`request`、`url_for`、`lipsum`。
3. Python 对象：`''.__class__.__mro__[1].__subclasses__()`。
4. Java：看数据模型里放的对象/视图名。

**成功标志**：读到配置/对象结构。

**失败分支**：沙箱拦截→L4；无对象→换引擎/换入口。

### L3 到命令/文件

**前提**：能访问函数/模块。

**步骤**：
1. Jinja2：`cycler.__init__.__globals__.os.popen('id').read()`。
2. 或 `lipsum.__globals__['os']`、`url_for.__globals__`。
3. 沙箱：找 `__globals__`/`__subclasses__` 中可用类。
4. Java：`Runtime`/`ProcessBuilder`/表达式工具。
5. 只验证到固定回显/读文件。

**成功标志**：命令执行/文件读取。

**失败分支**：沙箱严→L4；无 globals→换对象。

### L4 沙箱与过滤绕过

**前提**：有沙箱/关键字过滤。

**步骤**：
1. 列出被拦属性：`__class__`/`__globals__`/`os`。
2. 用 `attr()`/`[]`/`|join`/十六进制拼接绕过。
3. 用 `request.args` 传参，避免模板里出现关键字。
4. 看引擎版本历史漏洞/沙箱逃逸。

**成功标志**：过滤条件下仍能读/执行。

**失败分支**：沙箱版本已修→换对象/换入口；无对象→转其他漏洞。

## 04 绕过与边界

| 限制 | 替代 | 示例 |
|---|---|---|
| 拦 `.`/`_` | `attr()`/`[]` | `|attr('__class__')` |
| 拦关键字 | 拼接/十六进制 | `'__glo'+'bals__'` |
| 拦 `os` | 子类/其他函数 | `cycler`/`lipsum` |
| 拦引号 | `request.args` | 外部传参 |
| 沙箱 | 版本逃逸/其他对象 | 看 jinja2 版本 |
| 无回显 | 写文件/外带 | 见 RCE 页 |

边界：能算一个数字只说明表达式执行；到 `__globals__` 里的模块才碰到进程接口。`SandboxedEnvironment` 与普通 `Environment` 不同，版本决定遗漏。

## 05 非典型入口

| 位置 | 示例 | 注意 |
|---|---|---|
| 昵称/签名 | 存储后渲染 | 存储型 SSTI |
| 邮件模板 | 用户可编辑 | 服务端渲染 |
| 页面片段 | CMS/富文本 | 二次渲染 |
| 视图名 | 控制器返回用户输入 | Thymeleaf |
| 错误页 | 参数回显 | 反射型 |
| 配置值 | 模板路径 | 文件包含 |
| 主题/语言包 | 模板文件 | 上传+包含 |

## 06 差异速查

| 引擎 | 输出 | 语句 | 备注 |
|---|---|---|---|
| Jinja2 | `{{ }}` | `{% %}` | Python/Flask |
| Twig | `{{ }}` | `{% %}` | PHP，查 composer |
| Smarty | `{$x}` | `{if}` | PHP |
| FreeMarker | `${}` | `<#if>` | Java |
| Velocity | `$x`/`${}` | `#if` | Java |
| Thymeleaf | `th:*`/`${}` | HTML 属性 | 视图名也可注入 |

## 09 失败分支

| 现象 | 优先怀疑 | 处理 |
|---|---|---|
| 表达式原样输出 | 数据绑定 | 找拼接点 |
| 括号无效 | 引擎不对 | 查依赖 |
| 报语法错 | 语法/上下文 | 修表达式 |
| 沙箱拦截 | 属性过滤 | 换对象/绕过 |
| 无 globals | 引擎限制 | 换链 |
| 命令无回显 | 通道 | 写文件/外带 |
