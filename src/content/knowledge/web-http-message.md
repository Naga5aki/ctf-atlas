Web 题最后都落到一份 HTTP 报文上。先把这份报文读完整，再决定是会话问题、参数问题，还是服务端又向外发了请求。

> 只对本地题目或明确授权的环境抓包与重放；保存请求时不要记录可用令牌。

## 00 30 秒速查

| 我要… | 先看… | 备注 |
|---|---|---|
| 报文结构 | 请求行/头/空行/正文 | 少了空行会 400/挂起 |
| 版本 | `HTTP/1.0`/`1.1`/`2` | 决定 Host/连接语义 |
| 方法 | `Allow`/状态码 | 是否接受 GET/PUT |
| 跳转 | `Location` + `Set-Cookie` | 不要立刻跟随 |
| 缓存 | `ETag`/`Cache-Control` | 304 不是跳转 |
| 来源 IP | `REMOTE_ADDR` vs `XFF` | 看谁写入 |
| 正文类型 | `Content-Type` | 决定解析器 |
| 身份 | Cookie/JWT | 分开保存 |
| 代理错误 | 502/504 | 先分拒绝/超时 |

## 01 原理与成立条件

```text
请求行 → 请求头 → 空行 → 正文
响应行 → 响应头 → 空行 → 响应体
              ├─ Host 选虚拟主机
              ├─ Cookie 带会话
              └─ Content-Type 选解析器
```

| 段 | 内容 | 读错时 |
|---|---|---|
| 请求行 | 方法、路径、查询、版本 | 漏路径参数 |
| 请求头 | `名字: 值` | 把浏览器头当业务 |
| 空行 | 分隔 | 正文被当头 |
| 正文 | 表单/JSON/多部分 | 只改 URL 无效 |

| 元素 | 含义 | 注意 |
|---|---|---|
| URL | 协议+主机+端口+路径+查询+片段 | 片段不发服务器 |
| Host | 虚拟主机 | 非默认端口要写 |
| `Content-Length`/`TE` | 正文边界 | 冲突见走私页 |
| `Set-Cookie` | 种会话 | 多条头，不按逗号拆 |

## 02 判断与分型

```text
先看状态码：
 ├─ 2xx → 业务是否真的变化
 ├─ 3xx → 读 Location/Set-Cookie，不跟随
 ├─ 4xx → 认证/授权/方法/报文
 └─ 5xx → 应用异常 or 代理错误
再看头：
 ├─ Host → 换站点
 ├─ XFF/Referer → 是否被信任
 ├─ Content-Type → 解析器
 └─ Cookie/JWT → 身份
```

| 状态 | 含义 | 下一步 |
|---|---|---|
| 200 | 有正文 | 看是否错误页 |
| 201/204 | 创建/无正文 | 看资源变化 |
| 301/302 | 跳转 | 读 `Location` |
| 304 | 缓存验证 | 看 `ETag` |
| 400 | 报文错 | 空行/Host/长度 |
| 401/403 | 未认证/拒绝 | 分路径是否存在 |
| 404 | 无资源 | 对比错误页 |
| 405 | 方法不允许 | 读 `Allow` |
| 500 | 应用异常 | 看正文/日志 |
| 502/504 | 代理失败 | 连接 vs 超时 |

| 假阳性 | 原因 | 处理 |
|---|---|---|
| 200 就成功 | 错误页也 200 | 看正文 |
| 302 后登录 | 跟随丢了中间包 | 不跟随 |
| 304 当故障 | 无正文正常 | 看验证器 |
| `XFF` 当真实 IP | 客户端可伪造 | 看代理配置 |

## 03 利用阶梯

### L0 拆四段与版本

**前提**：有一次真实交互。

**步骤**：
1. `curl -v -D headers.txt -o body.txt URL`。
2. 标出请求行、头、空行、正文。
3. 看版本：1.0/1.1/2；2 看伪头 `:method`/`:path`/`:authority`。
4. 看 `Host`/`Content-Type`/`Content-Length`。

**成功标志**：能复述这次请求的每个字段。

**失败分支**：抓不到→代理/DevTools；版本不明→看请求行。

### L1 方法与状态

**前提**：接口对方法/路径敏感。

**步骤**：
1. 试 `OPTIONS` 看 `Allow`。
2. 试 `PUT` 与删除类方法（授权环境）。
3. 301/302/303/307/308 分清是否改方法。
4. 304 配对 `ETag`/`If-None-Match`。

**成功标志**：知道哪些方法被接受、跳转是否丢正文。

**失败分支**：405/501→方法未开；跟随丢包→不跟随重放。

### L2 头字段与信任边界

**前提**：应用按头做判断。

**步骤**：
1. 换 `Host` 看虚拟主机/重置链接。
2. 加 `X-Forwarded-For`/`X-Real-IP`/`Client-IP`，对照日志与 `REMOTE_ADDR`。
3. 换 `Referer` 看防盗链/来源限制。
4. 改 `Content-Type`（表单/JSON/多部分）看解析分支。

**成功标志**：头改变导致业务分支变化，且能指出谁写入。

**失败分支**：头被覆盖→看反代；不生效→应用未读。

### L3 Cookie 与 JWT

**前提**：有会话/令牌。

**步骤**：
1. 读 `Set-Cookie` 属性：`HttpOnly`/`Secure`/`SameSite`/`Domain`/`Path`。
2. 登录前后对比会话号；看是否旋转。
3. JWT 解码三段，记录 `alg`/`kid`/`exp`，但不把解码当验签。
4. 区分 Session（服务端存）与 JWT（客户端存）。

**成功标志**：知道身份载体与校验缺口。

**失败分支**：Cookie 不生效→Domain/Path；JWT 改不动→验签正常。

### L4 代理/版本/走私边界

**前提**：有反代/CDN，或长度/编码冲突。

**步骤**：
1. 502 查上游连接；504 查超时。
2. 1.0 默认短连接；1.1 默认持久；2 多路复用。
3. `Content-Length` 与 `Transfer-Encoding` 同时出现→见走私页。
4. 记录哪一层返回的状态码。

**成功标志**：定位失败层/可构造解析差异。

**失败分支**：代理覆盖→看配置；版本不支持→换路径。

## 04 绕过与边界

| 场景 | 边界 | 说明 |
|---|---|---|
| 301/302 | 可能改 POST 为 GET | 303 明确 GET；307/308 保留 |
| 304 | 无正文 | 不是跳转 |
| `no-cache` | 仍可存 | 用前必须验证 |
| `no-store` | 不保存 | 登录/支付 |
| `HttpOnly` | 防读不防发 | 脚本仍可发请求 |
| `SameSite` | 跨站自动带 Cookie | 不防同站 |
| `XFF` | 客户端可写 | 只信可信代理覆盖 |
| HTTP/2 | `Connection` 无效 | 看伪头 |

## 05 非典型入口

| 位置 | 示例 | 注意 |
|---|---|---|
| `Host` | 密码重置链接 | 投毒 |
| `X-Forwarded-*` | 来源 IP/协议 | 信任边界 |
| `Referer` | 防盗链 | 可伪造 |
| `Range` | 分段读取 | 206/416 |
| `Content-Type` | JSON/表单 | 解析器 |
| `Transfer-Encoding` | 分块 | 走私 |
| Cookie 域 | 子域 | 固定/覆盖 |

## 06 差异速查

| 版本 | 连接 | Host |
|---|---|---|
| 0.9 | 短 | 无 |
| 1.0 | 默认短 | 非强制 |
| 1.1 | 默认持久 | 必填 |
| 2 | 多路复用 | `:authority` |

| 解析器 | 正文 | PHP |
|---|---|---|
| 表单 | `a=1` | `$_POST` |
| JSON | JSON | `php://input` |
| 多部分 | boundary | `$_POST`/`$_FILES` |

## 07 工具与验证

| 目标 | 工具/命令 |
|---|---|
| 看报文 | `curl -v`/DevTools |
| 不跟随 | `curl` 不加 `-L` |
| 改头 | Burp Repeater |
| 分段 | `curl -r` |
| 记录 | 请求/响应头 |

验证顺序：四段 → 状态 → 头 → Cookie → 代理。

## 09 失败分支

| 现象 | 优先怀疑 | 处理 |
|---|---|---|
| 400 | 空行/Host/长度 | 修报文 |
| 一直等待 | 正文长度错 | 补 CL/TE |
| 302 丢正文 | 方法被改 | 用 307/308 |
| 304 无内容 | 缓存验证 | 看 ETag |
| 头不生效 | 被覆盖 | 看反代 |
| 502/504 | 上游/超时 | 分层查 |
| Cookie 不带 | Domain/Path/SameSite | 逐项看 |
