接口提供抓取网页、检查站点、生成预览或代理下载，服务器会代替用户发起请求。此时把 **用户输入 → URL 解析 → 地址解析 → 实际连接 → 响应返回** 连成一条链，避免只看字符串过滤。XML 则是解析器在读文档时又去取一份资源。

> 只在本地题目或授权环境对照；让服务访问你自己的 HTTP 服务，核对 Host 与路径，不读取无关数据。

## 00 30 秒速查

| 我要… | 先试… | 备注 |
|---|---|---|
| 确认 SSRF | 让服务请求你的接收端 | 看 Host/来源 IP |
| 内网探测 | `127.0.0.1`、内网段、端口 | 先确认回显 |
| 换协议 | `file://`、`gopher://`、`dict://` | 看客户端库 |
| 绕黑名单 | 十进制/八进制 IP、`@`、IPv6 | 解析后比较 |
| 重定向 | 你的 302 跳到内网 | 看是否重新校验 |
| DNS 再绑定 | 短 TTL 两次解析 | 检查/连接不一致 |
| 云元数据 | `169.254.169.254` | 见云容器页 |
| XXE 回显 | 外部实体读文件 | 看响应 |
| 盲 XXE | 外部 DTD/外带 | 看接收端 |

## 01 原理与成立条件

```text
用户 URL → 校验（字符串/域名/IP） → DNS 解析 → 连接
                                      ├─ 重定向 → 再次校验？
                                      └─ 协议 → http/file/gopher
XML → 解析器 → DTD/实体 → 取外部资源 → 响应/出站
```

| 条件 | 含义 | 不满足时 |
|---|---|---|
| URL/XML 可控 | 参数进入客户端/解析器 | 找其他入口 |
| 服务可出网 | 容器/主机网络 | 打本机/内网 |
| 校验与连接不一致 | 字符串 vs 二进制 | 构造解析差异 |
| 响应可见/有副作用 | 回显/盲打 | 用接收端 |

## 02 判断与分型

```text
服务会发起请求吗？
 ├─ 是 → SSRF
 │    ├─ 回显 → 直接读内网
 │    ├─ 无回显 → 盲 SSRF/时间/外带
 │    └─ 可控协议 → file/gopher/dict
 └─ XML 进入解析器 → XXE
      ├─ 回显 → 读文件
      └─ 盲 → 外部 DTD/外带
```

| 信号 | 含义 | 下一步 |
|---|---|---|
| 接收端收到请求 | SSRF 成立 | 探内网 |
| 返回内网页面 | 有回显 | 列服务 |
| 只有延时 | 盲 SSRF | 端口扫描 |
| `file://` 读到文件 | 协议可用 | 读源码/密钥 |
| `gopher://` 可用 | 可打 Redis/FastCGI | 构造协议 |
| XML 报实体错 | 解析器处理 DTD | 试外部实体 |
| 外带收到 DNS/HTTP | 盲 XXE | 读文件 |

| 假阳性 | 原因 | 处理 |
|---|---|---|
| 请求超时 | 网络不通/被拦 | 换目标 |
| 返回错误页 | 只是客户端报错 | 看接收端 |
| `Content-Type: xml` | 未必解析 | 找解析函数 |
| 页面空白 | 可能盲打 | 看接收端 |

## 03 利用阶梯

### L0 证明出站

**前提**：有抓取/预览/代理/XML 解析入口。

**步骤**：
1. 搭自己的 HTTP/DNS 接收端。
2. 提交指向接收端的 URL/XML 实体。
3. 看接收端是否收到请求、Host/路径/来源 IP。
4. 记录超时、重定向、响应体上限。

**成功标志**：服务端确实发起请求/解析器取外部资源。

**失败分支**：无请求→参数未进入客户端；有请求但不回显→盲打。

### L1 内网与端口

**前提**：SSRF 成立。

**步骤**：
1. 试 `http://127.0.0.1:80/`、`http://localhost/`。
2. 常见内网段/端口：80/443/6379/3306/8080/9000。
3. 用响应差异/时间判断开放。
4. 云环境试 `169.254.169.254`（见云页）。

**成功标志**：读到内网服务/确认端口开放。

**失败分支**：回环被拦→换地址表示；无回显→时间盲。

### L2 协议扩展

**前提**：客户端库支持非 HTTP 协议。

**步骤**：
1. 试 `file:///etc/passwd`、`file:///var/www/html/index.php`。
2. `gopher://` 构造 Redis/FastCGI/HTTP 请求。
3. `dict://` 探端口/服务。
4. 以 `curl_version()`/库文档确认协议列表。

**成功标志**：读文件/打内网服务/写数据。

**失败分支**：协议未编译→换客户端/换入口；gopher 被拦→编码/换协议。

### L3 解析差异与重定向

**前提**：有黑名单/白名单校验。

**步骤**：
1. 用户信息：`http://allowed@127.0.0.1/`。
2. IP 变形：十进制/八进制/十六进制/IPv6。
3. 302：你的服务跳 `http://127.0.0.1/`，看是否重新校验。
4. DNS 再绑定：短 TTL 两次解析不同地址。

**成功标志**：绕过校验访问内网。

**失败分支**：解析后比较→换重定向/再绑定；全拦→换入口。

### L4 XXE 实体与盲打

**前提**：XML 进入解析器且允许 DTD/外部实体。

**步骤**：
1. 内部实体确认解析：`<!ENTITY x "test">` + `&x;`。
2. 外部实体读文件：`<!ENTITY x SYSTEM "file:///etc/passwd">`。
3. 盲 XXE：外部 DTD + 参数实体，把内容拼进 URL 外带。
4. 无回显时看接收端 DNS/HTTP。

**成功标志**：文件内容回显/外带请求到达。

**失败分支**：DTD 禁用→换解析器/入口；外部实体禁用→内部实体/报错。

## 04 绕过与边界

| 限制 | 替代 | 示例 |
|---|---|---|
| 黑名单 `127.0.0.1` | 十进制/八进制/IPv6 | `2130706433`、`0x7f000001` |
| 只查字符串开头 | `@`/重定向 | `http://allowed@127.0.0.1/` |
| 只查一次 DNS | 再绑定 | 短 TTL |
| 只校验初始 URL | 302 | `Location: http://127.0.0.1/` |
| 禁 `file://` | `gopher://`/`dict://` | 看库 |
| DTD 禁用 | 内部实体/其他解析器 | 换入口 |
| 外部实体禁用 | 参数实体/报错 | 看配置 |

边界：`requests` 只支持 http/https；PHP curl 协议取决于编译；容器回环与宿主回环不同；DNS 再绑定需要两次解析证据。

| XML API | SOAP/RSS | XXE |

## 06 差异速查

| 客户端 | 协议 | 备注 |
|---|---|---|
| PHP `file_get_contents` | http/https/ftp | `allow_url_fopen` |
| PHP curl | 编译进库的协议 | 常见 gopher/dict |
| Python `requests` | http/https | 无 file/gopher |
| Java `URL` | 注册的 handler | JDK 版本相关 |
| lxml | 可关实体/网络 | 看参数 |
| ElementTree | 默认不解析外部实体 | 版本差异 |

## 09 失败分支

| 现象 | 优先怀疑 | 处理 |
|---|---|---|
| 接收端无请求 | 未进客户端 | 换参数/入口 |
| 请求但不回显 | 盲 SSRF | 时间/外带 |
| 回环被拦 | 黑名单 | IP 变形/重定向 |
| `file://` 失败 | 协议未启用 | gopher/dict |
| 302 不跟 | 客户端配置 | 换跳转方式 |
| XML 无实体 | DTD 禁用 | 换解析器 |
| 盲 XXE 无外带 | 出网/DTD | 换通道 |
