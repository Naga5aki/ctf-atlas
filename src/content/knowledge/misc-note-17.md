## 一、核心定位

盲水印是CTF Misc高频频域隐写考点，其基于DCT/DWT等频域变换将信息嵌入图片，肉眼完全不可见，具备抗压缩、抗裁剪、抗旋转的强鲁棒性。它与LSB空域隐写有本质区别：LSB将信息藏在像素最低位，轻微修改就会被破坏；盲水印嵌入图像变换域，鲁棒性更强，常规空域检测工具无法识别。

## 二、核心分类与操作方法

（一）单图盲水印

仅需一张带水印图片即可完成提取，无需原始无水印图，是题目最常见的类型。

**核心工具：** 首选Windows绿色版「隐形水印工具V1.2」，其次为PuzzleSolver集成的单图盲水印模块；

**图形化操作：** 切换至提取水印功能，导入图片后默认选择方案一、亮度50提取；无结果时轮换其他方案，上下调整亮度参数。

**命令行提取：** python3 bwm.py decode--no-original带水印.png输出.png

**结果特征：** 提取内容常同时呈现正序与倒序，或为镜像、反转状态，需手动翻转后识别，多为二维码、密码、flag片段。

（二）双图盲水印

需同时拥有原始无水印图和带水印图才能提取，要求两张图片分辨率完全一致，否则需先缩放对齐。分为两个主流实现版本：

### 1.原版BlindWaterMark

**工具：** 原版Python脚本，PuzzleSolver已完整集成，无需手动配置Python环境，是比赛首选方案。

**核心命令：**

**嵌入：** python bwm.py encode原图.png水印.png带水印图.png

提取（Python3环境）：python bwmforpy3.py decode原图.png带水印图.png输出水印.png

**关键参数：** --oldseed，用于兼容Python2版本生成的盲水印，提取失败时必须添加该参数重试。

**标志性特征：** 将原图与带水印图异或后，会出现明显的横向蓝色虚线，可快速判定为此版本。

**兼容性：** 支持PNG、JPG、BMP格式任意混合搭配。

### 2.频域盲水印

**特点：** 基于频域变换实现，抗压缩、抗裁剪能力远强于原版；带水印图与原图视觉差异极小，肉眼完全无法分辨，隐蔽性更强。

**核心命令：**

**嵌入：** python encode.py--image原图.png--watermark水印.png--result带水印图.png

**提取：** python decode.py--original原图.png--image带水印图.png--result提取的水印.png

**区分特征：** 两图异或不会出现原版的横向蓝色虚线。

**补充：** BlindWaterMark进阶参数与版本说明

标准比赛适配版本为v0.4.1，2025年后的重构版算法与赛事题目不兼容，提取结果为纯噪点，禁止使用。

--alpha：调整水印强度，结果模糊时可调至2.0-5.0

--wm：指定水印尺寸，提取结果为黑块时，可尝试200,200或300,300

## 三、标准解题流程

**前置排查：** 先通过常规工具检测LSB隐写、EXIF元数据、文件尾拼接，排除空域隐写考点。

**类型判断：** 仅单张图片→单图盲水印，优先用隐形水印工具V1.2或无原图命令；两张图片→双图盲水印，优先用PuzzleSolver一键提取，失败再切换命令行工具。

**版本区分：** 双图场景下，两图异或出现横向蓝色虚线→原版BlindWaterMark；无虚线、视觉差异极小→频域盲水印。

**调优重试：** 提取失败或效果差时，调整alpha强度、水印尺寸；原版添加--oldseed重试；必要时做格式转换、尺寸对齐、反色等预处理。

**结果处理：** 提取结果若为镜像、反转、倒序状态，手动翻转调整后识别有效信息。

## 四、避坑指南

双图盲水印必须依赖原图才能提取，无原图时不要浪费时间尝试双图方案。

原版BlindWaterMark的Python2与Python3生成结果不兼容，提取失败务必添加--oldseed参数重试。

双图提取前必须保证两张图片分辨率完全一致，尺寸不同时先将带水印图缩放到与原图匹配。

工具仅支持PNG、BMP格式，JPG格式需先转换为PNG再提取。

单图盲水印提取结果常为镜像、反转或倒序，需手动调整后再识别有效内容。
