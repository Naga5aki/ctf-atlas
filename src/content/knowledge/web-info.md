敏感信息不需要猜路径。先看已经返回的响应、题目附件和源码包里实际存在的文件；主动探测只对本地题目或书面授权目标做，并先留一条随机路径的响应做对照。

> 只对本地题目或授权目标做目录/端口探测；版本与端点以运行中的响应为准，不把扫描器候选直接写成结论。

## 00 30 秒速查

| 我要… | 先看… | 备注 |
|---|---|---|
| 语言/框架 | `Server`/`X-Powered-By`/报错 | 版本可能被改 |
| 隐藏接口 | HTML 注释/JS 里的地址 | 内部主机名 |
| 源码包 | `.env`/`.git`/备份/锁文件 | 看是否被加载 |
| 指纹 | 扩展名/Cookie/默认页 | 需第二处证据 |
| 源站 | DNS/证书/邮件头 | 只产生候选 |
| 是否 CDN | CNAME/多地 A | 单次解析不够 |
| 敏感文件 | 200 + 正文特征 | 与随机路径对比 |
| 自定义 404 | 状态/长度/标题/哈希 | 四项都相同就排除 |
| 工具 | whatweb/EHole/dirsearch | 先被动 |

## 01 原理与成立条件

```text
响应头/正文/报错 → 指纹（语言/中间件/CMS/系统）
源码包/DNS/证书 → 候选路径/候选源站
候选 → 与随机路径或域名正例对照 → 结论
```

| 条件 | 含义 | 不满足时 |
|---|---|---|
| 有响应/材料 | 首页/报错/附件 | 先拿样本 |
| 线索可对照 | 第二处证据 | 只记假设 |
| 探测被授权 | 本地/书面 | 停在被动 |
| 运行态可确认 | 响应/日志 | 以运行态为准 |

## 02 判断与分型

```text
先看已有响应：
 ├─ 头 → 语言/中间件/CDN
 ├─ 正文/注释 → 路径/接口/版本
 └─ 报错 → 绝对路径/依赖
再看材料：
 ├─ 压缩包 → 源码/配置/备份
 ├─ DNS → 源站候选
 └─ 证书 → 子域/源站候选
最后才主动探测：
 └─ 先随机路径基线 → 再扫
```

| 信号 | 含义 | 下一步 |
|---|---|---|
| `X-Powered-By: PHP` | 语言声明 | 看扩展名/报错 |
| `Server: nginx` | 代理/源站自称 | 看配置 |
| 报错含 `/var/www` | 路径/系统 | 对源码目录 |
| `wp-content` | WordPress | 找 `wp-login.php` |
| `rememberMe` Cookie | Shiro 默认名 | 只当假设 |
| `/actuator` JSON | Spring Boot 2+ | 列端点 |
| CNAME 到 CDN | 前面有 CDN | 找源站 |
| 泛解析 | 所有子域同答 | 先排除 |

| 假阳性 | 原因 | 处理 |
|---|---|---|
| `Server` 是 CDN | 边缘节点 | 看源站配置 |
| 无 `X-Powered-By` | 生产关闭 | 看扩展名 |
| Cookie 名撞默认 | 只说明名字 | 看服务端 |
| 扫描器报未授权 | 候选 | 浏览器验证 |
| 200 返回错误页 | 自定义 404 | 四项对照 |

## 03 利用阶梯

### L0 被动收集

**前提**：有首页/报错/题目附件。

**步骤**：
1. 保存首页、登录页、报错页的头与正文。
2. 记 `Server`/`X-Powered-By`/`Set-Cookie`/HTML 注释/JS 接口。
3. 搜公开索引（`site:`/`inurl:`/`filetype:`）只做被动梳理。
4. 不向目标发扫描请求。

**成功标志**：有一份线索清单与来源。

**失败分支**：无响应→拿样本；线索少→L1 指纹。

### L1 指纹与第二证据

**前提**：有响应样本。

**步骤**：
1. 语言：扩展名/报错句式/`X-Powered-By`。
2. 中间件：`Server`/默认错误页/Cookie。
3. CMS/框架：固定路径/特征 Cookie/管理端点。
4. 系统：路径分隔符/换行/发行版字样。
5. 每条假设找第二处证据。

**成功标志**：语言/框架/系统有两条以上证据。

**失败分支**：重写 URL→看日志；CDN 改名→看源站。

### L2 源码包与敏感文件

**前提**：有压缩包/目录/备份。

**步骤**：
1. 列 `.env`/`config`/`.git`/`.svn`/`.DS_Store`/锁文件。
2. 看启动脚本是否加载该配置。
3. 目录列表存在时保存列表，逐个打开允许的文件。
4. 备份与当前页面对照差异。

**成功标志**：找到被运行态使用的配置/源码。

**失败分支**：文件未被加载→看启动命令；无列表→被动/授权扫描。

### L3 DNS、CDN 与源站候选

**前提**：有域名/授权。

**步骤**：
1. 分类型查 A/CNAME/MX/TXT/NS。
2. 两个随机子域判断泛解析。
3. 多地解析/CNAME 判断 CDN。
4. 候选源站用 `--resolve` 与证书 SNI 核对。
5. 只写“会回答该主机名”的结论。

**成功标志**：候选地址返回同一站点/同一叶子证书。

**失败分支**：只有 CDN 地址→历史/子域/邮件头；候选过期→标注。

### L4 目录探测与自定义 404

**前提**：本地/授权环境。

**步骤**：
1. 先请求随机路径 `/atlas-missing-9f3c`，记状态/长度/标题/哈希。
2. 用 dirsearch/whatweb/EHole，参数以 `-h` 为准。
3. 结果与随机路径四项对比，排除错误页。
4. 只人工打开少数候选，记正文特征。

**成功标志**：候选路径返回真实内容而非错误页。

**失败分支**：全 200→自定义 404；全 403→WAF；递归失控→关递归。

## 04 绕过与边界

| 场景 | 边界 | 处理 |
|---|---|---|
| CDN 改名 | `Server` 不可信 | 看源站/证书 |
| 生产关头 | 无 `X-Powered-By` | 扩展名/报错 |
| 泛解析 | 子域全存活 | 两个随机名 |
| 自定义 404 | 200 错误页 | 四项对照 |
| 扫描器候选 | 未验证 | 浏览器打开 |
| `phpinfo` | 可能改名 | 看标题/内容 |
| Actuator | 版本/掩码 | 只记路径/键名 |

边界：`open_basedir` 限制文件函数；`disable_functions` 只禁函数名；`allow_url_include` 与 `allow_url_fopen` 分开；容器路径不等于宿主机。

## 05 非典型入口

| 位置 | 示例 | 注意 |
|---|---|---|
| HTML 注释 | 旧接口/内网名 | 被动 |
| JS 文件 | API/密钥 | 源码 |
| 报错页 | 路径/版本 | 触发 |
| 备份 | `.bak`/`.zip` | 同名 |
| DNS | 历史/泛解析 | 候选 |
| 证书 | SAN/序列号 | 子域 |
| 邮件头 | `Received` | 源站候选 |

## 06 差异速查

| 记录 | 存什么 | 用途 |
|---|---|---|
| A | IPv4 | 落点 |
| CNAME | 别名 | CDN |
| MX | 收信 | 邮件 |
| TXT | 文本 | SPF/验证 |
| NS | 权威 | 历史 |

| 框架 | 特征 | 确认 |
|---|---|---|
| WordPress | `wp-content` | `wp-login.php` |
| Spring Boot | `/actuator` | JSON |
| Shiro | `rememberMe` | 配置 |
| ASP.NET | `__VIEWSTATE` | SessionId |

## 07 工具与验证

| 目标 | 工具/命令 |
|---|---|
| 指纹 | `whatweb -v -a 1 URL` |
| 指纹库 | `ehole -u URL` |
| 目录 | `dirsearch -u URL -e php -t 20` |
| DNS | `dig +short TYPE name` |
| 源站 | `curl --resolve`/`openssl s_client` |
| 记录 | 路径/头/正文特征 |

验证顺序：被动 → 指纹 → 源码 → DNS → 目录。

## 08 实战流程

| 阶段 | 动作 | 产出 |
|---|---|---|
| 1 被动 | 头/正文/注释 | 线索 |
| 2 指纹 | 语言/框架/系统 | 两条证据 |
| 3 材料 | 源码/备份 | 路径 |
| 4 DNS | 记录/泛解析/CDN | 候选 |
| 5 探测 | 随机基线+工具 | 真实路径 |
| 6 记录 | 证据/来源 | 报告 |

## 09 失败分支

| 现象 | 优先怀疑 | 处理 |
|---|---|---|
| 头不可信 | CDN/改写 | 看源站 |
| 指纹冲突 | 改皮肤/重写 | 看日志 |
| 路径全 200 | 自定义 404 | 四项对照 |
| 全 403 | WAF | 降速/停 |
| 子域全存活 | 泛解析 | 随机对照 |
| 源站不通 | 候选过期 | 换候选 |
| 配置未生效 | 未加载 | 看启动 |
