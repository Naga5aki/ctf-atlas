## 一、工具概述

Stegseek 是面向 Steghide 隐写的专用高速分析工具，采用 C++ 原生实现。

**核心定位：** 覆盖 Steghide 算法的字典爆破、隐写检测、种子漏洞利用全场景

**核心优势：** 内置完整解密校验逻辑，无需依赖 steghide 本体；性能远超 stegcracker，单线程每秒可尝试数百万密码，百万级字典可秒级跑完

**支持载体：** 完全兼容 Steghide 格式，包括 JPG、BMP 图片，WAV、AU 音频文件

**底层特性：** 利用 Steghide 32 位随机种子漏洞（CVE-2021-27211）实现无字典检测

## 二、核心命令及参数

**基础调用格式：**

stegseek [选项] 载体文件 字典文件

| 参数分类 | 参数 | 功能说明 |
| --- | --- | --- |
| 基础爆破 | 默认模式 | 字典爆破模式，传入载体与字典文件，破解密码并自动提取隐藏内容 |
| 输出控制 | -o <输出路径> | 自定义隐藏文件的输出路径；默认自动生成 载体文件名.out |
| 检测功能 | --seed | 启用种子暴力枚举，无需字典即可检测隐写存在性、获取隐藏文件元信息 |
| 效率优化 | --continue | 断点续跑，从中断位置继续字典爆破，无需从头遍历 |
| 效率优化 | --threads <数量> | 指定爆破线程数，默认自动适配 CPU 核心数 |
| 日志控制 | -v / --verbose | 详细模式，输出实时进度与调试信息 |
| 通用命令 | -q / --quiet | 静默模式，仅输出最终破解结果 |
| 通用命令 | --help | 查看完整帮助文档 |
| 通用命令 | --version | 查看工具版本信息 |

## 三、应用场景

带密码 Steghide 破解：最核心考点，针对 JPG、BMP、WAV 等载体的密码型隐写，配合字典快速爆破获取密码与隐藏内容

**隐写类型初筛：** 通过 --seed 模式快速判定文件是否包含 Steghide 隐写，用于隐写题的快速分类排查

**大字典高效遍历：** 支持 rockyou 等百万级大字典，数秒即可完成遍历，适配复杂密码、长字典的题目场景

**长任务断点续跑：** 超大规模字典场景下支持中断后续跑，避免重复计算，节省解题时间

**隐写元信息提取：** 无密码场景下，通过种子枚举获取隐藏文件大小、加密属性等信息，辅助解题方向判断

## 四、补充点

**算法限制：** 仅支持 Steghide 隐写，无法破解 Jphide、OutGuess、Jsteg 等其他 DCT 域隐写算法

**依赖特性：** 无需预装 steghide 工具，自身内置完整解密校验逻辑，可独立运行

**性能对比：** 爆破性能约为 stegcracker 的数千倍，是 Steghide 题型的首选爆破工具

**种子模式局限：** --seed 仅可检测隐写存在性与元信息，绝大多数场景无法直接提取隐藏明文，仍需配合密码解密

**常见踩坑：** 载体文件损坏、非 Steghide 加密时工具会直接报错；解题需先确认隐写类型，避免无效尝试

**输出规则：** 破解成功后同时输出密码与提取的文件，默认输出文件与载体文件同目录
