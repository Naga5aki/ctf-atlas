## 一、工具概述

multimon-ng 是 CTF Misc 方向调制类音频隐写的核心解题工具。它支持十余种无线电协议解码，兼容 WAV、RAW 格式音频与管道流输入，可对接 sox、ffmpeg 等工具完成音频预处理，覆盖 DTMF、摩尔斯电码、寻呼协议等绝大多数信号类音频题型，可替代低效的手动频谱分析。

## 二、核心命令及参数

| 参数 | 功能说明 |
| --- | --- |
| -a <解码模式> | 指定解码协议，可多次叠加开启多模式；DTMF、MORSE_CW、POCSAG1200 为 CTF 最高频模式 |
| -t <格式> | 手动指定输入文件格式，支持 wav、raw 等；工具无法自动识别格式，缺省会直接报错 |
| -r <采样率> | 指定输入音频的实际采样率，适配默认值（8000Hz、22050Hz）之外的非标准音频 |
| -q | 开启静默模式，过滤低信噪比误检与冗余日志，仅输出有效解码结果 |
| -h | 查看全部支持的解码模式与完整参数说明 |

| 解题场景 | 标准执行命令 |
| --- | --- |
| 标准 WAV 格式 DTMF 解码 | multimon-ng -a DTMF -t wav 目标文件.wav |
| 摩尔斯电码（CW）解码 | sox 目标.wav -t raw -r 22050 -e signed -b 16 -c 1 - \| multimon-ng -a MORSE_CW -t raw - |
| POCSAG1200 寻呼协议解码 | multimon-ng -a POCSAG1200 -t raw 目标.raw |
| AFSK1200 数据包解码 | sox 目标.wav -t raw -r 22050 -e signed -b 16 -c 1 - \| multimon-ng -a AFSK1200 -t raw - |
| 多模式联合盲测排查 | multimon-ng -a DTMF -a MORSE_CW -a POCSAG1200 -t raw 目标.raw |
| 解码结果保存到文件 | multimon-ng -a DTMF -t wav -q 目标.wav > result.txt |
| 从视频中提取音频直接解码 | ffmpeg -i 视频.mp4 -vn -acodec pcm_s16le -f wav - \| multimon-ng -a DTMF -t wav - |

## 三、应用场景

DTMF 双音多频隐写：flag 编码为电话按键序列，音频为间断双音信号；可快速解码长时长拨号音频，输出按键序列与对应时间戳。

**摩尔斯电码隐写：** 通过长短单频脉冲编码字符；自动解调 CW 等幅电报信号，输出点划序列，替代手动数拍解码。

POCSAG 寻呼协议隐写：flag 隐藏在寻呼数据报文中；支持 512/1200/2400 三种标准波特率，可直接解码寻呼帧内容。

AFSK/FSK 频移键控隐写：常承载 AX.25 业余无线电协议；解调频移键控信号，提取原始报文与 flag。

**选呼信令隐写：** 对应 ZVEI、CCIR 等调度电台单音编码；解码单频序列得到数字类 flag。

**批量自动化解题：** 适用于长时长音频、多文件批量处理、视频内嵌音频等场景；通过管道联动工具实现无中间文件的自动化解码，大幅提升解题效率。

## 四、补充点

标准解题流程

**初筛定位：** 用 Audacity 查看波形与频谱，排除 LSB 隐写、频谱图隐写，确认为调制类信号；

**格式预处理：** 用 sox 将音频转为 16 位单声道 22050Hz 的 RAW 格式，兼容全部解码模式；

**高频盲测：** 叠加 DTMF、MORSE_CW、POCSAG1200、AFSK1200 四个高频模式批量测试；

**参数精调：** 无结果则测量信号波特率与中心频率，切换对应解码模式，调整采样率参数；

**结果校验：** 整理输出内容，完成去重纠错，提取最终 flag。

高频避坑指南

**声道限制：** 仅支持单声道解码，立体声文件仅解析左声道，需先转单声道避免信号丢失；

**采样率适配：** 默认适配 22050Hz 采样率，非标准采样率会导致无输出或乱码，需用-r参数指定；

**频率偏移：** 信号频率偏移过大时自动解码失效，需手动测量频率后调整，或切换人工频谱分析；

**噪音干扰：** 低信噪比会产生大量误码，需先做降噪处理再解码；

**模式冲突：** 同时开启过多解码器易产生误判，优先测试高频考点模式。
