## 一、核心命令与参数

| 分类 | 参数/命令格式 | 功能说明 |
| --- | --- | --- |
| 基础初筛 | mediainfo <目标文件> | 输出文件通用属性、视频 / 音频 / 图片 / 字幕流的基础结构与核心参数 |
|   | mediainfo <文件1> <文件2> [文件3...]支持通配符 *.mp4 | 同时输出多个文件的媒体信息，支持批量匹配 |
| 深度扫描 | -f / --Full | 全层级完整扫描，输出所有字段、隐藏元数据、私有标签、异常偏移、填充数据 |
| 结果输出 | --Output=JSON--Output=XML--Output=CSV | 以结构化标准格式输出结果 |
|   | > <输出文件路径>（Shell 重定向） | 将扫描结果保存到本地文本文件 |
| 定向提取 | --Inform="<流类型>;%<字段名>%" | 定向提取指定流的单个或多个参数，过滤所有冗余信息 |
|   | mediainfo --Inform="General;%Comment%" <目标文件> | 提取文件通用注释字段 |
|   | mediainfo --Inform="Image;%Width%x%Height% %Format%" <图片文件> | 提取图片尺寸与编码格式 |
|   | mediainfo --Inform="Video;%Width%x%Height% %FrameRate%" <视频文件> | 提取视频分辨率与帧率 |
|   | mediainfo --Inform="Audio;%SamplingRate% %Channels%" <音频文件> | 提取音频采样率与声道数 |
| 辅助查询 | --Info-Parameters | 列出所有支持提取的参数字段与对应说明 |
|   | --Version | 查看 mediainfo 版本信息 |
|   | --Help | 查看完整帮助文档与全参数列表 |

## 二、应用场景

### 1.识破后缀伪造，识别真实格式

不依赖文件后缀名，直接读取文件头与内部流结构输出真实编码类型，重点参考 Format、Codec ID 字段。可快速破解 MP4 改图片、音频改文本、压缩包伪装成媒体等常见套路，避免 file、binwalk 等工具因后缀误导出现误判。

### 2.检测结构异常，定位隐写篡改线索

**宽高篡改排查：** 可识别文件头显示宽高被修改的情况，非标准分辨率、奇数尺寸等异常值，通常意味着超出正常显示区域的像素中藏有数据，后续可定向提取完整像素内容。

**隐藏流检测：** 完整枚举所有音视频、字幕、私有数据轨道，普通播放器默认不显示的隐藏音频流、字幕流、空数据流均可被检出，发现额外流后可直接用 ffmpeg 定向提取分离。

**元数据藏信定位：** 全量扫描可读出注释、标题、编码器、自定义私有标签等隐藏字段，大量题目会直接将 flag、提示信息藏在这些常规视图不可见的元数据位置。

**参数失配校验：** 正常媒体文件的大小、比特率、时长三者数值匹配，若出现比特率异常偏高、时长为 0 或与体积严重不符，说明文件内填充了额外隐藏数据，需进一步做分离提取。

### 3.初筛隐写手法，缩小分析范围

**图片类：** 通过位深度、色彩空间、压缩模式预判风险，异常位深度、非常规压缩参数往往提示存在 LSB 隐写、数据嵌入。

**视频类：** 通过帧率、关键帧间隔、总帧数与时长的匹配度判断，帧率异常偏低、帧间隔反常大概率存在单帧藏图、单帧藏字。

**音频类：** 通过采样率、位深度、声道数、静音段特征排查，参数偏离标准值、存在异常长静音段时，优先排查频谱隐写、LSB 隐写。

### 4.校验文件状态，识别损坏与伪加密

可识别文件头损坏、内容截断导致的格式未知、参数缺失、信息乱码等完整性问题；也能鉴别伪加密场景 —— 播放器提示加密但文件实际无加密标记，确认后可直接重新封装解封，无需额外破解操作。
