## 一、适用范围及原理

**工具定位：** 轻量型 DTMF 专属解码工具，是  DTMF 音频隐写的首选工具，，非标准信号兼容性优于通用型工具 multimon-ng。

**核心原理：** 检测音频中的双音多频信号，匹配标准 DTMF 高低频率对，输出对应按键字符，无额外冗余功能。

**格式边界：** 仅支持 16 位线性 PCM 编码的 WAV 格式音频，不兼容 MP3、AAC 等压缩格式与其他位深编码的 WAV 文件。

**核心优势：** 最高容忍 50Hz 频率偏移、自动合并左右声道信号、内置长按键自动去重、基础命令即可覆盖绝大多数题型。

## 二、使用方法

| 参数 | 功能说明 | 取值与默认值 |
| --- | --- | --- |
| 无参数（基础模式） | 直接输出连续的 DTMF 按键序列，无冗余信息 | - |
| -v | 详细模式，输出每个按键的低频、高频值与时间戳，用于排查解码问题 | - |
| -t <阈值> | 调整检测阈值：阈值越高抗噪性越强、漏检率越高；阈值越低灵敏度越高、误检率越高 | 取值 0~1，默认 0.5 |
| -s <毫秒> | 设置最小识别按键时长，过滤时长过短的无效信号 | 单位 ms，默认 50ms |
| -r <采样率> | 手动指定音频采样率，解决格式不标准导致的采样率识别错误 | 单位 Hz，默认自动识别 |

常用命令示例

### 1.标准 DTMF 音频基础解码

dtmf2num.exe 目标文件.wav

### 2.详细模式排查解码异常

dtmf2num.exe -v 目标文件.wav

### 3.高噪音场景调高检测阈值

dtmf2num.exe -t 0.7 目标文件.wav

### 4.超短按键场景调低识别时长

dtmf2num.exe -s 20 目标文件.wav

### 5.配合 ffmpeg 直接解码视频内嵌 DTMF 信号

ffmpeg -i 视频文件.mp4 -vn -acodec pcm_s16le -f wav - | dtmf2num.exe -

## 三、应用场景

标准 DTMF 隐写题：flag 编码为电话按键序列，音频为标准双音拨号信号；基础命令即可一键输出完整按键序列。

非标准 DTMF 进阶题：包含频率偏移、弱信号、超短按键等陷阱的进阶题型；通过调整阈值、最小时长、采样率等参数适配，解决通用工具解码失败的问题。

视频内嵌 DTMF 信号题：DTMF 信号隐藏在视频音轨中；配合 ffmpeg 直接提取音轨解码，无需导出单独音频文件，提升解题效率。

批量 DTMF 文件处理：多段音频分别藏有 flag 片段的题型；可编写批处理脚本批量解码全部文件，自动汇总结果。

## 四、补充点

### 1. 高频坑点与解决方案

**格式不兼容：** 非 16 位 PCM 编码的 WAV、压缩格式音频会报错或无输出；用 Audacity 导出为 16 位 PCM 编码的 WAV 格式后再解码。

**信号强度过弱：** DTMF 信号音量极低、被噪音淹没导致无输出；先用 Audacity 放大音频音量，配合调低检测阈值解码。

**按键间隔过短：** 相邻按键无静音间隔，被识别为单个按键；开启详细模式查看频率变化，手动区分不同按键。

**自定义频率映射：** 非标准频率对应关系的难题，自动解码输出乱码；通过详细模式提取全部频率对，手动推导映射关系解码。

### 2. 工具选型原则

遵循 “先 dtmf2num，后 multimon-ng，最后手动解码” 的优先级：

时长小于 30 秒的 DTMF 音频，优先使用 dtmf2num 快速验证；

dtmf2num 解码失败时，尝试 multimon-ng 调整参数适配；

所有自动工具失效时，使用 Audacity 手动频谱分析，可解决全部 DTMF 题型。

### 3. 标准解题流程

**格式校验：** 确认音频为 WAV 格式，非标准格式先转码为 16 位 PCM 编码 WAV；

**快速解码：** 执行基础命令尝试一键输出按键序列；

**调参适配：** 解码失败时，依次尝试详细模式排查、调整阈值、调整最小时长、指定采样率；

**结果验证：** 校验输出序列，提取 flag 或进一步线索；

**方案降级：** 仍无结果时切换 multimon-ng 或手动频谱分析。
