## 一、工具概述

PdfStreamDumper 是面向 PDF 底层结构的专业分析工具。它主打 PDF 对象级深度解析，核心能力覆盖压缩流解压、内嵌资源提取、JavaScript 反混淆、格式异常修复、加密状态鉴别五大类，可适配流隐写、文件嵌套、JS 混淆、伪加密、格式畸形等绝大多数 PDF 高频考点。

## 二、核心功能与使用

| 功能标签 | 核心作用 |
| --- | --- |
| Objects | 枚举全部 PDF 间接对象，自动将异常、加密对象标红高亮，帮助快速定位隐写点位 |
| Streams | 展示所有流数据，支持 FlateDecode、LZWDecode 等多种压缩过滤器的一键解压，直接查看流内明文 |
| Embedded Files | 识别 PDF 内嵌的隐藏附件，支持提取压缩包、图片、文档等各类嵌套文件 |
| Javascript | 提取 PDF 内嵌的全部 JS 代码，支持一键格式化、反混淆，还原代码执行逻辑 |
| Security | 查看 PDF 加密配置信息，可快速区分伪加密与标准真加密 |
| Headers / Repair XREF | 检查修复 PDF 文件头标识，修复损坏的交叉引用表，解决格式篡改导致的文件无法打开问题 |
| Text / Annotations / Metadata | 分别提取全量文本内容、隐藏注释、文档元数据，覆盖常规阅读器的视觉盲区 |

## 三、核心应用场景

### 1.压缩流隐写破解

**出题套路：** flag 或编码线索藏匿于 FlateDecode 等压缩流中，普通 PDF 阅读器无法直接读取内容。

**实战用法：** 切换至 Streams 标签，选中标红或体积异常的流对象，右键执行 Decode Stream 解压，在预览区检索 flag 等关键字获取线索。

### 2.内嵌隐藏文件提取

**出题套路：** PDF 内部嵌套压缩包、图片、文档等附件，常规解压工具无法识别，常伴随二次隐写。

**实战用法：** 在 Embedded Files 标签选中目标文件，一键提取到本地，继续开展压缩包爆破、图片隐写等后续分析。

### 3.JavaScript 隐写反混淆

**出题套路：** flag 经字符串拆分、编码转换、变量重命名等 JS 混淆手法藏匿，打开文档无直接显示。

**实战用法：** 切换至 Javascript 标签，对目标代码执行格式化，梳理运算逻辑，提取隐藏的字符串或解密结果。

### 4.畸形 PDF 格式修复

**出题套路：** 通过篡改文件头、破坏交叉引用表等方式制造畸形 PDF，导致常规工具无法打开，遮蔽隐写内容。

**实战用法：** 通过 Headers 标签修复文件头，使用 Repair XREF 功能修复交叉引用表，恢复文件可解析性后继续分析。

### 5.真伪加密快速鉴别

**出题套路：** 混淆伪加密与真加密题型，误导考生执行无意义的密码爆破。

**实战用法：** 在 Security 标签查看加密详情，仅有加密标记无有效算法为伪加密，可直接修复；存在完整加密算法（如 AES-256）为真加密，需搭配密码破解工具处理。

### 6.隐藏文本与元数据排查

**出题套路：** flag 藏于同色文本、注释、自定义文档属性中，常规浏览无法发现。 实战用法：分别通过 Text、Annotations、Metadata 标签提取对应内容，排查文本类隐藏线索。
