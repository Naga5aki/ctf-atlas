## 一、工具定位

gnuplot 是 CTF Misc 方向的轻量命令行数据可视化工具，可将文本格式的坐标数据、时序数值转换为可视化图形，用于还原点阵隐写的二维码、文字图案，解析波形类编码信号，是坐标点隐写、时序数据分析类题型的核心必备工具。

## 二、进入与退出程序

**交互式模式：** 终端输入gnuplot回车，进入交互式命令环境，提示符为gnuplot>，所有绘图操作在此环境内执行。

**单命令执行：** 终端直接执行gnuplot -persist -e '绘图命令'，其中-persist用于防止执行完成后图形窗口自动闪退。

**退出程序：** 交互环境内输入exit或quit回车，返回系统终端。

三、核心命令及参数

| 分类 | 命令/参数 | 功能说明 | 适用场景 |
| --- | --- | --- | --- |
| 基础绘图 | plot "data.txt" with points pointtype 7 pointsize 0.5 | 散点模式绘图，采用实心圆点样式，可调整点大小 | 坐标点隐写题必用，避免连线破坏二维码 / 图案结构 |
| 基础绘图 | plot "wave.txt" with lines | 连线模式绘制连续波形 | 单列时序数据、音频采样、电平信号可视化 |
| 范围控制 | plot [xmin:xmax][ymin:ymax] "data.txt" ... | 限定横纵坐标取值范围 | 匹配题目坐标区间，防止图案拉伸变形 |
| 画面调试 | set yrange reverse + replot | 翻转 Y 轴方向 | 修正像素坐标类题目（原点在左上角）上下颠倒的问题 |
| 纯净画面 | unset key / unset border / unset xtics / unset ytics | 分别关闭图例、边框、X 轴刻度、Y 轴刻度 | 还原二维码 / 图案时，排除多余元素干扰识别 |
| 刷新重绘 | replot | 刷新当前画面，使修改的参数生效 | 调试参数时快速更新图像，无需重复输入完整命令 |
| 格式设置 | set terminal png size 宽,高 | 设置输出格式为 PNG，指定分辨率 | 导出高清结果图；还原二维码建议匹配坐标尺寸 |
| 文件输出 | set output "result.png" | 指定输出的图片文件名 | 将绘图结果保存到当前目录 |
| 模式切换 | set terminal x11 + unset output + replot | 导出完成后切回交互窗口模式 | 保存图片后恢复交互式绘图环境 |
| 辅助操作 | reset | 重置所有参数为默认值 | 切换题型时清空配置，避免参数残留影响 |
| 辅助操作 | clear | 清空当前绘图画面 | 重新绘制前清理画布 |
| 辅助操作 | show xrange / show terminal | 查看指定参数的当前配置 | 调试时确认参数状态 |

## 三、应用场景

**坐标点隐写还原：** 处理由大量 (x,y) 数值对组成的文本文件，还原隐藏的二维码、文字或图案 Flag；支持空格、逗号、制表符分隔的数据格式，无需额外预处理。

波形 / 时序数据可视化：处理单列纯数值数据（如音频采样值、高低电平、二进制流），自动以行号为 X 轴、数值为 Y 轴绘制波形；用于识别摩斯电码、周期编码、频谱特征。

**脚本化批量绘制：** 将全套绘图命令写入.gp脚本文件，终端执行gnuplot 脚本文件名.gp即可一键出图；适用于需要反复调试参数的题目，提升解题效率。

## 四、补充点

**窗口闪退问题：** 单命令行执行必须添加-persist参数；远程 SSH 连接环境需开启 X11 转发。

**图案变形问题：** 还原二维码 / 图案时，必须严格匹配题目给定的坐标范围，禁止随意缩放，避免点位错位导致无法识别。

**乱线问题：** 坐标点隐写题型必须指定with points散点模式，禁止使用默认连线模式，否则会破坏点阵结构。

**文件读取失败：** 优先切换到目标文件所在目录执行命令，文件路径避免包含中文和空格。

**无图形窗口问题：** 确保图形终端设置为 x11；远程服务器环境需配置 X11 转发才能显示绘图窗口。

**调试技巧：** 修改任意参数后，只需执行replot即可刷新画面生效，无需重复输入完整绘图命令。
