## 一、工具概述

JPEGsnoop 是 JPEG 图像专业底层取证分析工具，具备标记段解析、元数据提取、编辑痕迹检测、异常数据块定位、频域隐写特征识别能力。

## 二、使用方法

| 功能标签 | 功能说明 |
| --- | --- |
| Main View | 展示文件基础信息与标记段列表，快速定位结构异常点 |
| Metadata | 提取 EXIF、IPTC、XMP 全量元数据，覆盖隐藏注释与自定义字段 |
| Structure | 可视化呈现分块结构，支持查看 APP 段、量化表、哈夫曼表等核心参数 |
| Analysis | 输出压缩签名比对结果，检测二次编辑痕迹，辅助判断频域隐写 |
| Hex View | 十六进制原始数据视图，支持定位文件头、尾及指定偏移字节 |

## 三、应用场景

**元数据隐写排查：** 针对 flag 藏匿于元数据字段的题型，在 Metadata 标签检索关键字，提取编码线索，为基础排查入口。

**频域隐写检测：** 通过 Analysis 标签比对压缩签名，识别量化表、哈夫曼表异常，预判隐写类型，指导后续破解。

**畸形文件修复：** 针对文件头 / 尾缺失、宽高篡改导致的无法打开问题，结合标记段列表与十六进制视图修复格式。

APP 段隐写提取：在 Structure 标签定位异常 APP 段，导出分段原始数据，解析隐藏内容与嵌套文件。

**真伪隐写鉴别：** 结合结构完整性、压缩特征快速区分真伪隐写，规避无效破解操作。
