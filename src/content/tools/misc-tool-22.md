## 一、工具概述

7-Zip（简称 7z）是开源跨平台的高兼容压缩解压工具，Windows 与 Linux 系统均可稳定运行，Kali Linux 中可通过7z命令直接调用。它支持 ZIP、RAR、7z、TAR、GZIP 等几乎所有主流压缩格式，除基础解压外，还具备压缩包状态检测、真伪加密识别、注释读取、轻微损坏修复、分卷与多层嵌套处理等能力。

在 CTF Misc 赛道中，7z 是所有压缩包类题目的首选前置工具，优先级高于系统自带的 unzip、unrar。

## 二、核心命令及参数

| 分类 | 命令格式 | 功能说明 |
| --- | --- | --- |
| 基础解压 | 7z x <目标压缩包> | 完整解压，保留原始目录结构 |
|   | 7z x <目标压缩包> -p<密码> | 指定密码解压加密压缩包 |
|   | 7z e <目标压缩包> | 解压所有文件至当前目录，不保留原目录结构 |
| 信息检测 | 7z l <目标压缩包> | 不解压直接列出包内文件名、大小、压缩方式、加密状态 |
|   | 7z l -slt <目标压缩包> | 输出详细技术信息，包含压缩包注释内容 |
|   | 7z t <目标压缩包> | 测试压缩包完整性，检测 CRC 错误、数据损坏 |
| 修复与特殊处理 | 7z r <损坏压缩包> | 尝试修复结构损坏的压缩包，重建文件索引 |
|   | 7z x <分卷首文件> | 自动识别分卷序列，合并解压完整文件 |
| 辅助功能 | 7z a <输出压缩包> <待压缩文件> | 将指定文件打包生成压缩包 |
|   | 7z --help | 查看完整帮助文档与参数说明 |

## 三、实战应用场景

### 1.常规压缩包内容提取

从图片隐写、文件分离、流量分析中得到的压缩包，通过 7z 直接解压获取内部文件。

2.ZIP 伪加密快速鉴别与绕过

当系统 unzip 提示需要密码时，用 7z 尝试解压，若可直接无密码解压，即可判定为伪加密，无需修改十六进制或使用修复工具，是最快的伪加密验证手段。

### 3.真加密状态确认与衔接破解

若 7z 强制要求输入密码、无密码无法读取任何内容，可判定为真加密。7z 负责确认加密状态，后续通过 2john 脚本配合 John the Ripper 破解密码，得到密码后再用 7z 完成最终解压，二者形成完整解题链路。

### 4.压缩包注释线索提取

部分题目将密码、flag 片段、解题提示隐藏在压缩包注释中，常规解压不会自动显示。通过 7z 的详细信息查看功能可直接读取注释。

### 5、损坏压缩包应急修复

针对头部被篡改、尾部轻微截断、索引损坏的压缩包，7z 可尝试重建文件结构完成修复，无需手动编辑十六进制，快速恢复可解压状态。

### 6、特殊压缩包场景处理

**多层嵌套压缩包：** 可配合 Shell 循环脚本实现全自动逐层解压，避免手动重复操作。

**分卷压缩包：** 自动识别分卷序列并合并解压，只需操作首个分卷文件，无需手动拼接二进制数据。

**异常文件识别：** 通过文件列表快速定位名称、格式异常的隐藏文件，避免遗漏考点。

## 四、补充考点

分卷压缩必须将所有分卷文件置于同一目录，仅操作单个分卷会解压失败。

文件路径含中文、空格、特殊符号时可能出现识别异常，建议重命名为纯英文短文件名。

7z 可直接解压的伪加密场景，无需额外使用破解工具或手动修改十六进制，避免浪费时间。

7z 仅能修复轻微结构损坏，数据严重丢失时无法恢复，需回到输入文件排查完整性。
