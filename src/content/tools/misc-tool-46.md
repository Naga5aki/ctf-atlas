## 一、工具概述

apngdis 是 APNG 动画格式的官方标准拆解工具，是 CTF 中 APNG 隐写题型的专属核心工具。它可完整提取 APNG 的全部帧像素数据与帧元数据，而 binwalk、通用压缩工具、普通图片查看器均会丢失关键帧信息，无法替代该工具。

## 二、使用方法

### 1. APNG 格式识别

满足任意一条即可判定为 APNG 格式，需使用 apngdis 处理：

执行pngcheck 目标文件，结果包含 acTL（动画控制块）、fcTL（帧控制块）、fdAT（帧数据块）任一标识

执行binwalk 目标文件，扫描出多条 PNG image data 条目且数量大于 1

浏览器打开为动态动画，普通图片查看器仅显示静态第一帧

文件体积显著大于同分辨率普通 PNG，且所有静态 PNG 隐写方法均无效

### 2. 拆解命令

**命令格式：**

apngdis 目标文件

无额外参数，自动完成全量拆解；目标文件后缀无限制，只要文件内容为 APNG 格式即可正常解析。

### 3. 输出文件说明

拆解后生成两类文件，数量与 APNG 总帧数完全一致：

**帧图片文件：** 命名格式为frame001.png、frame002.png…… 按播放顺序从 1 开始编号，为独立完整的 PNG 文件，包含完整像素与透明通道信息

**帧元数据文件：** 命名格式为frame001.txt、frame002.txt…… 与同名图片帧一一对应，记录该帧的技术参数

### 4. 核心元数据字段

delay_num：帧延迟时间的分子，整数类型

delay_den：帧延迟时间的分母，整数类型

实际播放延迟 = delay_num / delay_den，单位为秒；绝大多数 CTF 题目中delay_den固定为 1000，即延迟数值等于delay_num毫秒

## 三、应用场景

### 1. 帧内容隐写

**特征：** flag 的全部或部分内容直接绘制在某一帧或多帧的像素上，第一帧为无关的诱饵图片。

**解法：** 拆解后按编号顺序逐帧查看图片，定位包含文字、二维码、异常图案的帧；flag 分散时，按帧编号顺序拼接所有片段。

### 2. 帧延迟时间隐写

**特征：** 所有帧的图片内容完全一致，无肉眼可见差异，仅delay_num数值不同。 解法：按顺序提取所有帧的delay_num值，将两类固定数值分别映射为二进制 0 和 1，得到完整二进制串后按 8 位一组转换为 ASCII 字符。

### 3. 帧差分隐写

**特征：** 所有帧的画面高度相似但不完全相同，且所有帧的延迟参数完全一致。

**解法：** 使用 StegSolve 的 Image Combiner 功能，对相邻帧执行 XOR 或 Subtract 运算，从差分结果中提取 flag；无结果时更换帧组合继续验证。

### 4. 透明通道隐写

**特征：** 所有帧的画面与延迟时间均无明显异常。

**解法：** 逐帧查看图片的 Alpha 透明通道，flag 直接隐藏在某一帧的 Alpha 通道中。

## 四、补充点

### 1. 标准解题流程

pngcheck 确认 APNG 格式 → apngdis 拆解文件 → 查看前 10 帧图片内容 → 提取并分析所有帧的延迟时间 → 对相邻帧做差分运算 → 逐帧检查 Alpha 透明通道

### 2. 避坑指南

禁止用 binwalk 分离 APNG：仅能提取第一帧数据，会永久丢失后续所有帧

**禁止用截图工具逐帧采集：** 会丢失精确的延迟时间数值，且像素重采样会导致差分、通道分析完全失效

不可忽略 txt 元数据文件：半数以上 APNG 题目的 flag 隐藏在延迟时间参数中
