## 1. 版本、权限与对象

Oxygen Forensic Detective 的界面和支持范围随版本变化，先核对授权、驱动、设备型号、系统/补丁和输入格式。Device Extractor、Cloud Extractor、KeyScout、KeyDiver 与分析主程序承担不同任务，目录与菜单以实际版本为准。

| 材料 | 入口方向 | 要保存的条件 |
| --- | --- | --- |
| 手机、SIM/存储卡 | Device Extractor | 设备、系统、锁定状态、所选提取方法与覆盖 |
| 备份/镜像/已有提取 | Import | 格式、加密条件、解析版本与失败项 |
| 云端材料 | Cloud Extractor | 实际授权账号、时间范围、可取得服务与采集结果 |
| Windows/macOS/Linux | KeyScout | 活体/镜像、搜索配置、系统/应用/凭据范围 |
| 无人机、IoT | 对应设备/备份/日志入口 | 设备、控制端、记录范围与时间 |
| 加密文件/分区 | KeyDiver 等 | 格式、候选范围、密钥条件和验证结果 |

云提取会对外部账户产生请求，本文只说明适用条件；已有令牌不代表所有云数据已取得。锁屏旁路和物理提取也依设备/补丁支持，不能推定通用可用。

## 2. 提取与导入的顺序

先固定材料及哈希 → 选择确切对象/格式 → 设置案件与输出 → 保存提取/导入日志 → 检查完整与失败项 → 复核记录。导入列表中出现某应用，只说明工具可尝试解析，不表示设备一定安装了它。

选择性分析可减少耗时，但要记录跳过的应用和范围。后续有新问题再重新解析对应副本，不把局部导入结果写成“全设备没有该数据”。不同提取合并前保存原有提取标识，区分数据级与文件系统级合并、冲突和去重规则。

## 3. KeyScout 与 KeyDiver

KeyScout 可按系统痕迹、应用、口令/令牌、路径和内存配置搜索。活体采集、磁盘捕获、RAM 与外部盘采集是不同入口；每个任务记录对象、范围、权限、大小、输出和哈希，采集变化另存操作记录。

KeyDiver 先识别格式和支持算法，再配置字典、规则、掩码、攻击顺序、资源/温度限制与停止条件。自定义字典可从已确认的案件线索整理，保存搜索边界与任务状态；验证命中后文件确实可解析，不只接受口令提示。

## 4. 分析模块与核验点

| 模块 | 操作重点 | 复核 |
| --- | --- | --- |
| 时间线 | 选择设备/数据类、时间范围、事件，查看详情 | 不同时间字段、时区与缺失范围 |
| 社交图谱 | 账户、联系人、通话与消息关联 | 合并同人账户必须有证据，连接不等于关系性质 |
| 文本/语音识别 | 选定媒体、语言和任务，检查结果 | OCR/转录错误需回到画面/音频人工核对 |
| 人脸/图片分类 | 候选分组、相似度、分类与视频帧 | 自动识别只提供候选，保留阈值和范围 |
| 标签/关键证据 | 标记并注释已确认记录，筛选报告 | 自动分类与人工判断分开 |
| 全文/模式搜索 | 关键词、账号、邮箱等模式及范围 | 保存命中上下文、编码、重复与误报 |
| 统计 | 提取、应用、数据类和筛选数量 | 明确分母与去重规则 |
| 恶意软件分析 | 配置本地扫描范围和结果 | 标签需静态/行为证据复核，不执行候选文件 |
| 地图/地理数据 | 设备、数据来源、坐标、轨迹和时间 | 坐标系、精度、同步与反向地理编码条件 |
| SQLite 查看器 | 先表/schema，再记录与 SQL | DB/WAL、加密参数、删除/恢复状态 |

无人机分析将设备日志、飞行 App、控制端备份、媒体与地图对应到同一次飞行。Alexa、Google Home、Ring 等 IoT 数据需要实际取得的设备/账号材料；不能把一个账号记录推断成全部设备行为。

## 5. 设置与报告

核对电话号码判定、显示格式、语言、时区和高级分析配置。导出时选择案件/设备、标签、数据类型、附件和格式，保存报告配置；JSON/XML/CSV 等机器可读结果与 PDF/HTML 展示报告互补。

报告交付前抽查消息方向、账户、原始时间、附件哈希和逻辑路径；数值统计检查去重。Viewer 用于查看分享的分析结果，授权与包含范围依版本确认。图谱、地图或自动翻译不能代替可回溯的原记录。
