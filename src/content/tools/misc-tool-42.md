## 一、适用范围及原理

**隐写原理：** 基于 LSB（最低有效位）隐写技术，通过修改像素、音频采样点的最低二进制位藏匿数据，修改幅度极小，不影响媒体文件的正常显示与播放；但隐藏数据会被有损压缩算法破坏。

**格式边界：** 仅兼容无损压缩或未压缩的媒体格式，绝对无法处理 JPG 等有损压缩格式，强行处理仅会得到乱码或报错。CTF 实战中高频适用格式为 PNG、BMP、GIF、WAV，其中 PNG 与 WAV 占 LSB 隐写考点 90% 以上。

**格式特性：**

GIF 格式：支持自动遍历所有帧的 LSB 位并拼接为完整数据，是多数同类工具不具备的能力

WAV 格式：仅支持 PCM 编码的原始 WAV 文件；经 MP3 压缩后转存的 WAV，其 LSB 位已被压缩破坏，无法提取有效数据

## 二、使用方法

| 功能分类 | 命令格式 | 功能说明 |
| --- | --- | --- |
| 隐写检测 | stegpy info 载体文件名 | 快速检测文件内是否存在隐藏数据，输出数据大小、格式及加密状态，避免盲目提取 |
| 无密码提取 | stegpy extract 载体文件名 输出文件路径 | 提取未加密的隐藏数据，写入指定输出文件 |
| 加密提取 | stegpy extract 载体文件名 输出文件路径 -p 密码 | 针对 AES-256 加密的 LSB 隐写，指定密码后自动完成解密与数据提取 |

## 三、应用场景

基础无密码 LSB 隐写提取：flag 文本、压缩包、二维码等直接藏匿于载体最低位，无加密；先执行 info 检测再提取，无需额外参数，可快速解题。

加密 LSB 隐写提取：StegPy 的核心差异化优势，支持自带 AES-256 加密的 LSB 隐写；zsteg、StegSolve 等工具仅能提取加密乱码，StegPy 通过密码参数可一步解密；实战中可先尝试通用弱密码，结合题目线索定位密码，也可编写 Python 脚本批量爆破。

WAV 音频 LSB 隐写提取：兼容单声道与立体声 PCM 格式 WAV，自动提取音频采样点最低有效位数据，解题流程与图片隐写一致，弥补多数工具音频 LSB 支持不完善的短板。

**批量隐写处理：** 可结合 Shell 脚本，批量提取大量图片 / 音频文件中的分片隐藏数据，自动拼接完整 flag，适用于 flag 拆分藏匿的综合题型，大幅提升解题效率。

## 四、补充点

标准解题流程

**格式校验：** 若为 JPG 格式直接排除 StegPy 适用范围，转向频域隐写、文件尾追加隐写方向排查；PNG、BMP、GIF、WAV 格式继续检测。

**快速检测：** 执行 info 命令确认隐藏数据的存在性与加密状态。

**提取验证：** 未加密直接提取查看结果；已加密则先尝试通用弱密码，结合题目线索推导密码后提取。

**互补排查：** 若 StegPy 未检测到数据，但 LSB 位平面可视化存在异常，说明为自定义 LSB 隐写算法，需手动分析位平面或编写专用脚本提取。

避坑指南

**路径规范：** 文件路径与输出路径禁止包含中文、空格及特殊字符，否则会导致读写失败。

**版本兼容：** 不同版本 StegPy 的加密算法、隐写格式存在差异，旧题目无法提取时，可尝试 0.9.3 等经典稳定版本。

**密码特性：** 密码验证大小写敏感，需与隐藏时的密码完全一致，否则提取失败。

**数据限制：** 理论支持最大等于载体大小的隐藏数据，但数据过大会导致载体异常，提取时可能出现截断、损坏。
