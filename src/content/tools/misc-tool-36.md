## 一、工具定位

ffmpeg 支持格式修复、逐帧提取、音轨分离、元数据读取、变速剪辑、裸流封装、字幕提取等全维度操作，覆盖绝大多数音视频隐写与分析考点。

## 二、核心命令及参数

| 功能场景 | 命令格式 | 关键参数说明 |
| --- | --- | --- |
| 畸形文件修复 | ffmpeg -i 输入文件 输出文件 | -i 指定输入文件；自动重新封装，修复损坏的容器结构 |
| 视频逐帧提取 | ffmpeg -i test.mp4 frame_%04d.png | %04d 生成 4 位数字序号的序列图片文件名 |
| 分离音频轨道 | ffmpeg -i test.mp4 -vn audio.wav | -vn 关闭视频流，仅提取并保留音频流 |
| 音视频片段裁剪 | ffmpeg -i 输入文件 -ss 起始时间 -t 时长 输出文件 | -ss 指定截取起始时间；-t 指定截取时长 |
| 查看完整元数据 | ffmpeg -i test.mp4 -f null - | -f null - 采用空输出格式，仅解析并打印全部元数据 |
| 音频变速还原 | ffmpeg -i 输入.wav -atempo 倍速 输出.wav | -atempo 设置音频播放倍率，如 0.5 为减速一半 |
| 提取内嵌字幕 | ffmpeg -i test.mp4 -c:s copy out.srt | -c:s copy 直接复制字幕流，无损导出字幕文件 |
| 裸流封装格式 | ffmpeg -f 格式 -i raw.bin out.mp4 | -f 强制指定输入裸流的编码格式 |

## 三、应用场景

**畸形文件修复：** 处理文件头篡改、后缀伪造、容器结构损坏、部分帧丢失的异常音视频，通过重新封装修复基础格式，将无法打开的畸形文件还原为可解析的标准格式，是音视频题的首选预处理步骤。

**单帧隐写排查：** 应对闪现文字、帧内二维码、半透明水印、帧间差异藏信息等高频视频隐写题型，全量导出逐帧图片后，可配合图片对比工具快速定位异常帧，精准捕捉肉眼无法识别的瞬时线索。

**音频隐写预处理：** 支持从单音轨、多音轨视频中剥离独立音频流，导出无损 WAV 格式素材，为后续频谱分析、LSB 隐写检测、摩斯电码解码、语音识别等深度分析提供标准输入。

**关键片段精简：** 针对长时长、高冗余的音视频题目，精准裁剪指定时间区间的有效片段，剔除无关噪音与干扰内容，缩小分析范围，大幅提升后续解码与排查效率。

**元数据隐写排查：** 读取标题、作者、注释、版权、编码器、自定义字段等全量元数据，快速抓取直接隐藏在元数据中的明文 flag、解压密码、解题提示，属于低难度送分考点的常规排查项。

**变速内容还原：** 修复被加速、减速、倒放篡改的音视频内容，还原正常播放速率与播放顺序，使扭曲的语音、摩斯信号、节奏线索恢复为可被人耳或工具正常识别的状态。

**内嵌线索提取：** 提取视频内封装的软字幕、私有数据流、附件文件，获取隐藏在字幕文本、附加流中的解题线索；部分题目会将二级隐写文件以附件形式嵌入视频容器。

**裸流数据还原：** 针对无后缀、无容器封装的音视频编码裸流（如 H.264、PCM、AAC 原始流），手动指定编码格式完成标准封装，将纯二进制数据还原为可播放、可分析的完整音视频文件。

**格式兼容转换：** 实现不同封装格式、编码格式的互转，将小众或特殊格式音视频转为通用分析格式（如 M4A 转 WAV、FLV 转 MP4），适配后续各类分析工具的格式要求。

**精准帧提取：** 支持按时间点、帧序号提取单张目标画面，无需导出全部帧序列，适用于已知线索大致位置的题目，大幅缩减冗余操作，提升定位效率。

## 四、补充点

**格式优选：** 音频隐写分析优先转 WAV 无损格式，相比 MP3 更适合精准分析。

**操作提示：** 全量逐帧提取会生成大量图片文件，解题完成后需及时清理。

**标准解题流程：** 异常文件先修复→视频优先抽帧排查画面→分离音轨做音频分析→查看元数据→变速还原→提取字幕与隐藏流。
