zipdetails是专门深度解析ZIP底层结构的工具，主打分析压缩包标志位、加密属性、注释内容、尾部冗余数据、结构篡改、畸形压缩包。

## 一、核心基础用法

zipdetails目标压缩包.zip

工具会完整输出压缩包全部底层信息，包含文件目录、标志位、加密状态、注释、偏移、尾部附加数据等关键内容。

## 二、应用场景

**场景一：** 识别ZIP伪加密

压缩包双击解压会提示需要密码，看似加密，实则是人为修改文件局部加密标志位，压缩包内部数据完全明文，属于典型伪加密。普通解压工具无法分辨，只会强制要求输入密码。

**判断方法：** 执行命令后，重点观察两类标识：全局目录段无加密标记，但单个文件条目标注encrypted，就是标准伪加密。

**场景二：** 读取隐藏注释线索

出题人在ZIP全局注释、单个文件独立注释中写入明文flag、解压密码、解密提示、编码密钥，系统自带解压软件、普通解压工具默认不展示这类注释内容。

**工具输出特征：** 会单独打印Global comment全局注释、File comment单文件注释字段。

**场景三：** 检测压缩包尾部捆绑隐写

在ZIP合法结束结构之后，拼接PNG、TXT、另一款压缩包、Shellcode、流量文件等，属于文件拼接类复合隐写。

**工具判断逻辑：** 输出中会明确提示存在尾部多余数据，标记压缩目录结束后仍有额外字节。

**场景四：** 分析畸形与篡改ZIP

人为修改ZIP头部偏移、目录地址、压缩算法字段、文件大小字段，造成压缩包损坏、解压报错、无法正常读取。

**场景五：** 查看内部文件敏感特征

利用特殊文件名、空白文件、异常时间戳、特殊压缩算法埋藏线索，或是嵌套多层ZIP压缩。

完整列出压缩包内所有文件的原始名称、压缩尺寸、原始尺寸、创建修改时间、压缩算法。异常命名、诡异时间戳、非常规压缩方式，都是题目隐藏突破口，方便定向排查。

**场景六：** 识别分卷与嵌套压缩

使用分卷ZIP压缩、ZIP套多层压缩的出题方式，常规解压工具识别失败。

可识别分卷压缩标记、嵌套目录结构，区分主压缩包与分卷文件，辅助拆分多层嵌套压缩包，逐层解密解题。

## 三、关键做题注意点

仅针对ZIP格式生效，无法解析RAR、7Z等其他压缩格式；

伪加密是该工具不可替代的核心作用，其他工具无法如此直观分辨加密位；

所有结构异常、多余数据、特殊注释，都是人为设计的考点，不是文件损坏；

全程无需记忆复杂参数，直接执行基础命令，就能覆盖绝大多数ZIP题型考点。

## 四、vs. zipinfo

| 对比维度 | zipinfo | zipdetails |
| --- | --- | --- |
| 核心定位 | 传统 ZIP 目录列表工具，类ls风格的文件级信息汇总 | ZIP 底层二进制结构解析工具，字节级结构深度拆解 |
| 展示粒度 | 以单个文件为单位，宏观展示包内文件条目 | 以结构块为单位，精细到每个文件头字段、字节偏移地址 |
| 核心输出内容 | 文件名、原始大小、压缩后大小、压缩比、压缩方法、文件权限、修改时间、CRC 校验值 | 本地文件头 / 中央目录 / 结束标记的签名、各字段偏移、字段长度、CRC 存储位置、额外数据区、注释内容 |
| 字节偏移信息 | 无，不涉及二进制层面位置 | 完整展示每个结构的十六进制偏移量，可精准定位任意字段的字节位置 |
| 结构异常识别 | 仅能识别基础文件损坏、解压错误 | 可识别伪加密标记、头字段篡改、中央目录偏移异常、尾部冗余数据、隐藏区块 |
| 典型适用场景 | 快速枚举压缩包内容、查看压缩率、确认文件清单 | CTF 结构题排查、伪加密判定、隐藏数据定位、结构篡改修复 |
