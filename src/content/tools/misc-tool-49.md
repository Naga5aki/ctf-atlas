## 一、适用范围及原理

**工具定位：** CTF 领域主流专业级音频隐写工具，是省赛及以上级别带密码音频隐写的标准考点。

**支持格式：** 兼容 WAV、MP3、FLAC、WMA、APE 五种音频格式，其中 WAV 与 MP3 是赛题最常见的载体。

**核心原理：** 采用 AES-256-CBC 算法对隐藏文件全量加密后，将加密二进制数据分散嵌入音频的多个采样位；嵌入位置由加密密钥派生的伪随机序列决定，区别于普通 LSB 音频隐写。

**隐写特性：** 不改变音频的频谱、波形与听觉特征，常规音频分析工具无法检测；无正确密码时，既无法解密数据，也无法判定音频中是否存在隐写内容。

## 二、工具使用

**导入载体文件：** 启动软件后，通过菜单栏 File → Open 选择待分析音频文件；若存在对应隐写数据，右侧列表会自动显示嵌入文件的名称、大小、修改时间，无需额外扫描。

**无密码提取：** 选中目标文件，点击工具栏「Extract」按钮，选择输出路径与文件名即可完成提取。

**带密码提取：** 点击提取后在弹窗中输入密码；密码错误会直接提示 “无效密码”，不输出乱码，可用于快速验证密码正确性。

Kali 辅助爆破：可通过deepsound2john脚本提取音频中的密码哈希，再使用 John 工具进行字典爆破。

**嵌入功能：** 仅用于出题场景，解题无需掌握。

## 三、应用场景

### 1.无密码基础隐写题

**题型特征：** 入门级考点，无密码相关提示，常规音频分析无异常

**解题方法：** 直接导入音频后无密码提取，通过file命令验证输出文件类型，获取 flag 或二级分析文件

### 2.带密码进阶隐写题

**题型特征：** 无密码无法提取数据，题目中隐含密码线索

**解题方法：** 按优先级寻找密码：题目描述中的特殊文字 / 数字 → 音频元数据的标题、注释等字段 → 文件尾追加数据 → 其他附件内容 → 通用弱密码；无明确线索时可配合哈希爆破尝试

### 3.嵌套隐写综合题

**题型特征：** 提取出的文件为压缩包、其他隐写载体或编码文本

**解题方法：** 逐层拆解，对输出文件依次执行解压、隐写分析、编解码等操作，最终获取 flag

## 四、补充点

### 1. 隐写识别特征

同时满足以下条件可高度判定为 DeepSound 隐写：

载体为 WAV、MP3 或 FLAC 格式

Audacity 频谱、波形、相位等全量常规分析无异常，排除摩斯电码、SSTV、DTMF 等基础题型

MP3Stego、SilentEye、StegSpy 等其他音频隐写工具均提取失败

题目存在密码相关提示，或可从元数据、文件尾获取密码线索

音频体积略大于同时长、同码率的正常音频，但差异不显著

### 2. 标准解题流程

Audacity 常规分析排查基础题型 → 其他音频隐写工具验证无果 → 导入 DeepSound 检测隐写数据 → 先尝试无密码提取 → 按优先级寻找密码线索或哈希爆破 → 提取后用file命令确认文件真实类型 → 深度分析获取最终 flag

### 3. 避坑指南

**版本兼容：** 不同版本加密格式互不兼容，v2.1 及以上版本无法提取 v2.0 及更早版本的隐写内容；比赛需同时准备 v2.0 与 v2.2 版本，提取失败立即切换版本验证

**载体要求：** 裁剪、拼接、格式转换、音量调整、降噪等任何二次编辑都会彻底破坏隐写数据，必须使用原始未修改的音频文件

**格式边界：** 不支持 CDA 格式，赛题从未出现该类考点，无需投入时间

**输出验证：** 自定义的输出文件名不代表真实格式，提取后必须用file命令校验，输出可能为压缩包、图片、其他隐写文件等任意格式

**爆破限制：** 无原生暴力破解功能，仅可通过第三方脚本提取哈希后爆破，优先从题目上下文寻找密码线索
