## 一、命令及参数

**基础语法：**

sox [全局选项] <输入文件> <输出文件> [效果参数]

| 命令/参数 | 功能说明 |
| --- | --- |
| soxi <文件> | 查看音频元数据（采样率、声道数、位深、时长、编码格式） |
| stat | 输出音频统计特征（最大 / 最小振幅、直流偏移等） |
| -t <格式> | 强制指定输入 / 输出格式，支持导出 raw 裸数据 |
| rate <采样率> | 修改音频采样率 |
| channels <n> / -c <n> | 转换声道数，支持立体声↔单声道 |
| remix <声道号> | 提取指定声道（1 为左声道，2 为右声道） |
| trim <起始> <时长> | 截取指定时间段的音频片段 |
| vol <倍数> | 按倍率调节音量 |
| norm | 音量标准化至 0dB |
| lowpass <频率> | 低通滤波，滤除高于阈值的高频杂音 |
| highpass <频率> | 高通滤波，滤除低于阈值的低频杂音 |
| bandpass <中心频> <带宽> | 带通滤波，保留指定频段信号 |
| noisered <配置> <阈值> | 降噪处理 |
| speed <倍率> | 调节播放速度与音调 |
| -m -v <倍率> | 混音模式，支持反相叠加（-v -1实现反相） |
| spectrogram -o <文件> | 生成频谱图 PNG 文件 |
| : newfile : restart | 按固定时长自动分割长音频 |

## 二、应用场景

### 1.基础信息快速预判考点

通过soxi和stat一键获取音频参数，快速缩小考点范围：

8000/11025Hz 采样率 → 优先排查 DTMF 双音多频、摩尔斯电码

双声道立体声 → 优先做左右声道分离与作差

无损 PCM 编码 WAV → 可排查 LSB 隐写、SSTV 慢扫描电视

时长 <10 秒 → 大概率为 DTMF、摩尔斯电码；时长> 30 秒 → 偏向 SSTV、重复片段隐写

直流偏移异常、振幅范围异常 → 提示音频被篡改，存在隐藏数据

### 2.格式与参数标准化预处理

作为所有深度分析的前置步骤，解决格式兼容与参数不统一问题：

**格式转换：** 将 MP3/OGG/FLAC 等压缩格式转为标准 WAV，适配绝大多数隐写分析工具

**参数统一：** 作差前统一采样率、声道数，标准化音量，确保差值计算准确

**格式修复：** 针对后缀伪造、畸形无法打开的音频，强制指定格式完成修复

### 3.音频作差提取隐藏信号

通过反相叠加抵消相同信号，提取差异部分的隐藏内容：

**左右声道作差：** 单立体声音频中，flag 藏于左右声道差异处，分离声道后反相叠加，差值频谱常可直接看到 flag

**双文件作差：** 给出原始音频与隐写音频，抵消公共背景音，提取隐藏的摩斯码、语音线索

**进阶对齐作差：** 针对存在时间偏移、音量不一致的音频，先通过trim对齐时间、norm标准化音量，再作差，提升抵消效果

### 4.音频裁剪、拼接与自动分割

处理碎片化、长时长、含冗余噪音的音频：

**精准裁剪：** 截取关键时间段，剔除无效噪音片段

**碎片拼接：** 合并多段拆分的音频碎片，还原完整 SSTV、摩尔斯信号

**自动分割：** 将长音频按固定时长拆分为多段，批量排查重复隐藏片段

### 5.滤波降噪与信号提纯

针对被噪音覆盖的有效信号，通过滤波与降噪提升后续解码成功率：

**高低通滤波：** 过滤对应频段的背景杂波，提纯目标信号

**带通滤波：** 针对 DTMF、SSTV 的专用频段过滤，大幅提升工具解码准确率

**降噪处理：** 消除轻微背景噪音，强化微弱的摩斯码、语音线索

### 6.参数篡改还原

修复被人为修改参数的失真音频，还原原始信息：

**采样率篡改：** 修正异常采样率，还原正常波形与声音

**变速变调：** 调节播放速度，还原被加速 / 减速的摩斯码、语音线索

### 7.可视化与底层数据提取

对接后续分析工具，完成深度隐写排查：

**生成频谱图：** 直接输出频谱 PNG，快速识别隐藏文字、二维码、SSTV 波形等频谱隐写

导出原始 PCM 数据：提取音频底层二进制流，用于十六进制分析、LSB 隐写检测、字符串检索

## 三、补充要点

### 1.标准解题排查流程

① 基础信息检测：soxi查看元数据，初步预判考点

② 格式标准化：转为 WAV 无损格式，统一基础参数

③ 文件级隐写排查：strings 检索关键字、binwalk 检测内嵌附件

④ 声道隐写排查：分离左右声道，执行声道作差，查看差值频谱

⑤ 全局频谱排查：生成频谱图，检测隐藏文字、图案、特殊信号

⑥ 深度隐写排查：LSB 隐写检测、参数篡改修复、特殊信号（SSTV/DTMF）解码

### 2.常见坑点与避坑

**参数顺序严格：** 输入文件必须位于输出文件之前，效果参数需对应放置在目标文件后

**裁剪参数易错：** trim参数为「起始时间 + 持续时长」，而非起始到结束的时间点

**作差前提条件：** 双音频作差前，必须统一采样率、声道数，且标准化音量，否则无法完全抵消

**时间偏移问题：** 存在时间偏移的音频，需先裁剪对齐再作差，否则结果全为噪音

### 3.使用注意

对 WAV 无损格式支持最佳，压缩格式建议先转 WAV 再处理

仅负责音频结构、内容的修复与提取，不承担密码破解功能

trim支持小数秒精度，可精准定位毫秒级的关键音频片段
