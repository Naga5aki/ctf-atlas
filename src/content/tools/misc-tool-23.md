## 一、工具定位

Hashcat 是基于 GPU/CPU 加速的高性能哈希密码恢复工具，是 CTF Misc 赛道弱密码、弱哈希类题目的高效破解工具，核心优势是爆破效率远超纯 CPU 工具，可将数小时的穷举压缩至分钟级完成。

**其应用边界明确：** 仅适用于可穷举的弱加密 / 弱哈希场景（如短密码 ZipCrypto 加密、常见哈希值），对 AES-256 强加密、长复杂密码场景破解效率极低，不建议作为主力思路；在题目中主要承接哈希提取后的密码爆破环节，是压缩包、哈希类考点的效率天花板工具。

## 三、应用场景

### 1.传统 ZIP 压缩包弱密码爆破

针对采用 ZipCrypto 传统加密的 ZIP 包，且密码为 6-10 位短字符、字符集已知的场景，爆破效率远高于 CPU 类工具。WinZip AES-256 加密虽支持但爆破难度极高，CTF 几乎不会作为考点。 操作需先通过 zip2john 提取压缩包哈希，再传入 Hashcat 执行爆破。

### 2.文本哈希值明文恢复

针对题目直接给出、或从元数据 / 隐写中提取的 MD5、SHA1、NTLM 等常见哈希值，当明文为短字符串、常见弱口令时，可快速爆破还原明文。破解结果常作为 flag 组成部分、压缩包密码或后续关卡的解锁密钥，是 Misc 哈希类题目的标准解法。

### 3.文档与多格式弱加密破解

覆盖加密 PDF、Office 2007 + 文档、RAR3/4 格式、7z 压缩包、WiFi 握手包等场景的弱密码恢复。这类考点出现频率低于 ZIP 与文本哈希，仅适用于短密码场景；其中 RAR5 及以上格式加密爆破效率极低，遇到应优先寻找其他解题思路，而非盲目穷举。

## 四、补充考点

### 1.配套工具协作链路

**哈希提取：** 需搭配 zip2john、rar2john 等 John 工具集脚本，将加密压缩包转换为 Hashcat 可识别的哈希格式；哈希类型不明时可先用 hashid 工具识别。

**字典生成：** 可配合 crunch 工具，根据密码规律生成定制化字典，适配特定规则的密码场景。

**文件修复：** 压缩包结构损坏时需先修复文件头，否则无法提取有效哈希，Hashcat 也无法正常执行破解。

### 2.高频避坑指南

**模式号必须精准匹配：** 每种加密 / 哈希格式对应唯一模式号，写错会直接导致破解失败，不确定时可通过hashcat --help查询。

**强加密场景禁止无效爆破：** AES-256 加密 ZIP、RAR5 + 格式、10 位以上复杂混合密码，常规时间内几乎无法破解，应优先转向明文攻击、CRC 爆破、线索查找等其他思路。

必须启用 GPU 加速：纯 CPU 模式爆破效率极低，失去工具核心价值；执行前用hashcat -I校验显卡识别状态，确保加速生效。

**掩码规则精准匹配：** 密码长度、字符集需与题目线索严格对应，盲目扩大字符范围会大幅降低效率；比如纯小写字母用?l，不要用?a做无意义穷举。

### 3.解题效率技巧

**优先使用掩码攻击：** 已知密码长度与组成规律时，掩码攻击效率远高于字典攻击，无需生成额外字典文件。

**结果本地缓存：** 已破解的哈希会被工具缓存，重复执行不会重复计算，使用--show即可快速调取结果。

**增量爆破适配未知长度：** 密码长度范围不确定时，搭配--increment参数指定最小、最大长度，一次性完成范围穷举。
