二者是由 Niels Provos 开发的经典 JPEG DCT 域隐写分析工具链，形成「检测识别 → 定向爆破」的完整分析流程：stegdetect 负责判断 JPEG 疑似使用的隐写算法，stegbreak 针对支持的算法执行密码字典攻击，是 JPEG 经典隐写题型的核心工具组合。

## 一、工具概述

stegdetect

隐写检测工具，通过统计分析 JPEG 的 DCT 系数分布、格式特征，判断文件是否被特定隐写算法处理过，给出算法类型与置信度评估。

**支持检测算法：** JSteg、JPHide、OutGuess 0.13b、Invisible Secrets、F5、文件尾附加类隐写（appendX/camouflage）

**核心定位：** 隐写类型侦察，缩小解题方向，不负责提取数据和破解密码

配套 GUI：xsteg 是 stegdetect 的图形前端，核心检测能力与命令行版完全一致

stegbreak

定向密码破解工具，针对 stegdetect 识别出的隐写算法，使用字典对隐写密码进行暴力枚举，命中后返回正确密码。

**支持破解算法：** JSteg-Shell、JPHide、OutGuess 0.13b

**核心定位：** 密码字典攻击，仅能找回密码，不负责提取隐藏数据

**破解原理：** 逐密码尝试解密，通过解密内容的结构合理性、文件特征（Magic 头）判断是否命中

二者仅针对 JPEG 压缩域隐写，不适用 PNG/BMP 的像素域 LSB 隐写，也无法检测 Steghide 等现代隐写工具。

## 二、具体命令及参数

### 1. stegdetect 参数表

**基础调用格式：**

stegdetect [参数] 目标图片.jpg

| 参数分类 | 参数 | 功能说明 |
| --- | --- | --- |
| 基础调用 | 无额外参数 | 执行默认检测项，输出所有支持算法的检测结果 |
| 检测类型控制 | -t 算法标识 | 指定要运行的检测器，多个标识可连写 |
| 检测类型控制 | -tj | 仅检测 JSteg |
| 检测类型控制 | -tp | 仅检测 JPHide |
| 检测类型控制 | -to | 仅检测 OutGuess |
| 检测类型控制 | -tf | 仅检测 F5 隐写 |
| 检测类型控制 | -ta | 仅检测文件尾附加类隐写 |
| 检测类型控制 | -tjpo | 同时检测 JSteg、JPHide、OutGuess |
| 灵敏度控制 | -s 数值 | 调整检测灵敏度，默认基准为 1；数值越高越灵敏，漏报减少但误报增加 |
| 输出控制 | -q | 静默模式，仅输出存在隐写嫌疑的结果，过滤 negative 项，适合批量筛查 |
| 辅助优化 | -n | 结合 JPEG 头部信息辅助校验，降低部分误报率 |
| 通用命令 | -V | 查看工具版本信息 |

### 2. stegbreak 参数表

**基础调用格式：**

stegbreak [参数] 目标图片.jpg

| 参数分类 | 参数 | 功能说明 |
| --- | --- | --- |
| 破解类型指定 | -t 算法标识 | 指定目标隐写算法，是最核心参数 |
| 破解类型指定 | -tj | 针对 JSteg-Shell 执行字典攻击 |
| 破解类型指定 | -tp | 针对 JPHide 执行字典攻击 |
| 破解类型指定 | -to | 针对 OutGuess 0.13b 执行字典攻击 |
| 字典与规则 | -f 字典文件路径 | 指定密码字典文件；默认调用系统词典，CTF 中通常指定 rockyou.txt 等专用字典 |
| 字典与规则 | -r 规则文件路径 | 加载密码变形规则（兼容 John the Ripper 规则语法），对字典内密码做衍生扩展 |
| 输出控制 | -q | 静默模式，仅输出破解成功的结果，适合批量文件处理 |
| 辅助功能 | -c | 将 JPEG 预处理为精简数据结构，减少重复计算，早期分布式场景使用，常规解题可忽略 |
| 通用命令 | -V | 查看工具版本信息 |

## 三、应用场景

JPEG 隐写类型初筛：拿到未知 JPEG 隐写题时，先用 stegdetect 快速检测，判断属于哪类经典 DCT 隐写，避免盲目尝试所有工具，大幅缩小解题范围。

经典隐写密码爆破;确认隐写算法后，通过 stegbreak 配合字典执行定向密码攻击，快速获取隐写密码，后续再用对应工具提取隐藏数据。

批量 JPEG 文件筛查:题目包含多张 JPEG 图片时，使用 stegdetect -q *.jpg 批量扫描，快速定位存在隐写的目标文件，无需逐张分析。

## 四、补充说明

### 1. 结果解读规则

输出格式为 算法名(***)，星号数量代表置信度，星号越多嫌疑越高，*** 为强匹配。

negative 仅表示未检测到工具支持的经典隐写特征，不等于绝对无隐写；Steghide、自定义隐写、EXIF 隐写、文件尾拼接等均无法被检测。

单张图片可能同时命中多个算法候选，需结合置信度和题目场景综合判断。

### 2. 灵敏度与误报的权衡

灵敏度越高，越容易检出弱特征隐写，但误报概率同步上升。

**解题建议：** 默认 1.0 基准检测无结果时，再逐步调高到 2、3、5；高灵敏度下的低置信度结果（单星号）仅作参考，不可直接作为定论依据。

### 3. 算法支持边界

stegdetect 仅能检测列出的经典早期算法，对现代隐写工具无效。

stegbreak 仅支持三类算法的密码破解，F5、Invisible Secrets 等仅能检测、无法爆破。

OutGuess 仅适配 0.13b 旧版本，更高版本不支持。

### 4. 破解能力限制

stegbreak 本质是字典攻击，仅当密码存在于字典中时才能破解；无法对未知密码做纯暴力穷举，强随机密码无法通过该工具破解。

### 5. 操作小技巧

stegbreak 运行大字典时，第一次按 Ctrl+C 会显示当前进度与状态，短时间内再次按 Ctrl+C 才会终止程序，可随时查看破解进度。
