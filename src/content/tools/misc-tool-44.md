## 一、适用范围及原理

**格式边界：** F5 是 JPEG 格式专属的压缩域隐写工具，仅支持 JPG/JPEG 格式文件；PNG、BMP 等无损格式无 DCT 系数结构，完全不适用。

**核心原理：** 在 JPEG 量化后的 DCT 系数上操作，仅选取绝对值大于 1 的系数修改其最低位嵌入数据；通过矩阵编码技术，平均每嵌入 1 比特数据仅修改约 0.37 个系数，隐写痕迹极弱，隐蔽性远高于像素级隐写。

**加密机制：** 内置 AES-128 加密保护隐藏内容，原始算法硬编码默认密码为abc123。

**检测特性：** 修改发生在压缩域，StegSolve、zsteg 等像素级工具，steghide、binwalk 等常规隐写工具均无法检测与识别；常规排查无结果的 JPG 文件需优先考虑 F5 隐写。

**固有弱点：** 抗二次压缩能力极弱，图片被二次压缩会改变 DCT 系数，导致隐藏数据永久损坏，因此题目载体通常为无二次压缩的原图。

## 二、使用前准备

所有提取命令必须在工具根目录下执行，核心操作如下：

### 1.进入工具目录

切换至 F5-steganography 目录，确认Extract.class等核心程序文件存在：

cd  F5-steganography

ls -la

### 2.移入目标文件

将待分析图片复制到当前目录，避免跨目录读取失败；文件名含空格需用双引号包裹：

cp ~/桌面/challenge.jpg .

### 3.移出结果文件

提取完成后，将输出文件移至指定目录归档：

mv output.txt ~/桌面/

### 4.清理临时文件

单题结束后删除载体、结果文件，避免多题混淆：

rm  challenge.jpg  output.txt

### 5.路径规范

工具目录、文件路径及文件名全程使用纯英文，禁止中文、空格与特殊字符，防止工具静默失败。

## 三、使用方法

工具核心提取程序为Extract.class，在工具目录下通过 Java 命令调用。

### 1.核心参数

| 参数 | 功能说明 |
| --- | --- |
| -p | 指定提取密码；无密码可省略该参数，工具默认内置密码为abc123 |
| -e | 指定提取后的输出文件名；不指定时默认输出为output.txt |

### 2.常用提取命令

**无密码默认提取：** java Extract challenge.jpg

**指定密码提取：** java Extract challenge.jpg  -p 密码

**指定输出文件名提取：** java Extract challenge.jpg -e flag.zip

无密码 + 指定输出文件名：java Extract challenge.jpg -e output.bin

### 3.高版本 Java 兼容提取命令

Java 9 及以上版本因模块化系统限制，直接运行会触发权限报错，需使用兼容命令：

java --add-opens java.base/sun.security.provider=ALL-UNNAMED Extract 目标图片.jpg

其中--add-opens java.base/sun.security.provider=ALL-UNNAMED为核心兼容参数，其余为 F5 工具常规调用格式，可搭配-p、-e等参数组合使用。

## 四、应用场景

### 1.无密码基础题

**题目特征：** JPG 图片为载体，常规隐写工具排查无结果，无明确密码提示。

**解题思路：** 优先尝试无密码提取，失败后立即尝试默认密码abc123；提取后通过file命令确认文件真实类型，对应执行解压、解码等操作。

### 2.有密码进阶题

**题目特征：** 无密码与默认密码提取均失败，题目中隐含密码线索。

**解题思路：** 按优先级查找密码：EXIF 的 Comment 字段 > 文件尾追加数据 > LSB 隐写内容 > 题目描述提示 > 通用弱密码，获取密码后执行提取。

### 3.隐写嵌套综合题

**题目特征：** 多层隐写嵌套。

**解题思路：** 逐层拆解提取，每一步获取内容后先验证文件类型，再推进下一层分析。

### 4.批量隐写题

**题目特征：** 数十张按数字编号命名的 JPG 图片，每张隐藏 1 个 flag 字符片段。 解题思路：通过 Shell 循环脚本批量执行提取，再按编号顺序拼接所有结果得到完整 flag。

## 五、补充点

### 1. 标准解题流程

① 格式校验：执行file命令确认文件为标准 JPEG 格式；

② 常规排查：依次完成 LSB 位平面检测、steghide 隐写检测、binwalk 文件分离、EXIF 元信息查看；

③ F5 初测：常规排查无结果时，先尝试无密码提取，再尝试默认密码abc123提取；

④ 密码定位：默认密码失败时，按优先级系统查找密码线索；

⑤ 结果分析：提取完成后验证文件真实类型，开展解压、解码等后续分析。

### 2. 常见错误与解决方法

Java 版本不兼容报错：报错提示UnsupportedClassVersionError或IllegalAccessError，解决方式为切换 Java 11 版本，或添加上述兼容参数运行。

**提取后文件损坏：** 优先核对密码大小写；检查图片是否被二次压缩、修改过；尝试更换其他版本的 F5 工具提取。

### 3. 核心避坑要点

密码严格区分大小写，输入时需与嵌入密码完全一致。

不同实现版本的 F5 工具互不兼容，矩阵编码、加密逻辑存在差异，比赛优先使用原版 F5-steganography 工具。

输出文件默认后缀为.txt，不代表内容是纯文本，提取后必须用file命令确认真实格式，禁止直接按文本处理。

仅支持 JPEG 格式，切勿在 PNG、BMP 等其他格式图片上尝试。

提取大文件时需要几秒到十几秒的处理时间，请勿中途中断命令。

### 4. 进阶技巧

**快速验证命令：** 可通过一行命令依次尝试无密码和默认密码，提升效率：

java Extract challenge.jpg || java Extract challenge.jpg -p abc123

**批量提取脚本：** 针对批量题目，可通过循环一键完成所有图片提取与拼接：

for i in {0..99}; do java Extract $i.jpg -e $i.txt; donecat {0..99}.txt > full_flag.txt
