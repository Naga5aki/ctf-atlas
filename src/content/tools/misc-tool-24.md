## 一、工具定位

xxd 是 Kali/Linux 系统原生预装的轻量十六进制处理工具。核心能力覆盖二进制与十六进制双向转换、指定偏移切片读取、不可打印字符可视化、自定义格式输出，可替代简易版专业十六进制编辑器，支持与 Shell 命令管道联动实现流水线分析，是处理文件头损坏、后缀伪造、Hex 编码类题目的首选工具。

## 二、核心命令及参数

| 分类 | 命令格式 | 功能说明 |
| --- | --- | --- |
| 基础查看 | xxd <目标文件> | 标准三列输出：左侧偏移地址、中间十六进制编码、右侧可打印 ASCII 字符 |
| 纯编码输出 | xxd -p <目标文件> | 输出连续纯净的十六进制字符串，去除偏移、ASCII 等所有冗余信息 |
| 反向还原 | xxd -r -p <Hex文本> <输出二进制文件> | 将纯十六进制字符串反向还原为原始二进制文件 |
| 定点截取 | xxd -s <起始偏移> -l <读取长度> <目标文件> | -s 指定读取起始偏移（支持0x前缀标识十六进制），-l 指定读取字节数 |
| 行宽控制 | xxd -c <每行字节数> <目标文件> | 自定义每行显示的字节数量 |
| 格式适配 | xxd -u <目标文件> | 以大写字母输出十六进制编码 |
| 辅助查询 | xxd -h | 查看完整帮助文档与参数说明 |

## 三、实战应用场景

### 1.文件格式核验与伪装识别

通过头部魔数快速识别文件真实类型，识破后缀伪造；同时可快速查看文件尾部区域，定位藏在末尾的明文 flag、Base64 密文等线索。

### 2.十六进制与二进制双向转换

导出文件纯 Hex 编码，用于在线解码、脚本运算；反向将题目给出的 Hex 密文、分段 Hex 数据还原为图片、压缩包、可执行文件等完整二进制文件。

### 3.指定偏移精准提取数据

针对给出偏移地址、长度提示的题目，定点截取文件中的隐藏数据段，单独导出分析；无需打开重型十六进制编辑器，一条命令完成精准提取。

### 4.损坏文件头快速修复

针对魔数被篡改、头部残缺的图片 / 压缩包，先导出完整 Hex，修改补全正确的文件头字段后，反向还原为正常二进制文件，实现快速修复，适配 PNG、JPG、ZIP、BMP 等绝大多数常见格式。

### 5.不可见字符隐写排查

将零宽字符、控制符、隐藏分隔符等不可打印字符全部转为十六进制编码展示，可快速识别零宽隐写、空格隐写、分隔符分栏加密等题型的异常特征，定位隐藏信息。

### 6.流水线联动分析

配合 grep、strings、base64 等命令通过管道联动，实现一键检索 flag 关键字、截取数据后直接解码等操作，省去手动复制步骤，形成完整分析链路。

### 7.二进制构造与拼接

可通过 Hex 模板生成小型自定义二进制文件，也可将多段 Hex 拼接后反向还原，实现二进制文件无缝合并，适配隐写嵌入、文件构造类题目。

## 四、补充考点

反向还原必须搭配-r -p组合使用，仅用-r无法正确解析纯 Hex 字符串，会导致还原失败。

-s参数默认偏移单位为十进制字节，添加0x前缀可指定十六进制偏移，需与题目给出的偏移格式匹配。

xxd 仅适合轻量查看与小文件修复，大文件深度编辑优先使用专业十六进制编辑器。
