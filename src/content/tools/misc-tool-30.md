## 一、工具概述

pdfcrack 是 CTF Misc 赛道 PDF 加密题型的专用破解工具，针对标准 PDF 加密算法，可爆破用户打开密码、所有者权限密码，移除文档复制、打印、内容提取等权限限制，是 PDF 类隐写与加密题的核心解题工具。

## 二、核心命令及参数

| 参数/命令 | 功能说明 |
| --- | --- |
| pdfcrack -f 目标.pdf | 默认运行模式，优先爆破用户打开密码，自动遍历基础弱口令 |
| -w 字典文件路径 | 加载自定义字典文件，配合 crunch 生成定向字典，提升复杂密码破解成功率 |
| -u | 仅针对用户打开密码进行爆破（默认模式） |
| -o / --owner | 仅针对所有者权限密码进行爆破，用于解除文档权限限制 |
| -c 字符集 | 指定密码字符集，开启纯暴力破解模式 |
| -n 数字 | 设置暴力破解的密码最小长度，配合 -c 使用 |
| -m 数字 | 设置暴力破解的密码最大长度，配合 -c 使用 |
| -l 状态文件 | 加载已保存的破解进度，实现断点续破，中断后无需从头开始 |
| -s | 对字典内密码做首字母大小写变换，扩大字典覆盖范围 |
| -q | 静默运行模式，精简输出信息 |

## 三、应用场景

爆破 PDF 打开密码

对应 PDF 全局加密题型：文件需输入密码才能打开，内容完全锁定。通过默认弱口令爆破或字典攻击，解锁文档后提取隐藏 flag。

解除 PDF 权限限制

**对应所有者加密题型：** PDF 可正常预览，但禁止复制文字、提取图片、打印。爆破所有者密码后可导出无限制文档，直接获取文本类 flag。

定向字典破解

**对应带线索的中等难度题：** 题目给出密码长度、字符范围、格式规则等提示。配合 crunch 生成定制字典，缩小爆破范围，精准命中密码。

固定长度纯暴力破解

**对应短密码题型：** 密码为固定长度数字、简单字母组合。指定字符集与长度区间，直接暴力遍历快速破解。

双层加密分层破解

**对应复合加密题型：** 同时存在打开密码与权限限制。分别使用 -u、-o 参数分层爆破，逐层解锁文档。

长任务断点续破

**对应耗时较长的爆破任务：** 破解中途中断后，可加载保存的进度文件继续破解，避免重复计算浪费时间。

## 四、补充点

**生效边界：** 仅对标准 PDF 加密算法生效，无法破解加壳、篡改底层结构的畸形 PDF，也不支持 Word、Excel 等其他文档格式。

**解题标准流程：** 拿到 PDF 先验证打开权限与复制权限；可打开但无法编辑，优先破解所有者权限；需密码则先弱口令爆破，失败后结合题目线索定制字典。

**工具联动：** 搭配 crunch 生成规则化字典；搭配 strings 提取 PDF 底层字符串，寻找密码线索；搭配十六进制编辑器修复畸形 PDF 结构后再破解。

**题型规律：** CTF 题目不会设置无规律强密码，破解失败优先排查是否遗漏密码线索，或 PDF 存在结构畸形、隐写等其他考点。
