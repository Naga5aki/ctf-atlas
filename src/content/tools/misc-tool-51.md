MMSSTV 是处理慢扫描电视（SSTV）隐写的专用工具，是 CTF 音频隐写方向出现频率最高的考点。它将业余无线电中 "用声音传输图片" 的技术，转化为从音频文件中提取隐藏 flag 的标准解法。

## 一、核心原理与识别方法

### 1. 基本原理

SSTV 将静态图片的每一行像素编码为不同频率的声波（1500Hz-2300Hz），通过音频信号传递图像。CTF 中出题人会把包含 flag 的图片编码为 WAV 格式的音频，选手需要反向解码还原图片。

### 2. 三大识别特征（满足两个即可确定）

**听觉特征：** 音频听起来是老式传真机 + 电视雪花的混合声，是连续尖锐的嗡嗡声，没有任何语音或音乐元素

**频谱特征：** 用 Audacity 打开查看频谱图，会看到非常清晰的水平平行条纹（每一行像素对应一个固定频率）

**校准音特征：** 标准 SSTV 音频开头一定会有一个持续 300 毫秒的 1900Hz 纯音，用于接收端同步信号

## 二、标准操作流程

MMSSTV 本身不能直接读取 WAV 文件，只能从声卡输入接收信号。正确流程需要借助虚拟声卡实现内部音频传输：

1.配置虚拟声卡：将系统默认播放设备和 MMSSTV 的默认录音设备，同时设置为同一个虚拟音频线路（如 VB-Cable），避免外放再录制的噪音和失真

### 2.启动接收模式：打开 MMSSTV，切换到RX接收标签页，点击Auto按钮开启自动解码

### 3.播放音频文件：用任意音频播放器播放 SSTV 的 WAV 文件

4.获取结果：MMSSTV 会自动检测开头的 1900Hz 校准音，逐行解码图片，完成后自动保存到软件目录下的RX Images文件夹

## 三、主流 SSTV 模式

### 1. Martin 1

**分辨率：** 320×256

**传输时间：** 约 114 秒 / 张

**特点：** 使用 RGB 三通道分别传输，色彩还原度最高

**适用：** 绝大多数国内 CTF 比赛的 SSTV 题目

### 2. Scottie 1

**分辨率：** 320×256

**传输时间：** 约 110 秒 / 张

**特点：** 同步信号格式和行扫描顺序与 Martin 1 不同

**适用：** 自动模式解码出的图片有倾斜、错位时，优先手动切换到此模式

### 3. Robot 36

**分辨率：** 320×240

**传输时间：** 约 36 秒 / 张（速度最快）

**特点：** 使用 YCbCr 色彩空间，先传亮度再传色差，色彩还原度稍低

**适用：** 国际比赛、模拟真实无线电传输的题目，国际空间站 SSTV 也使用此模式

## 四、高频坑点与解决方案

### 1. 采样率不匹配（最常见失败原因）

**问题表现：** 解码出的图片严重倾斜、出现彩色条纹、上下错位

**根本原因：** SSTV 标准采样率是 11025Hz 或 22050Hz，题目给出的音频常为 44100Hz 或 48000Hz

**解决方法：** 用 Audacity 打开音频，在轨道→重采样中转换为 11025Hz，导出后重新解码

### 2. 音量不合适

**问题表现：** 解码完全失败，或图片有大量噪点

**解决方法：** 将系统音量和 MMSSTV 输入音量都调整到 50% 左右，观察 MMSSTV 右下角的电平表，确保始终在绿色区域，不要进入红色削波区

### 3. 同步失败

**问题表现：** MMSSTV 没有任何反应，或解码从中间开始

**根本原因：** 音频开头的校准音被截断、缺失或被噪音干扰

**解决方法：**

手动点击 MMSSTV 的Sync按钮，在音频播放到校准音位置时触发同步

先暂停音频，手动选择正确的 SSTV 模式，再从头播放

### 4. 图片方向错误

**问题表现：** 解码出的图片上下颠倒或左右翻转

**解决方法：** 不要怀疑音频问题，直接手动切换到 Martin 1 或 Scottie 1 模式重新解码即可

## 五、进阶组合场景

1.LSB+SSTV：最常见组合。先用 StegSolve 或 zsteg 从图片的 LSB 中提取出隐藏的 WAV 文件，再用 MMSSTV 解码

2.视频 + SSTV：SSTV 音频藏在视频的音轨中。用 FFmpeg 提取音频：ffmpeg -i video.mp4 -vn -acodec pcm_s16le sstv.wav

3.分段 SSTV：一张 flag 图片被拆成多段音频，分别藏在不同文件中。用 Audacity 将所有片段按顺序拼接成完整 WAV 后再解码

4.带噪 SSTV：音频中加入了背景噪音。先用 Audacity 的降噪功能，选取纯噪音样本对整个音频降噪后再解码

## 六、补充

MMSSTV无法直接读取 WAV 文件，只能通过声卡输入接收信号，虚拟声卡是实现无失真解码的唯一标准方案。

标准配置方案

统一使用VB-Cable虚拟声卡，安装后必须重启电脑生效

**核心对应关系：** 系统默认播放设备设为CABLE Input，MMSSTV 输入设备设为CABLE Output

关键操作要点

### 1.配置完成后，播放音频时观察 MMSSTV 右下角电平表，有跳动波形即为成功

### 2.解决 "自己听不到声音"：

**比赛推荐：** 解码完成后临时切回物理声卡

**一劳永逸：** 开启CABLE Output的 "侦听此设备" 功能，选择物理播放设备

常见排错

**无信号：** 检查设备对应关系，重启 MMSSTV 和播放器

信号过强（电平表满红）：将系统和播放器音量调至 50%，关闭所有音效

解码倾斜 / 条纹：与声卡无关，是采样率不匹配，用 Audacity 重采样为 11025Hz 即可
