## 一、适用范围及原理

**工具定位：** depix 是 CTF Misc 方向还原线性方框滤波类像素化（马赛克）文字的专用工具，可从被打码的截图中恢复被遮挡的文本内容。

**核心原理：** 基于像素块匹配算法，使用与原图字体、字号、颜色完全一致的字符样本，与目标图中的像素块逐一比对匹配，反向还原原始文字。

**适用条件：** 仅对线性方框滤波类像素化有效，覆盖 Greenshot、系统截图、Sublime 等绝大多数常用截图 / 编辑工具的像素打码效果。

**不适用场景：** 高斯模糊、动态模糊等非方框滤波类打码，工具完全无法还原。

**环境依赖：** 基于 Python 运行，仅需pillow、numpy两个核心依赖库。

## 二、工具使用

### 1. 前期准备

**环境安装：** 执行pip install pillow numpy安装核心依赖。

**素材处理：** 将目标图片裁剪为仅包含像素化文字的矩形区域，剔除多余背景；准备与原图字体、字号、颜色、背景一致的字体样本，项目自带常见编辑器样本可直接使用。

### 2. 核心基础命令

**标准命令格式：**

python depix.py -p 像素化图.png -s 字体样本.png -o 结果.png

**核心参数说明：**

-p：待还原的像素化图片路径，必须为精准裁剪的矩形文字区域

-s：字体样本图片路径，是决定还原效果的核心因素

-o：还原结果图片的输出路径

### 3. 高频场景进阶参数

| 参数 | 适用场景 | 功能说明 |
| --- | --- | --- |
| --backgroundcolor R,G,B | 带背景色的编辑器截图（Sublime、VS Code 等） | 传入背景色 RGB 值，过滤背景干扰，仅匹配文字像素块 |
| --averagetype linear | GIMP 生成的像素化图片 | 切换为线性平均模式；默认 gamma 模式适配普通截图工具 |
| -bs 数值 | 非常规尺寸像素块（如 8×8） | 手动指定像素块的边长，适配非标准像素块的题目 |

### 4. 调试辅助

使用辅助脚本验证像素块识别：

python tool_show_boxes.py -p 目标图.png -s 样本.png

正常结果中红色框会完整包围每个像素块，若出现偏差则需重新裁剪目标图片。

## 三、应用场景

**普通截图像素化还原：** 针对系统截图、Greenshot 等工具生成的标准方框像素化文字，使用基础命令即可完成还原。

**代码编辑器截图还原：** 针对 Sublime、VS Code 等带自定义背景的编辑器像素截图，通过指定背景色参数过滤干扰，还原其中的 flag、代码文本。

GIMP 像素化图片还原：针对 GIMP 软件生成的像素化图片，切换线性平均模式适配，解决默认模式还原失效的问题。

**非常规像素块题型还原：** 针对非标准尺寸的像素块题目，手动指定块大小参数，适配特殊出题场景。

## 四、补充点

### 1. 核心注意事项

**样本是还原的核心：** 字体、字号、颜色、背景必须与原图高度一致，匹配度直接决定还原准确率。

**裁剪必须精准：** 目标图仅保留像素化文字区域，多余的边框、背景会干扰块匹配，导致还原失败。

**优先使用自带样本：** 项目images/searchimages目录下覆盖了记事本、主流编辑器的标准样本，可直接匹配选用。

### 2. 失败排查思路

还原效果差优先更换匹配度更高的字体样本。

背景干扰明显时添加背景色过滤参数。

GIMP 类图片切换平均模式为linear。

像素块识别异常时，用-bs手动指定块尺寸，或重新裁剪目标图。

### 3. 标准解题流程

裁剪目标图片，仅保留像素化文字的矩形区域。

根据图片来源（系统、编辑器、GIMP）选择对应字体样本。

执行基础还原命令，初步验证还原效果。

效果不佳时，根据场景添加对应进阶参数调试。

识别异常时用辅助脚本检查像素块匹配情况，调整裁剪或参数后重试。
