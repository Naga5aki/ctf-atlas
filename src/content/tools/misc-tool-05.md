fcrackzip是一款专门用于暴力破解ZIP加密文件的命令行工具，专门用来穷举破解ZIP文件的解压密码。

## 一、核心定义与原理

**本质：** fcrackzip是一款轻量级的ZIP密码破解工具，支持字典攻击和**暴力破解（穷举）**两种模式。

**核心优势：**

速度快，专门针对ZIP传统加密算法优化。

支持指定密码长度、字符集（数字/字母/符号），大幅缩小破解范围。

能直接识别并验证加密ZIP，自动过滤错误密码。

## 二、典型应用场景

### 1.暴力破解已知长度/字符集的密码

当题目给出密码线索，可以精准指定破解范围：

#破解4位数字密码

fcrackzip -v -u -l 4-p 0000 hidden.zip

-v：显示详细破解过程。

-u：验证并只输出正确密码，自动过滤错误尝试。

-l 4：限定密码长度为4位。

-p 0000：从0000开始穷举数字密码。

### 2.字典攻击（针对弱密码/常见密码）

#使用字典文件破解

fcrackzip -v -u -D -p wordlist.txt hidden.zip

-D：启用字典模式。

-p wordlist.txt：指定字典文件路径。

### 3.混合模式破解（字母+数字组合）

当密码是字母+数字的组合时，可以指定字符集：

#破解6位小写字母+数字密码

fcrackzip -v -u -l 6 -c a1 hidden.zip

-c a1：限定字符集为小写字母（a）+数字（1）。

## 三、常用参数详解

-v显示详细破解过程（Verbose）

-u自动验证密码，只输出正确结果（Unlink）

-l min-max限定密码长度范围（如-l 4-6表示4~6位）

-c charset指定字符集：a=小写字母，A=大写字母，1=数字，!=符号

-p init指定初始密码/字典文件：数字穷举时填起始值，字典模式时填字典路径

-D启用字典攻击模式（需配合-p指定字典文件）

## 四、使用注意事项

**线索优先：** 先从题目/文件名中找密码线索（如数字长度、字符类型），缩小破解范围，避免无意义的全字符穷举。

**效率优化：** 4位数字密码（0000~9999）破解速度极快，几秒即可完成；若密码更长或字符集更广，建议使用字典攻击。

**兼容性：** 仅支持ZIP传统加密，不支持AES等高级加密算法，这类算法需用zip2john+john破解。
