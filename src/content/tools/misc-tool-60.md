## 一、工具概述

TShark 是 Wireshark 官方推出的命令行版网络抓包与协议分析工具，完全复用 Wireshark 的协议解析引擎与显示过滤语法，支持上千种网络协议解析。它可实现离线 pcap 文件分析、实时网卡抓包、字段精准提取、流量统计还原等功能，无需图形界面，支持脚本化批量处理，广泛应用于网络运维排障、安全审计等场景。

## 二、核心命令及参数

| 参数分类 | 参数 | 功能说明 |
| --- | --- | --- |
| 输入输出 | -r <pcap文件路径> | 读取离线 pcap/pcapng 文件，是 CTF 离线流量分析的核心参数 |
| 输入输出 | -i <网卡标识> | 指定网卡进行实时流量捕获 |
| 输入输出 | -w <输出文件路径> | 将过滤后的数据包或捕获结果保存为 pcap 文件 |
| 输入输出 | -c <数据包数量> | 仅处理指定数量的数据包 |
| 过滤控制 | -Y <显示过滤表达式> | 按 Wireshark 标准显示过滤语法筛选数据包，支持多条件逻辑组合 |
| 过滤控制 | -f <捕获过滤表达式> | 实时抓包时的捕获过滤，语法同 tcpdump，离线分析基本不用 |
| 字段提取 | -T <输出格式> | 指定输出格式，常用值：fields（字段提取）、json、text |
| 字段提取 | -e <协议字段名> | 配合-T fields使用，指定提取的目标字段，可重复指定多个 |
| 字段提取 | -V | 输出数据包完整的分层详细解析内容 |
| 字段提取 | -n | 禁用 IP 反向域名解析，大幅提升大文件处理速度 |
| 统计分析 | -z <统计命令> | 执行流量统计功能，如 TCP 流追踪、会话统计、协议分布统计 |

**高频提取字段参考：**

**网络层：** ip.src（源 IP）、ip.dst（目的 IP）

**传输层：** tcp.srcport（源端口）、tcp.payload（TCP 载荷）

**应用层：** http.request.uri（请求路径）、http.host（请求主机）、dns.qry.name（DNS 查询名）

## 三、应用场景

1.CTF 流量初筛定位

通过-Y参数过滤指定协议、关键字段，快速从海量流量中筛选 HTTP、DNS、FTP 等可疑会话，排除无关流量。

### 2.关键字段批量导出

配合-T fields批量提取 URL、请求体、DNS 查询内容、载荷数据等，结合 grep 等工具快速检索 flag 关键字。

### 3.会话流完整还原

通过-z follow命令追踪 TCP/UDP 流，还原完整交互内容，提取传输的文件、明文凭证、命令执行记录等。

### 4.异常流量排查

统计协议占比、会话长度、数据包特征，快速识别 DNS 隧道、ICMP 隧道、文件隐写传输等异常攻击流量。

### 5.实时抓包与运维排障

指定网卡实时捕获流量，按需过滤保存，用于网络故障定位、攻击行为溯源、业务流量审计。

## 四、补充点

**语法兼容：** 显示过滤语法与 Wireshark 图形版完全通用，支持&&（与）、||（或）、!（非）逻辑运算符，可嵌套组合复杂过滤规则。

**流追踪标准用法：** 还原指定编号 TCP 流的 ASCII 内容：tshark -r test.pcap -z follow,tcp,ascii,0，流编号从 0 开始计数，可替代 GUI 的跟随 TCP 流功能。

**批量处理：** 输出结果可直接对接 grep、awk、sed 等命令二次处理，支持写入脚本实现自动化解题与批量流量分析。

避坑要点

处理大体积 pcap 时，优先添加-Y过滤条件缩小范围，再执行字段提取，显著提升运行效率

提取二进制载荷时注意截断与编码问题，需完整原始数据建议导出后再做分析

HTTPS 等加密流量需导入 SSL/TLS 会话密钥，才能解密查看明文内容

**扩展能力：** 支持 Lua 脚本自定义协议解析，可适配小众协议与特殊 CTF 出题场景。
